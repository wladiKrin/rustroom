# Phase 1 / M1.2 — Core Global Adjustments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the core global develop adjustments — white balance, exposure, contrast, highlights/shadows/whites/blacks, and a point tone curve — as pipeline stages driven by the `Edits` op-list, and stand up the **golden-image regression test harness** that locks their output for the rest of the project.

**Architecture:** Each adjustment is a `PipelineStage` operating in linear light, inserted (in canonical order) *before* `OutputTransformSrgb`. `build_pipeline(&Edits)` conditionally adds a stage only when its params are non-neutral, then always appends the output transform. Every stage gets a fast unit test on tiny inputs plus a golden test that renders a fixed synthetic chart with fixed `Edits` and compares to a committed reference PNG within tolerance.

**Tech Stack:** Existing Rust workspace; `image` as a dev-dependency of `pipeline` for golden PNG I/O; `serde_json` promoted to a normal dep of `edit-model` for loading sidecar JSON in the CLI.

## Scope & modeling notes (MVP, flagged)

These are **creative global adjustments operating on the demosaiced, camera-WB-applied, sRGB-primaries linear image** libraw hands us — not raw-domain operations. Two are deliberate MVP approximations, called out so they aren't mistaken for final color science:

1. **White balance (temp/tint)** here is a *creative* WB layered on top of the camera WB, modeled as luminance-normalized per-channel gains. True raw-domain WB (multipliers before demosaic) is a later refinement.
2. **Contrast / highlights / shadows / whites / blacks** use simple, hue-preserving, pivot/region-weighted models in linear light. They are predictable and testable, not Adobe-identical. Perceptual-space refinement is later.

Exposure (linear `×2^EV`) and the tone-curve LUT are exact/standard. Every model's neutral parameter is a strict no-op, so `Edits::default()` still yields the M1.1 zero-edit render.

**Canonical pipeline order** (each added only if non-neutral):
`WhiteBalance → Exposure → Contrast → ToneRegions(hi/sh/wh/bl) → ToneCurve → OutputTransformSrgb`

```rust
    pub fn map_pixels<F: Fn([f32; 3]) -> [f32; 3]>(&self, f: F) -> ImageBuf {
        let mut data = Vec::with_capacity(self.data.len());
        for px in self.data.chunks_exact(Self::CHANNELS) {
            let [r, g, b] = f([px[0], px[1], px[2]]);
            data.push(r);
            data.push(g);
            data.push(b);
        }
        ImageBuf::from_vec(self.width, self.height, data)
```

```rust
use crate::PipelineStage;
use core_image::ImageBuf;
use edit_model::WhiteBalance;

const LUMA: [f32; 3] = [0.2126, 0.7152, 0.0722]; // Rec.709 luma weights

/// Creative white balance: temp/tint -> luminance-normalized per-channel gains.
pub struct WhiteBalanceStage {
    gains: [f32; 3],
}

impl WhiteBalanceStage {
    pub fn new(wb: &WhiteBalance) -> Self {
        let t = wb.temp / 100.0;
        let g = wb.tint / 100.0;
        // Raw gains: warmer -> more R, less B; magenta(+tint) -> less G.
        let mut gains = [1.0 + 0.4 * t, 1.0 - 0.3 * g, 1.0 - 0.4 * t];
        // Normalize so a neutral gray keeps its luminance (WB shifts color, not brightness).
        let lum = LUMA[0] * gains[0] + LUMA[1] * gains[1] + LUMA[2] * gains[2];
        if lum > 1e-6 {
            for c in &mut gains {
                *c /= lum;
            }
        }
        Self { gains }
    }
}

impl PipelineStage for WhiteBalanceStage {
    fn name(&self) -> &'static str {
        "white_balance"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        let [gr, gg, gb] = self.gains;
        image.map_pixels(|[r, g, b]| [r * gr, g * gg, b * gb])
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn neutral_wb_is_identity() {
        let s = WhiteBalanceStage::new(&WhiteBalance::default());
        let mut img = ImageBuf::new(1, 1);
        img.set_pixel(0, 0, [0.2, 0.5, 0.8]);
        let out = s.apply(img);
        let [r, g, b] = out.pixel(0, 0);
        assert!((r - 0.2).abs() < 1e-5 && (g - 0.5).abs() < 1e-5 && (b - 0.8).abs() < 1e-5);
    }

    #[test]
    fn warming_raises_red_lowers_blue() {
        let s = WhiteBalanceStage::new(&WhiteBalance { temp: 50.0, tint: 0.0 });
        assert!(s.gains[0] > s.gains[2]); // red gain > blue gain
    }

    #[test]
    fn neutral_gray_preserves_luminance() {
        let s = WhiteBalanceStage::new(&WhiteBalance { temp: 60.0, tint: -20.0 });
        let gray = [0.5, 0.5, 0.5];
        let out_lum: f32 = (0..3).map(|i| LUMA[i] * gray[i] * s.gains[i]).sum();
        let in_lum: f32 = (0..3).map(|i| LUMA[i] * gray[i]).sum();
        assert!((out_lum - in_lum).abs() < 1e-4);
    }
}
```

```rust
use crate::PipelineStage;
use core_image::ImageBuf;

const PIVOT: f32 = 0.18; // linear middle gray

/// Contrast around a mid-gray pivot: `out = pivot + (in - pivot) * slope`.
pub struct ContrastStage {
    slope: f32,
}

impl ContrastStage {
    /// `amount` ~[-100, 100]; 0 = identity, +100 = slope 2, -100 = slope 0 (flat).
    pub fn new(amount: f32) -> Self {
        Self { slope: 1.0 + amount / 100.0 }
    }
}

impl PipelineStage for ContrastStage {
    fn name(&self) -> &'static str {
        "contrast"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        let slope = self.slope;
        image.map_samples(|s| (PIVOT + (s - PIVOT) * slope).max(0.0))
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn zero_is_identity() {

        img.set_pixel(0, 0, [0.05, 0.18, 0.9]);
        let out = ContrastStage::new(0.0).apply(img);
        let [r, g, b] = out.pixel(0, 0);
        assert!((r - 0.05).abs() < 1e-6 && (g - 0.18).abs() < 1e-6 && (b - 0.9).abs() < 1e-6);
    }

    #[test]
    fn pivot_is_a_fixed_point() {
        let mut img = ImageBuf::new(1, 1);
        img.set_pixel(0, 0, [PIVOT, PIVOT, PIVOT]);
```

```rust
use crate::PipelineStage;
use core_image::ImageBuf;

const LUMA: [f32; 3] = [0.2126, 0.7152, 0.0722];
const STRENGTH: f32 = 0.5; // scales all four amounts

/// Highlights/shadows/whites/blacks as a single luminance-region-weighted gain.
/// All amounts ~[-100, 100]; positive brightens that region. Hue-preserving.
pub struct ToneRegionsStage {
    highlights: f32,
    shadows: f32,
    whites: f32,
    blacks: f32,
}

impl ToneRegionsStage {
    pub fn new(highlights: f32, shadows: f32, whites: f32, blacks: f32) -> Self {
        Self {
            highlights: highlights / 100.0,
            shadows: shadows / 100.0,
            whites: whites / 100.0,
            blacks: blacks / 100.0,
        }
    }

    fn gain_for_luma(&self, l: f32) -> f32 {
        let l = l.clamp(0.0, 1.0);
        let shadow_w = (1.0 - l) * (1.0 - l);
        let highlight_w = l * l;
        let black_w = (1.0 - 3.0 * l).max(0.0); // only l < 1/3
        let white_w = (3.0 * l - 2.0).max(0.0); // only l > 2/3
        1.0 + STRENGTH
            * (self.shadows * shadow_w
                + self.highlights * highlight_w
                + self.blacks * black_w
                + self.whites * white_w)
    }
}

impl PipelineStage for ToneRegionsStage {
    fn name(&self) -> &'static str {
        "tone_regions"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        image.map_pixels(|[r, g, b]| {
            let l = LUMA[0] * r + LUMA[1] * g + LUMA[2] * b;
            let gain = self.gain_for_luma(l).max(0.0);
            [r * gain, g * gain, b * gain]
        })
    }
}
```

Applied per-sample on clamped [0,1] linear values via a linearly-interpolated LUT.

```rust
use crate::PipelineStage;
use core_image::ImageBuf;

const LUT_SIZE: usize = 1024;

/// Point tone curve compiled to a LUT. Points are (x, y) in [0, 1].
pub struct ToneCurveStage {
    lut: Vec<f32>,
}

impl ToneCurveStage {
    /// Build from control points. Fewer than 2 points => identity.
    pub fn new(points: &[[f32; 2]]) -> Self {
        let mut pts: Vec<[f32; 2]> = points
            .iter()
            .map(|p| [p[0].clamp(0.0, 1.0), p[1].clamp(0.0, 1.0)])
            .collect();
        pts.sort_by(|a, b| a[0].partial_cmp(&b[0]).unwrap());

        let lut = (0..LUT_SIZE)
            .map(|i| {
                let x = i as f32 / (LUT_SIZE - 1) as f32;
                Self::eval(&pts, x)
            })
            .collect();
        Self { lut }
    }

    /// Piecewise-linear evaluation; identity if fewer than 2 points.
    fn eval(pts: &[[f32; 2]], x: f32) -> f32 {
        if pts.len() < 2 {
            return x;
        }
        if x <= pts[0][0] {
            return pts[0][1];
        }
        if x >= pts[pts.len() - 1][0] {
            return pts[pts.len() - 1][1];
        }
        for w in pts.windows(2) {
            let (a, b) = (w[0], w[1]);
            if x >= a[0] && x <= b[0] {
                let span = b[0] - a[0];
                let t = if span > 1e-9 { (x - a[0]) / span } else { 0.0 };
                return a[1] + t * (b[1] - a[1]);
            }
        }
        x
    }

    fn sample(&self, v: f32) -> f32 {
        let v = v.clamp(0.0, 1.0);
        let pos = v * (LUT_SIZE - 1) as f32;
        let i = pos.floor() as usize;
        if i >= LUT_SIZE - 1 {
            return self.lut[LUT_SIZE - 1];
        }
        let frac = pos - i as f32;
        self.lut[i] + frac * (self.lut[i + 1] - self.lut[i])
    }
}

impl PipelineStage for ToneCurveStage {
    fn name(&self) -> &'static str {
        "tone_curve"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        image.map_samples(|s| self.sample(s))
    }
}
```

```rust
/// Build the ordered stage list for a set of edits. A stage is added only when its
/// params are non-neutral; the output transform is always last.
pub fn build_pipeline(edits: &Edits) -> Pipeline {
    let mut stages: Vec<Box<dyn PipelineStage>> = Vec::new();

    if edits.white_balance != edit_model::WhiteBalance::default() {
        stages.push(Box::new(WhiteBalanceStage::new(&edits.white_balance)));
    }
    if edits.exposure != 0.0 {
        stages.push(Box::new(ExposureStage::new(edits.exposure)));
    }
    if edits.contrast != 0.0 {
        stages.push(Box::new(ContrastStage::new(edits.contrast)));
    }
    if edits.highlights != 0.0 || edits.shadows != 0.0 || edits.whites != 0.0 || edits.blacks != 0.0
    {
        stages.push(Box::new(ToneRegionsStage::new(
            edits.highlights,
            edits.shadows,
            edits.whites,
            edits.blacks,
        )));
    }
    if !edits.tone_curve.points.is_empty() {
        stages.push(Box::new(ToneCurveStage::new(&edits.tone_curve.points)));
    }

    stages.push(Box::new(OutputTransformSrgb));
    Pipeline::new(stages)
}
```

```rust
//! Golden-image regression tests. Set `UPDATE_GOLDEN=1` to (re)write references.
//!
//! A fixed synthetic "chart" is rendered through `build_pipeline(&edits)`; the RGB8
//! output must match the committed PNG within `TOL` per channel.

use core_image::ImageBuf;
use edit_model::{Edits, ToneCurve, WhiteBalance};
use pipeline::build_pipeline;
use std::path::PathBuf;

const W: usize = 64;
const H: usize = 16;
const TOL: i32 = 2; // per-channel tolerance (float pow differs slightly across platforms)

/// Deterministic linear test chart: 4 horizontal bands (gray, R, G, B), each a 0..1 ramp.
fn chart() -> ImageBuf {
    let mut img = ImageBuf::new(W, H);
    for y in 0..H {
        let band = y * 4 / H; // 0..3
        for x in 0..W {
            let v = x as f32 / (W - 1) as f32;
            let px = match band {
                0 => [v, v, v],
                1 => [v, 0.0, 0.0],
                2 => [0.0, v, 0.0],
                _ => [0.0, 0.0, v],
            };
            img.set_pixel(x, y, px);
        }
    }
    img
}

fn to_rgb8(img: &ImageBuf) -> Vec<u8> {
    img.data()
        .iter()
        .map(|&v| (v.clamp(0.0, 1.0) * 255.0).round() as u8)
        .collect()
}

fn golden_path(name: &str) -> PathBuf {
    PathBuf::from(env!("CARGO_MANIFEST_DIR"))
        .join("tests/golden")
        .join(format!("{name}.png"))
}

fn check_golden(name: &str, edits: &Edits) {
    let rendered = build_pipeline(edits).run(chart());
    let bytes = to_rgb8(&rendered);
    let path = golden_path(name);

    if std::env::var("UPDATE_GOLDEN").is_ok() {
        std::fs::create_dir_all(path.parent().unwrap()).unwrap();
        image::save_buffer(&path, &bytes, W as u32, H as u32, image::ColorType::Rgb8).unwrap();
        return;
    }

    let golden = image::open(&path)
        .unwrap_or_else(|_| panic!("missing golden {name}; run with UPDATE_GOLDEN=1"))
        .to_rgb8();
    assert_eq!(golden.dimensions(), (W as u32, H as u32), "{name}: size");
    let gbytes = golden.into_raw();
    let max_diff = bytes
        .iter()
        .zip(&gbytes)
        .map(|(&a, &b)| (a as i32 - b as i32).abs())
        .max()
        .unwrap_or(0);
    assert!(max_diff <= TOL, "{name}: max per-channel diff {max_diff} > {TOL}");
}

#[test]
fn golden_neutral() {
    check_golden("neutral", &Edits::default());
}

#[test]
fn golden_exposure_plus1() {

}

#[test]
fn golden_warm_wb() {
```

```rust
fn render(input: &Path, output: &Path, edits_path: Option<&Path>, quality: u8) -> Result<()> {
    let decoded = raw_decode::decode_raw(input, &raw_decode::DecodeOptions::linear_scene())
        .with_context(|| format!("decoding {}", input.display()))?;
    let m = &decoded.metadata;
    eprintln!("Decoded {}x{}  {} {}", m.width, m.height, m.make, m.model);

    let edits = match edits_path {
        Some(p) => edit_model::Edits::from_json_file(p)
            .with_context(|| format!("loading edits {}", p.display()))?,
        None => edit_model::Edits::default(),
    };
    let rendered = pipeline::build_pipeline(&edits).run(decoded.image);

    export::save_jpeg(&rendered, output, quality)
        .with_context(|| format!("writing {}", output.display()))?;
    eprintln!("Wrote {}", output.display());
    Ok(())
}
```
