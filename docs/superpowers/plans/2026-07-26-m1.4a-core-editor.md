# M1.4a — Core Interactive Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working desktop GUI (`Rustroom`) that opens a RAW at half-size, shows a live preview updated by a background render worker, exposes the scalar adjustment sliders + a live histogram, supports zoom/pan and reset, and exports a full-res JPEG.

**Architecture:** New `crates/app` (lib + bin). All non-UI logic lives in the lib as small unit-tested modules (`downscale` lives in `core-image`; `histogram`, `render_engine` in `app`); the egui view code in `main.rs` stays thin and is verified by a build + manual smoke run. The develop pipeline stays CPU (reused `pipeline` crate); its sRGB output is uploaded as an egui texture. A dedicated worker thread renders on request with coalescing so the UI never blocks.

**Tech Stack:** `eframe`/`egui` 0.35 (wgpu backend), `rfd` 0.17 (native file dialogs), existing `core-image`/`raw-decode`/`edit-model`/`pipeline`/`export`.

```rust
    /// Downscale so the longer edge is at most `max_dim`, preserving aspect ratio, using
    /// area averaging in the current (linear) light. Never upscales; returns a copy if
    /// already small enough or if `max_dim == 0`.
    pub fn downscale_to(&self, max_dim: usize) -> ImageBuf {
        let long = self.width.max(self.height);
        if max_dim == 0 || long <= max_dim {
            return self.clone();
        }
        let scale = max_dim as f32 / long as f32;
        let dw = (self.width as f32 * scale).round().max(1.0) as usize;
        let dh = (self.height as f32 * scale).round().max(1.0) as usize;

        let mut out = ImageBuf::new(dw, dh);
        for oy in 0..dh {
            // source row span for this output row
            let sy0 = oy * self.height / dh;
            let sy1 = (((oy + 1) * self.height / dh).max(sy0 + 1)).min(self.height);
            for ox in 0..dw {
                let sx0 = ox * self.width / dw;
                let sx1 = (((ox + 1) * self.width / dw).max(sx0 + 1)).min(self.width);
                let mut acc = [0.0f32; 3];
                let mut n = 0.0f32;
                for sy in sy0..sy1 {
                    for sx in sx0..sx1 {
                        let p = self.pixel(sx, sy);
                        acc[0] += p[0];
                        acc[1] += p[1];
                        acc[2] += p[2];
                        n += 1.0;
                    }
                }
                out.set_pixel(ox, oy, [acc[0] / n, acc[1] / n, acc[2] / n]);
            }
        }
        out
    }
```

```rust
/// Per-channel 256-bin counts [R, G, B] from an interleaved RGBA byte buffer.
pub fn histogram_rgba(rgba: &[u8]) -> [[u32; 256]; 3] {
    let mut h = [[0u32; 256]; 3];
    for px in rgba.chunks_exact(4) {
        h[0][px[0] as usize] += 1;
        h[1][px[1] as usize] += 1;
        h[2][px[2] as usize] += 1;
    }
    h
}
```

```rust
//! Background render worker: renders `Edits` against a cached linear editing buffer,
//! off the UI thread, coalescing superseded requests.

use core_image::ImageBuf;
use edit_model::Edits;
use pipeline::build_pipeline;
use std::sync::mpsc::{channel, Receiver, Sender, TryRecvError};
use std::sync::Arc;
use std::thread::{self, JoinHandle};

/// A finished preview frame (display sRGB, RGBA8).
pub struct RenderedFrame {
    pub width: usize,
    pub height: usize,
    pub rgba: Vec<u8>,
}

struct Request {
    edits: Edits,
    max_dim: usize,
}

/// Owns a worker thread that renders against a fixed editing buffer.
pub struct RenderEngine {
    req_tx: Sender<Request>,
    res_rx: Receiver<RenderedFrame>,
    _handle: JoinHandle<()>,
}

impl RenderEngine {
    /// `on_done` is called after each render completes (e.g. `ctx.request_repaint`).
    pub fn new(buffer: Arc<ImageBuf>, on_done: impl Fn() + Send + 'static) -> Self {
        let (req_tx, req_rx) = channel::<Request>();
        let (res_tx, res_rx) = channel::<RenderedFrame>();
        let handle = thread::spawn(move || {
            while let Ok(mut req) = req_rx.recv() {
                // Coalesce: skip to the most recent pending request.
                loop {
                    match req_rx.try_recv() {
                        Ok(newer) => req = newer,
                        Err(TryRecvError::Empty) => break,
                        Err(TryRecvError::Disconnected) => return,
                    }
                }
                let frame = render(&buffer, &req);
                if res_tx.send(frame).is_err() {
                    return;
                }
                on_done();
            }
        });
        Self {
            req_tx,
            res_rx,
            _handle: handle,
        }
    }

    /// Queue a render at the given working resolution.
    pub fn request(&self, edits: Edits, max_dim: usize) {
        let _ = self.req_tx.send(Request { edits, max_dim });
    }

    /// Return the newest finished frame, if any (drops older ones).
    pub fn poll_latest(&self) -> Option<RenderedFrame> {
        let mut latest = None;
        while let Ok(f) = self.res_rx.try_recv() {
            latest = Some(f);
        }
        latest
    }
}

fn render(buffer: &ImageBuf, req: &Request) -> RenderedFrame {
    let preview = buffer.downscale_to(req.max_dim);
    let out = build_pipeline(&req.edits).run(preview); // sRGB, 0..=1
    let (width, height) = (out.width(), out.height());
    let mut rgba = Vec::with_capacity(width * height * 4);
    for px in out.data().chunks_exact(3) {
        rgba.push((px[0].clamp(0.0, 1.0) * 255.0).round() as u8);
        rgba.push((px[1].clamp(0.0, 1.0) * 255.0).round() as u8);
        rgba.push((px[2].clamp(0.0, 1.0) * 255.0).round() as u8);
        rgba.push(255);
    }
    RenderedFrame {
        width,
        height,
        rgba,
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    fn tiny() -> Arc<ImageBuf> {
        let mut img = ImageBuf::new(8, 8);
        for y in 0..8 {
            for x in 0..8 {
                img.set_pixel(x, y, [0.5, 0.5, 0.5]);
            }
        }
        Arc::new(img)
    }

    fn wait_for_frame(engine: &RenderEngine) -> RenderedFrame {
        for _ in 0..200 {
            if let Some(f) = engine.poll_latest() {
                return f;
            }
            std::thread::sleep(std::time::Duration::from_millis(5));
        }
        panic!("no frame produced");
    }

    #[test]
    fn produces_rgba_frame_of_expected_size() {
        let engine = RenderEngine::new(tiny(), || {});
        engine.request(Edits::default(), 4); // downscale 8 -> 4
        let f = wait_for_frame(&engine);
        assert_eq!((f.width, f.height), (4, 4));
        assert_eq!(f.rgba.len(), 4 * 4 * 4);
        // mid-gray linear 0.5 -> sRGB ~188; alpha 255
        assert!(f.rgba[0] > 180 && f.rgba[0] < 195);
        assert_eq!(f.rgba[3], 255);
    }

    #[test]
    fn exposure_brightens() {
        let engine = RenderEngine::new(tiny(), || {});
        engine.request(
            Edits {
                exposure: 2.0,
                ..Edits::default()
            },
```

```rust
    }
}

fn draw_histogram(ui: &mut egui::Ui, hist: &[[u32; 256]; 3]) {
    let max = hist
        .iter()
        .flat_map(|c| c.iter())
        .copied()
        .max()
        .unwrap_or(1)
        .max(1) as f32;
    let (rect, _) = ui.allocate_exact_size(egui::vec2(ui.available_width(), 80.0), egui::Sense::hover());
    let painter = ui.painter_at(rect);
    let colors = [
        egui::Color32::from_rgb(220, 80, 80),
        egui::Color32::from_rgb(80, 200, 80),
        egui::Color32::from_rgb(90, 120, 230),
    ];
    for (ci, chan) in hist.iter().enumerate() {
```

```rust
    fn export_dialog(&mut self) {
        let Some(s) = &self.session else { return };
        let Some(out) = rfd::FileDialog::new()
            .add_filter("JPEG", &["jpg", "jpeg"])
            .set_file_name("export.jpg")
            .save_file()
        else {
            return;
        };
        let src = s.path.clone();
        let edits = s.edits.clone();
        self.status = "Exporting (full-res decode)…".into();
        // Full decode + render + encode is slow; run on a thread.
        std::thread::spawn(move || {
            let result = (|| -> anyhow::Result<()> {
                let decoded = raw_decode::decode_raw(&src, &raw_decode::DecodeOptions::linear_scene())?;
                let rendered = pipeline::build_pipeline(&edits).run(decoded.image);
                export::save_jpeg(&rendered, &out, 92)?;
                Ok(())
            })();
            if let Err(e) = result {
                eprintln!("export error: {e}");
            }
        });
    }
```
