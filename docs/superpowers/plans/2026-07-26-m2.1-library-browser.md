# M2.1 — Folder Browser / Library Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a folder of RAWs in `Rustroom`, show a grid of embedded-JPEG thumbnails that load progressively, and double-click / Enter a photo to edit it in the existing Develop view.

**Architecture:** A new `catalog` crate scans a folder into a sorted list of RAW entries. `raw-decode` gains `extract_thumbnail` (embedded JPEG → RGBA, no demosaic). The `app` lib gains a `thumb_loader` background worker (same shape as `render_engine`) that streams thumbnails off the UI thread. `app`'s `main.rs` gains a `Library`/`Develop` view split: the Library view renders the grid; selecting a photo builds the existing editor `Session` and switches to Develop.

**Tech Stack:** Existing workspace + `eframe`/`egui` 0.35, `rfd` (folder picker), `image` (JPEG decode of the embedded thumbnail). No new external crates beyond wiring `image` into `raw-decode`.

## Spec reference

Implements `docs/superpowers/specs/2026-07-26-m2.1-library-browser-design.md`. Scope is layout **A** (Library grid ↔ Develop). Filmstrip/**C**, on-disk cache, edit-accurate thumbnails, ratings, sorting, subfolders are **deferred** — do not build them here.

//! The thin catalog: scan a folder for RAW files. In-memory only (no DB yet).

use std::path::{Path, PathBuf};

/// Known RAW file extensions (lowercase, without the dot).
pub const RAW_EXTENSIONS: &[&str] = &["cr2", "cr3", "nef", "arw", "raf", "dng", "orf", "rw2"];

/// One browsable photo in a folder.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CatalogEntry {
    pub path: PathBuf,
    pub file_name: String,
}

fn is_raw(path: &Path) -> bool {
    path.extension()
        .and_then(|e| e.to_str())
        .map(|e| RAW_EXTENSIONS.contains(&e.to_ascii_lowercase().as_str()))
        .unwrap_or(false)
}

/// Scan a single folder (non-recursive) for RAW files, sorted by file name.
pub fn scan_folder(dir: &Path) -> std::io::Result<Vec<CatalogEntry>> {
    let mut entries = Vec::new();
    for dirent in std::fs::read_dir(dir)? {
        let dirent = dirent?;
        let path = dirent.path();
        if path.is_file() && is_raw(&path) {
            let file_name = path
                .file_name()
                .and_then(|n| n.to_str())
                .unwrap_or_default()
                .to_string();
            entries.push(CatalogEntry { path, file_name });
        }
    }
    entries.sort_by(|a, b| a.file_name.cmp(&b.file_name));
    Ok(entries)
}

pub(crate) fn extract_thumbnail(bytes: &[u8]) -> Result<Thumbnail, DecodeError> {
    let mut raw =
        RawImage::open(bytes).map_err(|e| DecodeError::Backend(format!("open: {e:?}")))?;
    let thumbs = raw
        .extract_thumbs()
        .map_err(|e| DecodeError::Backend(format!("thumbs: {e:?}")))?;
    // Largest by pixel count (rsraw returns them sorted by height; pick the biggest).
    let t = thumbs
        .into_iter()
        .max_by_key(|t| t.width as u64 * t.height as u64)
        .ok_or_else(|| DecodeError::Format("no embedded thumbnail".into()))?;

    match t.format {
        ThumbFormat::Jpeg => {
            let img = image::load_from_memory(&t.data)
                .map_err(|e| DecodeError::Backend(format!("thumb jpeg: {e}")))?
                .to_rgba8();
            Ok(Thumbnail {
                width: img.width() as usize,
                height: img.height() as usize,
                rgba: img.into_raw(),
            })
        }
        ThumbFormat::Bitmap => {
            let (w, h, c) = (t.width as usize, t.height as usize, t.colors as usize);
            if c != 3 || t.data.len() < w * h * c {
                return Err(DecodeError::Format(format!(
                    "unexpected bitmap thumb: {w}x{h} colors={c} len={}",
                    t.data.len()
                )));
            }
            let mut rgba = Vec::with_capacity(w * h * 4);
            for px in t.data.chunks_exact(c) {
                rgba.extend_from_slice(&[px[0], px[1], px[2], 255]);
            }
            Ok(Thumbnail {
                width: w,
                height: h,
                rgba,
            })
        }
        other => Err(DecodeError::Format(format!(
            "unsupported thumbnail format: {other:?}"
        ))),
    }
}
```

//! Background worker that extracts embedded thumbnails off the UI thread and streams
//! them back keyed by their index in the folder listing.

use raw_decode::Thumbnail;
use std::path::PathBuf;
use std::sync::mpsc::{channel, Receiver};
use std::thread::{self, JoinHandle};

/// One finished thumbnail (or `None` if that file had no usable preview).
pub struct ThumbResult {
    pub index: usize,
    pub thumb: Option<Thumbnail>,
}

/// Owns a worker thread that loads a fixed list of paths, in order.
pub struct ThumbLoader {
    rx: Receiver<ThumbResult>,
    _handle: JoinHandle<()>,
}

impl ThumbLoader {
    /// `on_progress` is called after each thumbnail (e.g. `ctx.request_repaint`).
    pub fn new(paths: Vec<PathBuf>, on_progress: impl Fn() + Send + 'static) -> Self {
        let (tx, rx) = channel::<ThumbResult>();
        let handle = thread::spawn(move || {
            for (index, path) in paths.into_iter().enumerate() {
                let thumb = raw_decode::extract_thumbnail(&path).ok();
                if tx.send(ThumbResult { index, thumb }).is_err() {
                    return;
                }
                on_progress();
            }
        });
        Self { rx, _handle: handle }
    }

    /// Take all thumbnails finished since the last call.
    pub fn drain(&self) -> Vec<ThumbResult> {
        self.rx.try_iter().collect()
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn streams_results_keyed_by_index_even_on_failure() {
        // Non-existent files fail extraction -> thumb is None, but a result still streams.
        let paths = vec![
            PathBuf::from("/nonexistent/rustroom_a.raf"),
            PathBuf::from("/nonexistent/rustroom_b.raf"),
        ];
        let loader = ThumbLoader::new(paths, || {});
        let mut results = Vec::new();
        for _ in 0..200 {
            results.extend(loader.drain());
            if results.len() >= 2 {
                break;
            }
            std::thread::sleep(std::time::Duration::from_millis(5));
        }
        results.sort_by_key(|r| r.index);
        assert_eq!(results.len(), 2);
        assert_eq!(results[0].index, 0);
        assert_eq!(results[1].index, 1);
        assert!(results[0].thumb.is_none() && results[1].thumb.is_none());
    }
}
```
