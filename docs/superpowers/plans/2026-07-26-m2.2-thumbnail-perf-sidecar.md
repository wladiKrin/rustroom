# M2.2 — Thumbnail Perf + Lossless Photo Switching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two small fixes from M2.1 user feedback: (1) stop decoding/holding full-resolution embedded JPEGs for tiny grid cells — downscale thumbnails; (2) auto-save the edit sidecar when leaving a photo so switching photos never loses edits.

**Architecture:** `raw-decode::extract_thumbnail` downscales the decoded preview to a modest max dimension (via `image`'s `thumbnail`), cutting per-thumb memory ~100×. In `app`, a `persist_current_session` helper writes the current session's `<file>.json` sidecar (when edited) before the session is replaced or the app exits; the existing load-on-open then restores it.

**Tech Stack:** Existing workspace. `image` 0.25 `DynamicImage::thumbnail`.

> **No separate spec:** design was agreed in conversation (measured evidence: embedded preview is 4416×2944; extraction is 2.42 s debug / 0.088 s release — the debug build was the main speed cause, but full-res RGBA textures for 160 px cells are wasteful regardless). Bonus item "run release for real speed" is a usage note, not code — folded into the README in Task 3.

## Task 1: `raw-decode` — downscale thumbnails

Decode both JPEG and bitmap embedded previews into a `DynamicImage`, downscale to `THUMB_MAX_DIM`, then to RGBA. Cuts a 13 MP (~52 MB) thumbnail to ~512 px (~0.7 MB).

**Files:** Modify `crates/raw-decode/src/backend_rsraw.rs`, `crates/raw-decode/src/lib.rs`.

- [ ] **Step 1: Replace the `match t.format { … }` body in `backend_rsraw::extract_thumbnail`**

Replace the whole `match t.format { … }` block (the part that builds the `Thumbnail`) with:
```rust
    const THUMB_MAX_DIM: u32 = 512;

    let dynimg = match t.format {
        ThumbFormat::Jpeg => image::load_from_memory(&t.data)
            .map_err(|e| DecodeError::Backend(format!("thumb jpeg: {e}")))?,
        ThumbFormat::Bitmap => {
            let (w, h, c) = (t.width as usize, t.height as usize, t.colors as usize);
            if c != 3 || t.data.len() < w * h * c {
                return Err(DecodeError::Format(format!(
                    "unexpected bitmap thumb: {w}x{h} colors={c} len={}",
                    t.data.len()
                )));
            }
            let rgb = image::RgbImage::from_raw(t.width, t.height, t.data[..w * h * c].to_vec())
                .ok_or_else(|| DecodeError::Format("bitmap thumb size mismatch".into()))?;
            image::DynamicImage::ImageRgb8(rgb)
        }
        other => {
            return Err(DecodeError::Format(format!(
                "unsupported thumbnail format: {other:?}"
            )))
        }
    };

    // Downscale to a modest size — the grid draws these at ~160 px, so full-res is wasteful.
    let scaled = dynimg.thumbnail(THUMB_MAX_DIM, THUMB_MAX_DIM).to_rgba8();
    Ok(Thumbnail {
        width: scaled.width() as usize,
        height: scaled.height() as usize,
        rgba: scaled.into_raw(),
    })
```

## Task 2: `app` — auto-save sidecar on photo switch / exit

Persist the current session's edits before it's replaced (opening another photo) or the app exits, so switching is lossless. Only writes when the photo has actually been edited (avoids littering `.json` next to untouched RAWs).

**Files:** Modify `crates/app/src/main.rs`.

- [ ] **Step 1: Add the helper on `RustroomApp`**

```rust
    /// Save the current session's edits to its `<file>.json` sidecar, if it has any.
    /// Called before switching photos / on exit so edits are never lost.
    fn persist_current_session(&self) {
        if let Some(s) = &self.session {
            if s.edits != Edits::default() {
                let _ = s.edits.to_json_file(&s.path.with_extension("json"));
            }
        }
    }
```

- [ ] **Step 2: Persist before replacing the session in `open_path`**

At the very start of `open_path` (before the `self.status = …` line):
```rust
        self.persist_current_session();
```
(Both `open_dialog` and `open_entry` go through `open_path`, so every photo switch persists the outgoing one.)

- [ ] **Step 3: Persist on window close (macOS close handler)**

In `ui`, change the close guard to persist first:
```rust
        #[cfg(target_os = "macos")]
        if ctx.input(|i| i.viewport().close_requested()) {
            self.persist_current_session();
            std::process::exit(0);
        }
```

Run:
