# Vignette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a creative post-crop vignette — darken or brighten the frame's edges, with control over the falloff's position, softness and shape.

**Architecture:** One new `VignetteStage` runs last before the output transform. It computes a normalized, frame-centred distance per pixel, maps it through a smoothstep falloff, and applies the result as an exposure-style multiplicative gain in linear light. The shape (ellipse / circle / rounded rectangle) lives in a small `Shape` helper so it can be tested independently of the gain. A new `ImageBuf::map_pixels_xy` supplies the coordinates.

**Tech Stack:** Rust (Cargo workspace), `rayon`, `serde`, `egui` 0.35, and the existing golden-image PNG regression harness.

**Design doc:** `docs/superpowers/specs/2026-08-05-vignette-design.md`

**Before you start.** Every `cargo` command needs libraw discoverable by pkg-config on macOS:

```bash
export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:/opt/homebrew/opt/libraw/lib/pkgconfig:$PKG_CONFIG_PATH"
```

Commit messages in this repo carry **no `Co-Authored-By` trailer** — the repo owner's explicit preference. Do not add one.

**Two things this stage deliberately does *not* need**, both inherited from earlier work — do not add them:

- **No `RenderScale`.** The vignette works in normalized frame coordinates, so preview and export agree exactly. `VignetteStage::new` takes only params.
- **No post-crop plumbing.** `GeometryStage` crops and runs first, so the stage already receives the cropped frame and reads its dimensions directly.

    /// Return a new image with `f` applied to each RGB pixel *together with its `(x, y)`*,
    /// dimensions preserved. For effects whose result depends on position — vignette today;
    /// graduated and radial filters, and lens corrections, later.
    ///
    /// Parallel across rows: pixels are independent, so the result is identical to the
    /// sequential one, bit for bit. `f` must therefore be `Sync + Send`.
    pub fn map_pixels_xy<F: Fn(usize, usize, [f32; 3]) -> [f32; 3] + Sync + Send>(
        &self,
        f: F,
    ) -> ImageBuf {
        let row = self.width * Self::CHANNELS;
        let mut data = vec![0.0f32; self.data.len()];
        if row == 0 {
            // `par_chunks_exact_mut(0)` panics.
            return ImageBuf::from_vec(self.width, self.height, data);
        }
        data.par_chunks_exact_mut(row)
            .zip(self.data.par_chunks_exact(row))
            .enumerate()
            .for_each(|(y, (orow, srow))| {
                for (x, (out, px)) in orow
                    .chunks_exact_mut(Self::CHANNELS)
                    .zip(srow.chunks_exact(Self::CHANNELS))
                    .enumerate()
                {
                    out.copy_from_slice(&f(x, y, [px[0], px[1], px[2]]));
                }
            });
        ImageBuf::from_vec(self.width, self.height, data)
    }
```

/// Post-crop vignette: darken or brighten the frame's edges. `amount` 0 = off; the other
/// three only shape the falloff.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
#[serde(default)]
pub struct Vignette {
    /// -100 darkens the edges by 2 EV, +100 brightens by 2 EV. 0 = off.
    pub amount: f32,
    /// Where the falloff sits, 0..100. Higher pushes it outward.
    pub midpoint: f32,
    /// Shape: -100 rounded rectangle … 0 ellipse following the frame … +100 true circle.
    pub roundness: f32,
    /// Transition width, 0..100. 0 is a hard edge.
    pub feather: f32,
}

impl Default for Vignette {
    fn default() -> Self {
        Self {
            amount: 0.0,
            midpoint: 50.0,
            roundness: 0.0,
            feather: 50.0,
        }
    }
}

impl Vignette {
    /// True when this actually changes pixels.
    ///
    /// Amount-only on purpose, the same rule `NoiseReduction::is_active` follows: midpoint,
    /// roundness and feather shape an effect that is off until `amount` is non-zero, so
    /// dragging one alone must not insert a stage.
    pub fn is_active(&self) -> bool {
        self.amount != 0.0
    }
}

use crate::PipelineStage;
use core_image::ImageBuf;
use edit_model::Vignette;

/// Radius at which the falloff is centred, at Midpoint 0 and 100. `d` is 1 on the
/// frame-inscribed ellipse and ~1.41 at its corners, so this spans "well inside the frame"
/// to "past the corners", i.e. effectively off.
const R_MID: (f32, f32) = (0.2, 1.4);
/// Width of the transition band at Feather 0 and 100. Starts at 0 so Feather 0 is a
/// genuinely hard edge.
const FEATHER: (f32, f32) = (0.0, 1.0);
/// ...which makes this the only thing standing between Feather 0 and a division by zero in
/// `smoothstep`. Load-bearing, not belt-and-braces.
const WIDTH_EPS: f32 = 1e-4;
/// Amount ±100 is this many stops at full falloff. Symmetric in log space, so −50 and +50
/// are exactly equal and opposite.
const MAX_EV: f32 = 2.0;
/// Superellipse exponent at Roundness −100. Higher is more rectangular.
const P_MAX: f32 = 6.0;

fn lerp(a: f32, b: f32, t: f32) -> f32 {
    a + (b - a) * t
}

/// Clamped Hermite smoothstep. Same form as the inline one in `stages/hsl.rs`.
fn smoothstep(e0: f32, e1: f32, x: f32) -> f32 {
    let t = ((x - e0) / (e1 - e0)).clamp(0.0, 1.0);
    t * t * (3.0 - 2.0 * t)
}

/// The vignette's iso-contour shape, from Roundness and the frame's aspect.
///
/// The two halves of the slider move different variables and never both at once: positive
/// stretches an axis (ellipse → circle), negative raises the exponent (ellipse → rounded
/// rectangle).
struct Shape {
    wu: f32,
    wv: f32,
    /// Superellipse exponent. 2 is an ellipse and takes the `sqrt` fast path.
    expo: f32,
    elliptical: bool,
}

impl Shape {
    /// `w`/`h` are the *cropped* frame's dimensions, so this cannot be built in
    /// `VignetteStage::new` — it depends on the image the stage is handed.
    fn new(roundness: f32, w: usize, h: usize) -> Self {
        let (mut wu, mut wv, mut expo, mut elliptical) = (1.0, 1.0, 2.0, true);
        if roundness > 0.0 {
            // Stretch the long axis so d = 1 traces a circle of radius min(w,h)/2 in pixels.
            let t = (roundness / 100.0).min(1.0);
            let aspect = w.max(h) as f32 / w.min(h).max(1) as f32;
            if w >= h {
                wu = lerp(1.0, aspect, t);
            } else {
                wv = lerp(1.0, aspect, t);
            }
        } else if roundness < 0.0 {
            expo = lerp(2.0, P_MAX, (-roundness / 100.0).min(1.0));
            elliptical = false;
        }
        Self {
            wu,
            wv,
            expo,
            elliptical,
        }
    }

    /// Distance in this shape's metric, for normalized frame coordinates in [-1, 1].
    fn distance(&self, u: f32, v: f32) -> f32 {
        let (u, v) = (u * self.wu, v * self.wv);
        if self.elliptical {
            (u * u + v * v).sqrt()
        } else {
            (u.abs().powf(self.expo) + v.abs().powf(self.expo)).powf(1.0 / self.expo)
        }
    }
}

/// Post-crop vignette: a position-dependent gain applied in linear light.
///
/// Needs no `RenderScale` — it works in normalized frame coordinates, so the preview and the
/// export agree exactly. And "post-crop" is structural rather than a mode: `GeometryStage`
/// runs first, so the image handed here is already cropped and its aspect is the crop's.
///
/// The gain is `exp2(..)`, hence strictly positive: this stage cannot emit negative samples
/// and needs no clamp, unlike `HslStage` and `NoiseReductionStage`. Being a scalar multiply,
/// it also leaves `r:g:b` ratios — and so hue and saturation — exactly alone.
pub struct VignetteStage {
    params: Vignette,
}

impl VignetteStage {
    pub fn new(params: &Vignette) -> Self {
        Self { params: *params }
    }
}

impl PipelineStage for VignetteStage {
    fn name(&self) -> &'static str {
        "vignette"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        let (w, h) = (image.width(), image.height());
        if w == 0 || h == 0 || !self.params.is_active() {
            return image;
        }
        let p = self.params;

        let shape = Shape::new(p.roundness, w, h);
        let r_mid = lerp(R_MID.0, R_MID.1, (p.midpoint / 100.0).clamp(0.0, 1.0));
        let width = lerp(FEATHER.0, FEATHER.1, (p.feather / 100.0).clamp(0.0, 1.0)).max(WIDTH_EPS);
        let (e0, e1) = (r_mid - width * 0.5, r_mid + width * 0.5);
        let k = p.amount / 100.0 * MAX_EV;
        let (hw, hh) = (w as f32 * 0.5, h as f32 * 0.5);

        image.map_pixels_xy(|x, y, rgb| {
            let u = (x as f32 + 0.5) / hw - 1.0;
            let v = (y as f32 + 0.5) / hh - 1.0;
            let gain = (k * smoothstep(e0, e1, shape.distance(u, v))).exp2();
            [rgb[0] * gain, rgb[1] * gain, rgb[2] * gain]
        })
    }
}
```
