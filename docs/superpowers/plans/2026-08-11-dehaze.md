# Dehaze Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bidirectional Dehaze control using the dark-channel prior, closing M2.3, without changing any existing rendered pixel.

**Architecture:** `DehazeStage` lives in the pipeline **prefix**, after noise reduction. That placement is the whole design: the prefix always runs whole-buffer, so the frame-global airlight needs no new plumbing, `REGION_MARGIN` never has to grow, and the region-render invariant is untouched. Two spatial primitives support it — a new O(1) `min_filter` for the dark channel, and `guided_self_filter` generalised out of `noise_reduction` into a shared cross-guided `guided_filter` for refining the transmission map.

**Tech Stack:** Rust, `rayon`, the existing `PipelineStage` / `RenderScale` / `PrefixKey` seams, `egui` for one slider.

**Spec:** `docs/superpowers/specs/2026-08-11-dehaze-design.md`

    /// Straightforward O(n·r) sliding minimum, for the deque implementation to be checked
    /// against. Deliberately dumb: its only job is to be obviously correct.
    fn naive_min(plane: &[f32], w: usize, h: usize, r: usize) -> Vec<f32> {
        let mut out = vec![0.0f32; w * h];
        for y in 0..h {
            for x in 0..w {
                let mut m = f32::INFINITY;
                for yy in y.saturating_sub(r)..=(y + r).min(h - 1) {
                    for xx in x.saturating_sub(r)..=(x + r).min(w - 1) {
                        m = m.min(plane[yy * w + xx]);
                    }
                }
                out[y * w + x] = m;
            }
        }
        out
    }

    #[test]

```rust
/// Sliding-window minimum over one contiguous line, window `[i-r, i+r]` clamped to the ends.
///
/// Monotonic deque: indices are held with strictly increasing values, so the front is always
/// the minimum of the current window. Each index is pushed and popped at most once, which
/// makes this **O(1) amortised per sample regardless of `r`** — the same reason `box_blur`
/// keeps running sums.
///
/// A deque rather than the van Herk / Gil-Werman block decomposition specifically because the
/// window **clamps** at the borders instead of reading outside, which a deque expresses
/// directly and block decomposition does not.
pub fn min_1d(line: &[f32], r: usize) -> Vec<f32> {
    let n = line.len();
    let mut out = vec![0.0f32; n];
    if n == 0 {
        return out;
    }
    let mut deque: std::collections::VecDeque<usize> = std::collections::VecDeque::new();
    let mut next = 0usize;
    for (o, dst) in out.iter_mut().enumerate() {
        // Admit everything the window's right edge has reached.
        let hi = (o + r).min(n - 1);
        while next <= hi {
            while let Some(&b) = deque.back() {
                if line[b] >= line[next] {
                    deque.pop_back();
                } else {
                    break;
                }
            }
            deque.push_back(next);
            next += 1;
        }
        // Retire everything the left edge has passed.
        let lo = o.saturating_sub(r);
        while let Some(&f) = deque.front() {
            if f < lo {
                deque.pop_front();
            } else {
                break;
            }
        }
        *dst = line[*deque.front().expect("window is never empty")];
    }
    out
}

/// Minimum over a `(2r+1)²` window — the dark channel's patch operator.
///
/// Separable, because a rectangular window's minimum is the minimum of per-row minima.
///
/// # Panics
/// Panics if `plane.len() != w * h`.
pub fn min_filter(plane: &[f32], w: usize, h: usize, r: usize) -> Vec<f32> {
    assert_eq!(plane.len(), w * h, "plane size mismatch");
    if r == 0 || w == 0 || h == 0 {
        return plane.to_vec();
    }

    // Horizontal: rows are contiguous and independent.
    let mut rows = vec![0.0f32; w * h];
    rows.par_chunks_exact_mut(w)
        .zip(plane.par_chunks_exact(w))
        .for_each(|(orow, srow)| orow.copy_from_slice(&min_1d(srow, r)));

    // Vertical: gather each column into scratch, reduce, scatter back. Unlike `box_blur`'s
    // vertical pass there is no running state to carry, so columns are independent and rayon
    // splits them directly; the gather is the price of reusing the same 1-D routine.
    let mut out = vec![0.0f32; w * h];
    let cols: Vec<Vec<f32>> = (0..w)
        .into_par_iter()
        .map(|x| {
            let column: Vec<f32> = (0..h).map(|y| rows[y * w + x]).collect();
            min_1d(&column, r)
        })
        .collect();
    for (x, column) in cols.iter().enumerate() {
        for (y, &v) in column.iter().enumerate() {
            out[y * w + x] = v;
        }
    }
    out
}
```

    /// The self-guided filter exactly as `noise_reduction` computed it before this was
    /// generalised — kept here as the reference the shared version must reproduce.
    fn legacy_self_filter(p: &[f32], w: usize, h: usize, r: usize, eps: f32) -> Vec<f32> {
        let squared: Vec<f32> = p.iter().map(|v| v * v).collect();
        let mean = box_blur(p, w, h, r);
        let mean_sq = box_blur(&squared, w, h, r);
        let mut slope = Vec::with_capacity(p.len());
        let mut offset = Vec::with_capacity(p.len());
        for (&m, &msq) in mean.iter().zip(mean_sq.iter()) {
            let var = (msq - m * m).max(0.0);
            let s = var / (var + eps);
            slope.push(s);
            offset.push((1.0 - s) * m);
        }
        let mean_slope = box_blur(&slope, w, h, r);
        let mean_offset = box_blur(&offset, w, h, r);
        mean_slope
            .iter()
            .zip(mean_offset.iter())
            .zip(p.iter())
            .map(|((&ms, &mo), &v)| ms * v + mo)
            .collect()
    }

    fn noisy_plane(w: usize, h: usize) -> Vec<f32> {
        let mut state: u32 = 0x9E37_79B9;
        (0..w * h)
            .map(|i| {
                state ^= state << 13;
                state ^= state >> 17;
                state ^= state << 5;
                // Structure plus noise, so `slope` actually varies across the plane.
                let base = if (i % w) < w / 2 { 0.2 } else { 0.7 };
                base + (state as f32 / u32::MAX as f32 - 0.5) * 0.05
            })
            .collect()
    }

        // algebraically to the old one — but `offset` is now `mean_p - slope*mean_I` where it

            let got = guided_filter(&p, &p, w, h, r, eps);

            }
        }

```rust
/// Guided filter (He et al.): edge-preserving smoothing of `p`, with edges taken from
/// `guide`. O(1) per pixel in `r`, because every window statistic is a `box_blur`.
///
/// `slope` and `offset` are the paper's `a` and `b`, renamed because `a` and `b` are the
/// Oklab chroma channels in the noise-reduction stage that calls this.
///
/// The behaviour lives entirely in `slope`. Where the guide's local variance greatly exceeds
/// `eps` — an edge — `slope → 1` and the pixel follows the guide. Where it is far below
/// `eps` — flat, or noise — `slope → 0` and the pixel becomes its local mean.
///
/// **`p == guide` is the self-guided special case** noise reduction uses. Dehaze uses the
/// general form: it filters the transmission map, guided by image luma, which is what pulls
/// the blocky patch-minimum transmission back onto the real depth edges.
///
/// # Panics
/// Panics if `p.len() != w * h` or `guide.len() != w * h`.
pub fn guided_filter(p: &[f32], guide: &[f32], w: usize, h: usize, r: usize, eps: f32) -> Vec<f32> {
    assert_eq!(p.len(), w * h, "p size mismatch");
    assert_eq!(guide.len(), w * h, "guide size mismatch");

    let guide_sq: Vec<f32> = guide.iter().map(|v| v * v).collect();
    let cross: Vec<f32> = guide.iter().zip(p).map(|(g, v)| g * v).collect();

    let mean_guide = box_blur(guide, w, h, r);
    let mean_p = box_blur(p, w, h, r);
    let mean_guide_sq = box_blur(&guide_sq, w, h, r);
    let mean_cross = box_blur(&cross, w, h, r);

    let mut slope = Vec::with_capacity(p.len());
    let mut offset = Vec::with_capacity(p.len());
    for (((&mg, &mp), &mgsq), &mc) in mean_guide
        .iter()
        .zip(mean_p.iter())
        .zip(mean_guide_sq.iter())
        .zip(mean_cross.iter())
    {
        // Cancellation between two nearly equal sums can push the variance slightly negative
        // on perfectly flat areas. The covariance is *not* clamped: unlike a variance it can
        // legitimately be negative when `p` and `guide` are anti-correlated.
        let var = (mgsq - mg * mg).max(0.0);
        let cov = mc - mg * mp;
        let s = cov / (var + eps);
        slope.push(s);
        offset.push(mp - s * mg);
    }

    let mean_slope = box_blur(&slope, w, h, r);
    let mean_offset = box_blur(&offset, w, h, r);
    mean_slope
        .iter()
        .zip(mean_offset.iter())
        .zip(guide.iter())
        .map(|((&ms, &mo), &g)| ms * g + mo)
        .collect()
}
```

use crate::spatial::{guided_filter, min_filter};
use crate::{PipelineStage, RenderScale};
use core_image::ImageBuf;
use edit_model::Dehaze;
use rayon::prelude::*;

/// Haze deliberately retained at full strength. Removing all of it flattens aerial
/// perspective, and keeping a little also softens the bright-object failure case.
const OMEGA: f32 = 0.95;
/// Transmission floor: bounds the recovery gain to x10 in dense haze.
const T_MIN: f32 = 0.1;
/// Dark-channel patch radius, in **full-resolution** pixels.
const PATCH_RADIUS_FULL: f32 = 20.0;
/// Guided-filter radius for refining the transmission, in full-resolution pixels.
/// Deliberately much larger than the patch: the refinement's job is to restore the edges the
/// patch minimum smeared.
const REFINE_RADIUS_FULL: f32 = 60.0;
/// Guided-filter regularisation, against **linear** luma variance.
const REFINE_EPS: f32 = 1e-4;
/// Long edge of the fixed-size image the airlight is estimated on.
const AIRLIGHT_SAMPLE: usize = 256;
/// Fraction of the darkest-channel histogram treated as "most hazy".
const AIRLIGHT_FRACTION: f32 = 0.001;
/// Floor on each channel of the airlight. Load-bearing: `I_c / A_c` divides by it.
const A_MIN: f32 = 1e-3;

/// Rec.709 luma, in linear light. Same as the sharpening and local-contrast stages.
fn luma(px: &[f32]) -> f32 {
    0.2126 * px[0] + 0.7152 * px[1] + 0.0722 * px[2]
}

/// Convert a full-resolution radius to the resolution being rendered. Never 0, which would
/// silently disable the filter at small preview scales. Mirrors `noise_reduction`.
fn scaled_radius(full_px: f32, scale: RenderScale) -> usize {
    ((full_px * scale.get()).round().max(0.0) as usize).max(1)
}

/// Per-channel minimum over the image, per pixel — the "dark channel" before the patch min.
fn channel_min(image: &ImageBuf) -> Vec<f32> {
    image
        .data()
        .par_chunks_exact(3)
        .map(|px| px[0].min(px[1]).min(px[2]))
        .collect()
}

/// Estimate the atmospheric light: the mean colour of the haziest pixels.
///
/// ⚠ Computed on a **fixed-size** downscale, never at the render resolution. An order
/// statistic over the brightest pixels moves when you downscale, so estimating it at the
/// render scale would give the fit preview, the 1:1 view and the export three different
/// airlights — and the image would visibly shift on zoom. Pinning the sample size makes this
/// render-scale-independent by construction.
///
/// The **mean** of the top fraction rather than the single brightest pixel, so one specular
/// highlight or hot pixel cannot set the airlight for the whole frame.
pub fn airlight(image: &ImageBuf) -> [f32; 3] {
    let small = image.downscale_to(AIRLIGHT_SAMPLE);
    let (w, h) = (small.width(), small.height());
    if w == 0 || h == 0 {
        return [A_MIN; 3];
    }
    // Patch radius scaled to the sample, so "haziest" means the same thing at any input size.
    let r = ((PATCH_RADIUS_FULL * AIRLIGHT_SAMPLE as f32
        / image.width().max(image.height()).max(1) as f32)
        .round() as usize)
        .max(1);
    let dark = min_filter(&channel_min(&small), w, h, r);

    let mut order: Vec<usize> = (0..w * h).collect();
    order.sort_unstable_by(|&a, &b| dark[b].total_cmp(&dark[a]));
    let take = ((w * h) as f32 * AIRLIGHT_FRACTION).round().max(1.0) as usize;

    let mut sum = [0.0f32; 3];
    for &i in order.iter().take(take) {
        let px = small.pixel(i % w, i / w);
        for c in 0..3 {
            sum[c] += px[c];
        }
    }
    let n = take as f32;
    [
        (sum[0] / n).max(A_MIN),
        (sum[1] / n).max(A_MIN),
        (sum[2] / n).max(A_MIN),
    ]
}

/// The refined transmission map for `image`: how much of each pixel survived the haze.
pub fn transmission(image: &ImageBuf, a: [f32; 3], scale: RenderScale) -> Vec<f32> {
    let (w, h) = (image.width(), image.height());
    // min over channels of I_c / A_c, then min over the patch.
    let normalized: Vec<f32> = image
        .data()
        .par_chunks_exact(3)
        .map(|px| (px[0] / a[0]).min(px[1] / a[1]).min(px[2] / a[2]))
        .collect();
    let dark = min_filter(&normalized, w, h, scaled_radius(PATCH_RADIUS_FULL, scale));
    let coarse: Vec<f32> = dark.iter().map(|&d| 1.0 - OMEGA * d).collect();

    // Refine against image luma. Without this the map is blocky and any plain blur of it
    // produces halos at depth discontinuities — sky against ridge, which is where dehaze is
    // used most.
    let guide: Vec<f32> = image.data().par_chunks_exact(3).map(luma).collect();
    guided_filter(
        &coarse,
        &guide,
        w,
        h,
        scaled_radius(REFINE_RADIUS_FULL, scale),
        REFINE_EPS,
    )
}

/// Dehaze via the dark-channel prior, on the haze model `I = J·t + A·(1 − t)`.
///
/// The model is **radiometric**, so it holds exactly in this pipeline's linear working space
/// and only approximately in the gamma-encoded space most published implementations use.
///
/// Both slider directions share one expression. With `k = amount/100` and
/// `t_k = 1 − |k|·(1 − t)`: positive **inverts** the model to remove haze, negative **applies**
/// it to add haze. At `k = 0`, `t_k = 1` and both collapse to `J = I` exactly. Because `t`
/// encodes depth, adding haze is depth-aware for free.
pub struct DehazeStage {
    params: Dehaze,
    scale: RenderScale,
}

impl DehazeStage {
    pub fn new(params: &Dehaze, scale: RenderScale) -> Self {
        Self {
            params: *params,
            scale,
        }
    }
}

impl PipelineStage for DehazeStage {
    fn name(&self) -> &'static str {
        "dehaze"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        let (w, h) = (image.width(), image.height());
        if w == 0 || h == 0 || !self.params.is_active() {
            return image;
        }
        let a = airlight(&image);
        let t = transmission(&image, a, self.scale);
        let k = (self.params.amount / 100.0).clamp(-1.0, 1.0);
        let remove = k > 0.0;
        let mag = k.abs();

        let mut data = vec![0.0f32; w * h * 3];
        data.par_chunks_exact_mut(3)
            .zip(image.data().par_chunks_exact(3))
            .zip(&t)
            .for_each(|((o, px), &tv)| {
                let tk = 1.0 - mag * (1.0 - tv);
                for c in 0..3 {
                    let v = if remove {
                        (px[c] - a[c]) / tk.max(T_MIN) + a[c]
                    } else {
                        px[c] * tk + a[c] * (1.0 - tk)
                    };
                    // A pixel darker than the airlight can be driven negative by the
                    // division; clamp at 0, the convention every other stage uses.
                    o[c] = v.max(0.0);
                }
            });
        ImageBuf::from_vec(w, h, data)
    }
}

    fn scene(w: usize, h: usize) -> ImageBuf {
        let mut img = ImageBuf::new(w, h);
        for y in 0..h {

    /// Transmission that falls off to the right: the left of the frame is near, the right far.
    fn depth_t(x: usize, w: usize) -> f32 {
        0.9 - 0.6 * (x as f32 / w as f32)
    }

    /// Apply the haze model forward, producing a hazy image from a known scene.
    fn add_haze(clear: &ImageBuf, a: [f32; 3]) -> ImageBuf {
        let (w, h) = (clear.width(), clear.height());
        let mut out = ImageBuf::new(w, h);
        for y in 0..h {
            for x in 0..w {
                let px = clear.pixel(x, y);
                let t = depth_t(x, w);
                out.set_pixel(
                    x,
                    y,
                    [
                        px[0] * t + a[0] * (1.0 - t),
                        px[1] * t + a[1] * (1.0 - t),
                        px[2] * t + a[2] * (1.0 - t),
                    ],
                );
            }
        }
        out
    }

        DehazeStage::new(&Dehaze { amount }, RenderScale::FULL).apply(img)

                for c in 0..3 {
                    sum += (a.pixel(x, y)[c] - b.pixel(x, y)[c]).abs();
                    n += 1;
