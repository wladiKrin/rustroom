# Ratings, Flags and Colour Labels (M4.2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cull from the keyboard — 1–5 stars, pick/reject, colour labels — stored per virtual copy, shown in the grid, and filterable.

**Architecture:** A version 2 migration adds three columns to `photos`. A `Marks` value type carries them; `app` reads the whole folder's marks once per rebuild into a map keyed by `PhotoId`, so the grid never queries per frame. Keys are handled in the Library only, behind the existing focus gate.

**Tech Stack:** Rust, `rusqlite`, `eframe`/`egui` 0.35.

**Spec:** `docs/superpowers/specs/2026-08-26-ratings-design.md`

/// Pick / reject, or neither.
///
/// ⚠ Stored as `1 / -1 / 0` rather than as text: the neutral value is then `0`, the same as an
/// unrated star and an unset label, so "no mark" needs no special case anywhere.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Flag {
    #[default]
    None,
    Pick,
    Reject,
}

impl Flag {
    fn to_i64(self) -> i64 {
        match self {
            Flag::None => 0,
            Flag::Pick => 1,
            Flag::Reject => -1,
        }
    }

    fn from_i64(v: i64) -> Self {
        match v {
            1 => Flag::Pick,
            -1 => Flag::Reject,
            // ⚠ Anything else reads as unflagged rather than erroring. The column is an integer a
            // future version could widen, and a catalog is never a reason to fail.
            _ => Flag::None,
        }
    }
}

/// Everything a photo is marked with.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct Marks {
    /// 0..=5, where 0 is unrated.
    pub rating: u8,
    pub flag: Flag,
    /// 0 is no label; 1..=5 are the colours.
    pub label: u8,
}

impl Marks {
    /// The largest star rating and colour label.
    pub const MAX_RATING: u8 = 5;
    pub const MAX_LABEL: u8 = 5;

    /// Whether anything is set. ⚠ Used to decide what is worth storing.
    pub fn is_empty(self) -> bool {
        self == Marks::default()
    }

    /// ⚠ Clamped on the way in, not trusted. The value arrives from a key handler and one day
    /// from an import; storing 9 stars would render as garbage in every badge that assumes 0..=5.
    fn clamped(self) -> Self {
        Self {
            rating: self.rating.min(Self::MAX_RATING),
            flag: self.flag,
            label: self.label.min(Self::MAX_LABEL),
        }
    }
}
```

    /// What a photo is marked with. Unknown photos read as unmarked.
    pub fn marks(&self, photo: &Path, copy: u32) -> Result<Marks, CatalogError> {
        let Some(id) = self.photo_id(photo, copy)? else {
            return Ok(Marks::default());
        };
        let (rating, flag, label): (i64, i64, i64) = self.conn.query_row(
            "SELECT rating, flag, label FROM photos WHERE id = ?1",
            [id],
            |r| Ok((r.get(0)?, r.get(1)?, r.get(2)?)),
        )?;
        Ok(Marks {
            rating: rating.clamp(0, Marks::MAX_RATING as i64) as u8,
            flag: Flag::from_i64(flag),
            label: label.clamp(0, Marks::MAX_LABEL as i64) as u8,
        })
    }

    /// Mark a photo. ⚠ A photo the catalog does not know is silently skipped — the catalog is
    /// never a reason an action fails.
    pub fn set_marks(&self, photo: &Path, copy: u32, marks: Marks) -> Result<(), CatalogError> {
        let Some(id) = self.photo_id(photo, copy)? else {
            return Ok(());
        };
        let m = marks.clamped();
        self.conn.execute(
            "UPDATE photos SET rating = ?2, flag = ?3, label = ?4 WHERE id = ?1",
            rusqlite::params![id, m.rating as i64, m.flag.to_i64(), m.label as i64],
        )?;
        Ok(())
    }

    /// Every *marked* photo in a folder, as `(path, copy, marks)`.
    ///
    /// ⚠⚠ One query per rebuild, never one per grid cell: the grid draws sixty times a second
    /// over hundreds of thumbnails, and a query per cell would be a database round trip per frame
    /// per photo. Only marked rows come back, so an unmarked folder costs almost nothing.
    pub fn marks_in(&self, folder: &Path) -> Result<Vec<(PathBuf, u32, Marks)>, CatalogError> {
        let key = folder.to_string_lossy().to_string();
        let mut stmt = self.conn.prepare(
            "SELECT p.file_name, p.copy, p.rating, p.flag, p.label
             FROM photos p JOIN folders f ON f.id = p.folder_id
             WHERE f.path = ?1 AND (p.rating != 0 OR p.flag != 0 OR p.label != 0)",
        )?;
        let rows = stmt.query_map([&key], |r| {
            let name: String = r.get(0)?;
            let copy: u32 = r.get(1)?;
            let rating: i64 = r.get(2)?;
            let flag: i64 = r.get(3)?;
            let label: i64 = r.get(4)?;
            Ok((
                PathBuf::from(&key).join(name),
                copy,
                Marks {
                    rating: rating.clamp(0, Marks::MAX_RATING as i64) as u8,
                    flag: Flag::from_i64(flag),
                    label: label.clamp(0, Marks::MAX_LABEL as i64) as u8,
                },
            ))
        })?;
        Ok(rows.filter_map(Result::ok).collect())
    }
```

Create `crates/app/src/marks.rs`:

```rust
//! What a key does to a photo's marks, and which photos a star filter shows.
//!
//! ⚠ Pure, so both rules are testable without a window — and both are rules that are easy to get
//! subtly wrong: which key clears, and whether an unrated photo passes a "1 star or more" filter.

use catalog::db::{Flag, Marks};

/// What a culling key asks for.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum MarkAction {
    Rating(u8),
    Flag(Flag),
    Label(u8),
}

/// The culling key for `c`, if it is one.
///
/// ⚠⚠ **Library only.** `1`–`4` select rail tools in Develop, which is exactly where Lightroom
/// puts star ratings — the collision is resolved by view, because the rail exists only in Develop
/// and culling happens in the grid.
pub fn action_for(c: char) -> Option<MarkAction> {
    match c {
        // ⚠ `0` clears rather than being "zero stars": they are the same value, and calling it
        // "clear" is what makes the key discoverable.
        '0'..='5' => Some(MarkAction::Rating(c as u8 - b'0')),
        '6'..='9' => Some(MarkAction::Label(c as u8 - b'5')),
        'p' | 'P' => Some(MarkAction::Flag(Flag::Pick)),
        'x' | 'X' => Some(MarkAction::Flag(Flag::Reject)),
        'u' | 'U' => Some(MarkAction::Flag(Flag::None)),
        _ => None,
    }
}

/// Apply an action to a photo's marks.
pub fn apply(marks: Marks, action: MarkAction) -> Marks {
    match action {
        MarkAction::Rating(r) => Marks { rating: r, ..marks },
        MarkAction::Flag(f) => Marks { flag: f, ..marks },
        // ⚠ Pressing the same colour again clears it, so one key both sets and unsets. Without
        // this there is no way to remove a label at all.
        MarkAction::Label(l) => Marks {
            label: if marks.label == l { 0 } else { l },
            ..marks
        },
    }
}

/// Whether `marks` passes a "at least this many stars" filter.
///
/// ⚠ `min == 0` shows everything **including rejected photos**. Hiding rejects by default would
/// make them look deleted, and nothing here deletes anything.
pub fn passes(marks: Marks, min: u8) -> bool {
    marks.rating >= min
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn the_digits_map_to_stars_and_colours() {
        assert_eq!(action_for('0'), Some(MarkAction::Rating(0)));
        assert_eq!(action_for('5'), Some(MarkAction::Rating(5)));
        assert_eq!(action_for('6'), Some(MarkAction::Label(1)));
        assert_eq!(action_for('9'), Some(MarkAction::Label(4)));
    }

    #[test]
    fn the_flag_keys_are_lightrooms() {
        assert_eq!(action_for('p'), Some(MarkAction::Flag(Flag::Pick)));
        assert_eq!(action_for('x'), Some(MarkAction::Flag(Flag::Reject)));
        assert_eq!(action_for('u'), Some(MarkAction::Flag(Flag::None)));
        assert_eq!(action_for('P'), Some(MarkAction::Flag(Flag::Pick)));
    }

    #[test]
    fn an_unbound_key_does_nothing() {
        // ⚠ The discriminating half: a mapping that answered `Some` for everything would make
        // every keystroke in the grid rate a photo.
        for c in ['a', 'z', ' ', '-', 'G'] {
            assert_eq!(action_for(c), None, "{c:?} should not be a culling key");
        }
    }

    #[test]
    fn setting_a_rating_leaves_the_flag_and_label_alone() {
        // ⚠ Three orthogonal marks. A rating key that reset the flag would silently undo a cull.
        let before = Marks { rating: 1, flag: Flag::Pick, label: 3 };
        let after = apply(before, MarkAction::Rating(4));
        assert_eq!(after.rating, 4);
        assert_eq!(after.flag, Flag::Pick);
        assert_eq!(after.label, 3);
    }

    #[test]
    fn pressing_the_same_colour_twice_clears_it() {
        // ⚠ Without this there is no way to remove a label at all.
        let m = apply(Marks::default(), MarkAction::Label(2));
        assert_eq!(m.label, 2);
        assert_eq!(apply(m, MarkAction::Label(2)).label, 0);
        assert_eq!(apply(m, MarkAction::Label(3)).label, 3, "a different colour replaces");
    }

    #[test]
    fn zero_clears_the_rating() {
        let m = apply(Marks::default(), MarkAction::Rating(4));
        assert_eq!(apply(m, MarkAction::Rating(0)).rating, 0);
    }

    #[test]
    fn a_zero_star_filter_shows_everything_including_rejects() {
        // ⚠ Hiding rejected photos by default would make them look deleted, and nothing here
        // deletes anything.
        let rejected = Marks { rating: 0, flag: Flag::Reject, label: 0 };
        assert!(passes(rejected, 0));
        assert!(passes(Marks::default(), 0));
    }

    #[test]
    fn a_star_filter_is_a_minimum_not_an_exact_match() {
        // ⚠ "3 stars" means "3 or better". An exact match would hide your best photographs from
        // a filter meant to find them, which is the wrong way round to be wrong.
        let three = Marks { rating: 3, ..Marks::default() };
        let five = Marks { rating: 5, ..Marks::default() };
        assert!(passes(three, 3));
        assert!(passes(five, 3), "5 stars must pass a 3-star filter");
        assert!(!passes(three, 4));
    }
}

    /// Re-read the marks for whatever the Library is showing.
    ///
    /// ⚠ Reads the marks of every *folder* represented, because a collection spans folders. One
    /// query per folder, not per photo.
    fn reload_marks(&mut self) {
        let Some(cat) = &self.catalog else { return };
        let Some(lib) = self.library.as_ref() else {
            return;
        };
        let mut folders: Vec<PathBuf> = Vec::new();
        for e in &lib.entries {
            if let Some(dir) = e.id.path.parent() {
                if !folders.iter().any(|f| f == dir) {
                    folders.push(dir.to_path_buf());
                }
            }
        }
        let mut map = std::collections::HashMap::new();
        for dir in &folders {
            if let Ok(rows) = cat.marks_in(dir) {
                for (path, copy, m) in rows {
                    map.insert(PhotoId::new(path, copy), m);
                }
            }
        }
        if let Some(lib) = self.library.as_mut() {
            lib.marks = map;
        }
    }

    ///
    /// ⚠ The **selection**, not the active photo — the rule a paste, a preset and a sync already
    /// follow, and culling is where it matters most: select a run of frames and press `X`.
    fn apply_mark(&mut self, action: rustroom_app::marks::MarkAction) {
        let chosen: Vec<PhotoId> = self
            .library
            .as_ref()
            .map(|l| {
                l.selection
                    .iter()
                    .filter_map(|i| l.entries.get(i))
                    .map(|e| e.id.clone())
                    .collect()
            })
            .unwrap_or_default();
        if chosen.is_empty() {
            return;
        }
        if let Some(cat) = &self.catalog {
            for id in &chosen {
                let now = cat.marks(&id.path, id.copy).unwrap_or_default();
                let next = rustroom_app::marks::apply(now, action);
                let _ = cat.set_marks(&id.path, id.copy, next);
            }
        }
        self.reload_marks();
    }
```

        // ⚠ One derived `visible` list, composed from both filters — **not** a second filtering
