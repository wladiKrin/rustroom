**Goal:** A brush stroke painted with Auto Mask on covers only the pixels perceptually close to the colour that was under the brush centre when each dab was laid down, so a stroke along a sky stops at the ridge.

**Architecture:** Each stroke point stores a reference colour, sampled at paint time from the displayed frame and baked into `Edits`. The rasteriser multiplies each dab's positional alpha by a smoothstep gate on the Oklab distance between the pixel and that dab's reference, **before** the per-stroke `max`. `MaskStage` supplies the pixels from the buffer it is already handed; `BrushCache` refuses to prebuild a map for such a brush so that path is always taken.

**Tech Stack:** Rust workspace; `pipeline` (no GUI), `edit-model` (no `color` dependency), `crates/app` lib (no egui) and its `Rustroom` bin (egui 0.35).

**Spec:** `docs/superpowers/specs/2026-09-08-auto-mask-design.md`

```rust
//! M1 for auto-mask: how far apart are the space the reference is sampled in and the space the
//! pixel is compared in?
//!
//! The reference is sampled from the displayed frame — after the display rendering, the creative
//! look and the output transform. The pixel is `MaskStage`'s input, before all three. Both are
//! converted to Oklab, which is absolute, but the S-curve has moved one of them, and the auto-mask
//! gate is a *threshold*, so a systematic offset in L biases it.
//!
//! ⚠ Run on a NEUTRAL `Edits`. Every global tail stage is then inactive and not inserted, so the
//! prefix output *is* the mask input. That is what makes this measurable without a new seam.
//!
//! Run: `cargo run --release -p app --example auto_mask_space_probe <raw>`
use edit_model::Edits;
use pipeline::PipelineStage;

const MAX_DIM: usize = 1600;

fn main() {
    let path = std::env::args().nth(1).expect("usage: auto_mask_space_probe <raw>");
    let opts = raw_decode::DecodeOptions::linear_scene();
    let decoded = raw_decode::decode(std::path::Path::new(&path), opts).expect("decode");
    let img = decoded.image.downscale_to(MAX_DIM);
    let scale = pipeline::RenderScale::new(1.0);
    let edits = Edits::default();

    // End A: what `MaskStage` sees.
    let (prefix, tail) = pipeline::build_pipeline_split(&edits, scale);
    let mut base = img.clone();
    for stage in prefix.into_stages() {
        base = stage.apply(base);
    }

    // End B: what the canvas samples — the displayed frame.
    let mut shown = base.clone();
    for stage in tail.into_stages() {
        shown = stage.apply(shown);
    }

    // Compare the two, bucketed by the DISPLAYED lightness, because that is the axis the offset
    // is expected to vary along and a whole-image mean would hide it — the mistake this file
    // records for the HueSatMap and colour-grading work.
    let mut buckets = vec![(0f64, 0f64, 0usize); 10];
    for y in 0..base.height() {
        for x in 0..base.width() {
            let a = color::prophoto_to_oklab(base.pixel(x, y));
            // The displayed frame reaches the canvas as sRGB bytes, so round-trip it the same way
            // `sample_reference` will: encode, quantize, decode, then Oklab.
            let s = shown.pixel(x, y);
            let enc = [
                color::linear_to_srgb(s[0]).clamp(0.0, 1.0),
                color::linear_to_srgb(s[1]).clamp(0.0, 1.0),
                color::linear_to_srgb(s[2]).clamp(0.0, 1.0),
            ];
            let q = enc.map(|c| ((c * 255.0 + 0.5) as u8 as f32) / 255.0);
            let b = color::linear_srgb_to_oklab(q.map(color::srgb_to_linear));

            let bucket = ((b[0] * 10.0) as usize).min(9);
            let dl = (b[0] - a[0]) as f64;
            let dc = (((b[1] - a[1]).powi(2) + (b[2] - a[2]).powi(2)).sqrt()) as f64;
            buckets[bucket].0 += dl;
            buckets[bucket].1 += dc;
            buckets[bucket].2 += 1;
        }
    }

    println!("displayed L | mean dL (shown - base) | mean chroma distance | samples");
    for (i, (dl, dc, n)) in buckets.iter().enumerate() {
        if *n == 0 {
            continue;
        }
        println!(
            "{:.1}-{:.1}       | {:+.4}                 | {:.4}               | {}",
            i as f32 / 10.0,
            (i + 1) as f32 / 10.0,
            dl / *n as f64,
            dc / *n as f64,
            n
        );
    }
}
```

```rust
fn the_gate_is_continuous_rather_than_a_hard_cut() {
    // ⚠ The discriminating property, and the reason the gate is a smoothstep. A hard cut aliases
    // along a ridge, which is exactly where this tool is used. Sweeping for the largest step
    // between neighbouring samples is what a probe at two chosen points could not see.

    let ceil = auto_mask_ceiling(50.0);
    let mut prev = auto_mask_gate(r, r, ceil);
    let mut worst = 0.0f32;
    for i in 1..=400 {
        let d = ceil * 1.5 * i as f32 / 400.0;
        let g = auto_mask_gate([0.5 + d, 0.0, 0.0], r, ceil);
        worst = worst.max((g - prev).abs());
        prev = g;
    }
    assert!(worst < 0.05, "gate jumps by {worst}, which is a hard cut");
}
```

```rust
/// The smallest Oklab distance the gate will ever accept, at tolerance 0.
///
/// ⚠ Not zero. A tolerance of 0 must still paint the pixel the reference was sampled from; a
/// ceiling of 0 would both refuse it and make the ramp below divide by zero.
const AUTO_MASK_MIN_DELTA: f32 = 0.01;
/// The Oklab distance accepted at tolerance 100.
///
/// ⚠ **A starting value, swept in Task 12 against real photographs.** This file records the
/// vignette needing three revisions before its feel was right and the colour range mask's
/// constants surviving first contact; neither outcome is predictable from a spec.
const AUTO_MASK_MAX_DELTA: f32 = 0.35;
/// The fraction of the ceiling at which the gate starts falling off.
///
/// ⚠ The gate is a smoothstep rather than a cut because a hard boundary aliases along a ridge,
/// which is the case this tool exists for. It is also why no `EPS` guard is needed here, unlike
/// `RadialGradient::FEATHER_EPS`: the ramp's width is a positive constant fraction of a ceiling
/// that is itself never zero.
const AUTO_MASK_SOFT: f32 = 0.5;

/// The Oklab distance at which a pixel stops being painted, for a 0..=100 tolerance.
pub fn auto_mask_ceiling(tolerance: f32) -> f32 {
    let t = (tolerance / 100.0).clamp(0.0, 1.0);
    AUTO_MASK_MIN_DELTA + t * (AUTO_MASK_MAX_DELTA - AUTO_MASK_MIN_DELTA)
}

/// How much of a dab's coverage survives at a pixel, given its dab's reference colour.
///
/// Both arguments are **Oklab**, which is what makes the comparison meaningful across the two
/// spaces the ends come from — see the design doc's §3.
pub fn auto_mask_gate(pixel: [f32; 3], reference: [f32; 3], ceiling: f32) -> f32 {
    let d = ((pixel[0] - reference[0]).powi(2)
        + (pixel[1] - reference[1]).powi(2)
        + (pixel[2] - reference[2]).powi(2))
    .sqrt();
    let lo = ceiling * (1.0 - AUTO_MASK_SOFT);
    if d <= lo {
        return 1.0;
    }
    if d >= ceiling {
        return 0.0;
    }
    let q = (d - lo) / (ceiling - lo);
    1.0 - q * q * (3.0 - 2.0 * q)
}
```

```rust
/// A view of the buffer `MaskStage` was handed, addressed in **frame** coordinates.
///
/// ⚠ Under a region render the buffer *is* the region, so a frame coordinate is offset by the
/// region's origin. Out of range answers black rather than panicking — the rasterizer only asks
/// inside its own clip, which is the same rectangle, so that arm is unreachable in practice and
/// exists to keep the trait's totality promise.
struct BaseView<'a> {
    image: &'a ImageBuf,
    x0: usize,
    y0: usize,
}
impl crate::brush::BasePixels for BaseView<'_> {
    fn at(&self, x: usize, y: usize) -> [f32; 3] {
        if x < self.x0 || y < self.y0 {
            return [0.0; 3];
        }
        let (lx, ly) = (x - self.x0, y - self.y0);
        if lx >= self.image.width() || ly >= self.image.height() {
            return [0.0; 3];
        }
        self.image.pixel(lx, ly)
    }
}
```

```rust
/// Sample the displayed frame's colour at a frame pixel, for a brush dab's auto-mask reference.
///
/// `bytes` is the rendered frame as RGBA8 — the buffer `RustroomApp::readout_bytes` holds —
/// `w` x `h`, whose top-left corner sits at `origin` in frame coordinates. Returns
/// **display-referred sRGB 0..1**, which is what `BrushStroke::refs` stores.
///
/// ⚠ `None` when the point is outside the rendered area rather than a clamped edge pixel: at zoom
/// the region covers only part of the frame, and inventing a reference from the nearest edge would
/// gate a dab against a colour that is not under it. The dab then paints positionally, which is
/// the same degradation a short `refs` list produces — **one rule, not two**.
pub fn sample_reference(
    bytes: &[u8],
    w: usize,
    h: usize,
    origin: (usize, usize),
    frame_px: (usize, usize),
) -> Option<[f32; 3]> {
    let (x, y) = frame_px;
    if x < origin.0 || y < origin.1 {
        return None;
    }
    let (lx, ly) = (x - origin.0, y - origin.1);
    if lx >= w || ly >= h {
        return None;
    }
    let i = (ly * w + lx) * 4;
    let px = bytes.get(i..i + 3)?;
    Some([
        px[0] as f32 / 255.0,
        px[1] as f32 / 255.0,
        px[2] as f32 / 255.0,
    ])
}
```

```rust
            // capped grid (`tw` x `th`), the frame, and the readout buffer's rendered region. The
            // sampler is handed tint-grid coordinates and must land in the readout, so it goes

            // compares against the pre-mask buffer. That gap is measured as M1 and recorded as an
            // accepted caveat; it is feedback, not the photograph.
            struct TintBase<'a> {
                bytes: &'a [u8],
                w: usize,
                h: usize,
                origin: (usize, usize),
                /// Tint grid -> frame pixels.
                inv_scale: f32,
            }
            impl pipeline::brush::BasePixels for TintBase<'_> {
                fn at(&self, x: usize, y: usize) -> [f32; 3] {
                    let fx = (x as f32 * self.inv_scale) as usize;
                    let fy = (y as f32 * self.inv_scale) as usize;
                    match rustroom_app::brush_tool::sample_reference(
                        self.bytes, self.w, self.h, self.origin, (fx, fy),
                    ) {
                        // ⚠ Decoded to linear sRGB and then to the working space's own primaries,
                        // because `BasePixels` promises linear ProPhoto — the rasterizer converts
                        // what it is given with `prophoto_to_oklab`.
                        Some(c) => color::srgb_to_prophoto(c.map(color::srgb_to_linear)),
                        // ⚠ Outside the rendered region there is no data, so the gate cannot be
                        // evaluated. Returning the reference itself would paint; returning
                        // something far from it would not. Neither is honest, so the tint falls
                        // back to positional there — see step 3.
                        None => [0.0; 3],
                    }
                }
            }
```
