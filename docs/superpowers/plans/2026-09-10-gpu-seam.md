**Goal:** One pipeline stage runs as a `wgpu` compute shader, is proven equivalent to the CPU
stage by a harness, and the round-trip cost becomes a measurement in the repo.

**Architecture:** A new `gpu-pipeline` crate depends on `pipeline` and implements
`pipeline::PipelineStage` for a GPU exposure stage — using the trait designed as the GPU seam on
day one as exactly that. Nothing depends on `gpu-pipeline`, so `pipeline`, the CLI and the 63
goldens gain no `wgpu`. Every GPU failure degrades silently to the CPU stage.

**Tech Stack:** `wgpu` 29, `pollster` 0.4, `bytemuck` 1 — all already in the workspace tree via
eframe. WGSL for the shader.

**Spec:** `docs/superpowers/specs/2026-09-10-gpu-seam-design.md`

⚠⚠ **This slice is ~6 ms SLOWER per render, by measurement, and nothing in the app uses it.**
That is the design, not a defect — see spec §1 and §8. Do not "fix" it by wiring it in as a
default.

```rust
//! The shared `wgpu` device.

/// A `wgpu` device and queue, shared by every GPU stage.
///
/// ⚠⚠ **`new` returns `Option`, never `Result`.** A machine with no usable adapter is not an
/// error anybody should have to handle — it means the CPU path, which must always work. The same
/// posture `SettingsStore::load` and the optional `Catalog` already take.
///
/// ⚠ Creation costs 15–17 ms, so this is built **once** and shared behind an `Arc`. One per stage
/// would dwarf the work it enables.
///
/// ⚠ `Send + Sync` matters rather than being incidental: rendering happens on the render worker
/// thread, not the UI thread. `wgpu`'s `Device` and `Queue` are both, so this is free.
#[derive(Debug)]
pub struct GpuContext {
    pub(crate) device: wgpu::Device,
    pub(crate) queue: wgpu::Queue,
    adapter_name: String,
    backend: String,
}

impl GpuContext {
    /// Acquire an adapter and device, or `None` if this machine has none we can use.
    pub fn new() -> Option<Self> {
        let instance = wgpu::Instance::default();
        let adapter = pollster::block_on(
            instance.request_adapter(&wgpu::RequestAdapterOptions::default()),
        )
        .ok()?;
        let info = adapter.get_info();
        let (device, queue) =
            pollster::block_on(adapter.request_device(&wgpu::DeviceDescriptor::default())).ok()?;
        Some(Self {
            device,
            queue,
            adapter_name: info.name,
            backend: format!("{:?}", info.backend),
        })
    }

    /// The adapter's name, for the probe and for a future Settings readout.
    pub fn adapter_name(&self) -> &str {
        &self.adapter_name
    }

    /// The backend in use — `Metal`, `Vulkan`, `Dx12`, …
    pub fn backend(&self) -> &str {
        &self.backend
    }
}
```

⚠ `request_adapter` and `request_device` return `Result` in `wgpu` 29 (they returned `Option` in
older versions). Both are awaited through `pollster::block_on`, which is what every `wgpu` example
does for a headless device.

#[cfg(test)]
mod tests {
    use super::*;
    use pipeline::PipelineStage;
    use std::sync::Arc;

    fn ctx() -> Arc<GpuContext> {
        Arc::new(GpuContext::new().expect("a GPU is required for these tests"))
    }

    /// ⚠⚠ **Negative samples and samples above 1.0 are the point of this fixture.** The working
    /// space is scene-referred, so both occur in every real photograph — and a shader that
    /// clamped would be correct on a 0..1 chart while silently destroying every highlight. The
    /// same trap `ProfileHueSatMap`'s `v` and the display rendering's LUT index each documented.
    fn awkward(w: usize, h: usize) -> ImageBuf {
        let n = w * h * 3;
        let data: Vec<f32> = (0..n)
            .map(|i| match i % 7 {
                0 => -0.25,
                1 => 0.0,
                2 => 0.5,
                3 => 1.0,
                4 => 4.0,
                5 => f32::MIN_POSITIVE,
                _ => (i % 997) as f32 / 997.0,
            })
            .collect();
        ImageBuf::from_vec(w, h, data)
    }

    #[test]
    fn the_gpu_matches_the_cpu_bit_for_bit() {
        // ⚠ **Exact, not within a tolerance.** The gain is computed CPU-side and passed as a
        // uniform, so the shader does one multiply and no `exp2` — the probe measured worst
        // difference 0. A tolerance here would hide the plumbing bug this test exists to catch.
        let img = awkward(64, 48);
        let cpu = pipeline::ExposureStage::new(1.3).apply(img.clone());
        let gpu = GpuExposureStage::new(1.3, ctx()).apply(img);
        assert_eq!(
            (gpu.width(), gpu.height()),
            (cpu.width(), cpu.height()),
            "a wrong stride or a truncated readback shows up as the wrong size"
        );
        assert_eq!(
            gpu.data(),
            cpu.data(),
            "exposure is exactly representable on both; any difference here is plumbing"
        );
    }

    #[test]
    fn a_dispatch_larger_than_65535_workgroups_still_works() {
        // ⚠⚠ 65535 is the per-dimension workgroup limit. At 64 threads per group that is
        // 4,194,240 pixels, so this image is deliberately BIGGER. A 1D dispatch passes every
        // small fixture and fails on the first real photograph — the bug already hit by hand
        // while probing, which is why it is a test rather than a memory.
        let (w, h) = (2500, 1700);
        assert!(w * h > 65535 * 64, "fixture check: the limit must be exceeded");
        let img = awkward(w, h);
        let cpu = pipeline::ExposureStage::new(-0.5).apply(img.clone());
        let gpu = GpuExposureStage::new(-0.5, ctx()).apply(img);
        assert_eq!(gpu.data(), cpu.data(), "a large frame must dispatch correctly");
    }

    #[test]
    fn a_gpu_failure_falls_back_to_the_cpu_result() {
        // ⚠⚠ `apply` returns `ImageBuf`, not `Result` — the trait has no failure channel — so a
        // GPU error MUST degrade silently. The assertion is that the output equals the CPU
        // stage's EXACTLY: asserting merely that it is non-empty would pass against a fallback
        // that returned the input unchanged.
        let img = awkward(16, 12);
        let cpu = pipeline::ExposureStage::new(2.0).apply(img.clone());
        let stage = GpuExposureStage::new(2.0, ctx());
        let out = stage.apply_with(img, |_, _| None);
        assert_eq!(out.data(), cpu.data(), "the fallback must be the CPU stage's own answer");
    }

    #[test]
    fn the_stage_is_named_like_the_cpu_one() {
        // The name is what `Pipeline::stage_names` reports and what order-asserting tests match
        // on, so a GPU substitution must not change it.
        assert_eq!(
            GpuExposureStage::new(0.0, ctx()).name(),
            pipeline::ExposureStage::new(0.0).name()
        );
    }
}

```rust
//! Exposure as a compute shader — the first stage across the seam.

use crate::GpuContext;
use core_image::ImageBuf;
use pipeline::PipelineStage;
use std::sync::Arc;

/// Threads per workgroup. 64 is one Metal SIMD-group pair and a common sweet spot; the arithmetic
/// below does not depend on the value.
const WORKGROUP: u32 = 64;

/// The per-dimension workgroup limit every `wgpu` backend guarantees.
///
/// ⚠⚠ **This is why the dispatch is 2D.** A naive per-float 1D dispatch at the fit rung needs
/// `1600 × 1068 × 3 / 64 = 80,100` groups and **fails validation already**; per pixel it is
/// 26,700, which fits — but a 26 Mpx native rung needs 407,000, so 2D is required from the start
/// rather than retrofitted.
const MAX_GROUPS_PER_DIM: u32 = 65535;

/// One multiply per channel. The gain arrives as a uniform.
///
/// ⚠ **No `exp2` in the shader**, deliberately: `2^ev` is computed CPU-side, so the GPU does
/// arithmetic that is exactly representable and the result is bit-identical to the CPU stage.
/// That is what makes a divergence here mean "plumbing bug" rather than "float drift".
///
/// ⚠ `row_groups` recovers the linear pixel index from the 2D dispatch. Both dimensions stay
/// under [`MAX_GROUPS_PER_DIM`] at any resolution this app can produce.
const SHADER: &str = r#"
struct Params {
    gain: f32,
    pixels: u32,
    row_groups: u32,
    _pad: u32,
};
@group(0) @binding(0) var<storage, read_write> data: array<f32>;
@group(0) @binding(1) var<uniform> params: Params;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) id: vec3<u32>) {
    let pixel = id.y * (params.row_groups * 64u) + id.x;
    if (pixel >= params.pixels) { return; }
    let p = pixel * 3u;
    data[p] = data[p] * params.gain;
    data[p + 1u] = data[p + 1u] * params.gain;
    data[p + 2u] = data[p + 2u] * params.gain;
}
"#;

/// Exposure, on the GPU.
///
/// ⚠ Holds a CPU stage of its own rather than recomputing the gain, so the fallback path is the
/// real thing and cannot drift from it.
pub struct GpuExposureStage {
    factor: f32,
    cpu: pipeline::ExposureStage,
    ctx: Arc<GpuContext>,
}

impl GpuExposureStage {
    pub fn new(ev: f32, ctx: Arc<GpuContext>) -> Self {
        Self {
            factor: 2.0f32.powf(ev),
            cpu: pipeline::ExposureStage::new(ev),
            ctx,
        }
    }

    /// `apply`, with the GPU attempt injected.
    ///
    /// ⚠⚠ **This split exists so the fallback is testable.** Without it the CPU path could only
    /// be reached by unplugging a GPU, which is not a test.
    pub fn apply_with(
        &self,
        image: ImageBuf,
        run: impl Fn(&GpuContext, &ImageBuf) -> Option<Vec<f32>>,
    ) -> ImageBuf {
        let (w, h) = (image.width(), image.height());
        match run(&self.ctx, &image) {
            Some(data) => ImageBuf::from_vec(w, h, data),
            None => self.cpu.apply(image),
        }
    }

    /// Run the shader, or `None` on any GPU failure at all.
    fn run(&self, ctx: &GpuContext, image: &ImageBuf) -> Option<Vec<f32>> {
        let src = image.data();
        let pixels = (image.width() * image.height()) as u32;
        if pixels == 0 {
            return None;
        }
        let bytes = std::mem::size_of_val(src) as u64;
        let device = &ctx.device;

        let module = device.create_shader_module(wgpu::ShaderModuleDescriptor {
            label: Some("exposure"),
            source: wgpu::ShaderSource::Wgsl(SHADER.into()),
        });

        let storage = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("exposure-data"),
            size: bytes,
            usage: wgpu::BufferUsages::STORAGE
                | wgpu::BufferUsages::COPY_DST
                | wgpu::BufferUsages::COPY_SRC,
            mapped_at_creation: false,
        });
        let readback = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("exposure-readback"),
            size: bytes,
            usage: wgpu::BufferUsages::COPY_DST | wgpu::BufferUsages::MAP_READ,
            mapped_at_creation: false,
        });

        let total_groups = pixels.div_ceil(WORKGROUP);
        let row_groups = total_groups.min(MAX_GROUPS_PER_DIM);
        let col_groups = total_groups.div_ceil(row_groups);
        let params: [u32; 4] = [self.factor.to_bits(), pixels, row_groups, 0];
        let uniform = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("exposure-params"),
            size: 16,
            usage: wgpu::BufferUsages::UNIFORM | wgpu::BufferUsages::COPY_DST,
            mapped_at_creation: false,
        });
        ctx.queue.write_buffer(&uniform, 0, bytemuck::cast_slice(&params));
        ctx.queue.write_buffer(&storage, 0, bytemuck::cast_slice(src));

        let layout = device.create_bind_group_layout(&wgpu::BindGroupLayoutDescriptor {
            label: Some("exposure-layout"),
            entries: &[
                wgpu::BindGroupLayoutEntry {
                    binding: 0,
                    visibility: wgpu::ShaderStages::COMPUTE,
                    ty: wgpu::BindingType::Buffer {
                        ty: wgpu::BufferBindingType::Storage { read_only: false },
                        has_dynamic_offset: false,
                        min_binding_size: None,
                    },
                    count: None,
                },
                wgpu::BindGroupLayoutEntry {
                    binding: 1,
                    visibility: wgpu::ShaderStages::COMPUTE,
                    ty: wgpu::BindingType::Buffer {
                        ty: wgpu::BufferBindingType::Uniform,
                        has_dynamic_offset: false,
                        min_binding_size: None,
                    },
                    count: None,
                },
            ],
        });
        let bind = device.create_bind_group(&wgpu::BindGroupDescriptor {
            label: Some("exposure-bind"),
            layout: &layout,
            entries: &[
                wgpu::BindGroupEntry { binding: 0, resource: storage.as_entire_binding() },
                wgpu::BindGroupEntry { binding: 1, resource: uniform.as_entire_binding() },
            ],
        });
        // ⚠ `wgpu` 29: `bind_group_layouts` is `&[Option<&BindGroupLayout>]`, and the old
        // `push_constant_ranges` field is now `immediate_size`.
        let pipeline_layout = device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor {
            label: Some("exposure-pipeline-layout"),
            bind_group_layouts: &[Some(&layout)],
            immediate_size: 0,
        });
        let compute = device.create_compute_pipeline(&wgpu::ComputePipelineDescriptor {
            label: Some("exposure-pipeline"),
            layout: Some(&pipeline_layout),
            module: &module,
            entry_point: Some("main"),
            compilation_options: Default::default(),
            cache: None,
        });

        let mut enc = device.create_command_encoder(&Default::default());
        {
            let mut pass = enc.begin_compute_pass(&Default::default());
            pass.set_pipeline(&compute);
            pass.set_bind_group(0, &bind, &[]);
            pass.dispatch_workgroups(row_groups, col_groups, 1);
        }
        enc.copy_buffer_to_buffer(&storage, 0, &readback, 0, bytes);
        ctx.queue.submit(Some(enc.finish()));

        let slice = readback.slice(..);
        let (tx, rx) = std::sync::mpsc::channel();
        slice.map_async(wgpu::MapMode::Read, move |r| {
            let _ = tx.send(r);
        });
        // ⚠ `wgpu` 29's `PollType::Wait` is a struct variant; `None` waits for the most recent
        // submission.
        let _ = device.poll(wgpu::PollType::Wait { submission_index: None, timeout: None });
        rx.recv().ok()?.ok()?;
        let out: Vec<f32> = bytemuck::cast_slice(&slice.get_mapped_range()).to_vec();
        readback.unmap();
        Some(out)
    }
}

impl PipelineStage for GpuExposureStage {
    /// ⚠ The **same** name as the CPU stage. `Pipeline::stage_names` is what six order-asserting
    /// tests match on, so a GPU substitution must be invisible to them.
    fn name(&self) -> &'static str {
        "exposure"
    }

    fn apply(&self, image: ImageBuf) -> ImageBuf {
        self.apply_with(image, |ctx, img| self.run(ctx, img))
    }
}
```

//! Comparing a GPU render against the CPU one.
//!
//! ⚠⚠ **This harness is what protects the shipped path once a GPU render is the default.** The 63
//! goldens keep testing the CPU pipeline byte-for-byte and never move (user's call, 2026-09-10),
//! so from M8.3b onward they no longer test what ships — this does. It therefore has to be as
//! trustworthy as they are, which is why its own tests use awkward inputs rather than pretty ones.

use core_image::ImageBuf;

/// How far two renders of the same input differ.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Divergence {
    /// The largest single-sample difference, in **8-bit display levels**.
    pub worst_levels: f32,
    /// How many samples differ at all.
    pub differing: usize,
    /// How many samples were compared.
    pub total: usize,
}

impl Divergence {
    /// True when the two renders are bit-identical.
    pub fn is_exact(&self) -> bool {
        self.differing == 0 && self.worst_levels == 0.0
    }

    /// The share of samples that differ, as a percentage.
    pub fn differing_percent(&self) -> f64 {
        if self.total == 0 {
            return 0.0;
        }
        self.differing as f64 / self.total as f64 * 100.0
    }
}

/// Compare two renders of the same input.
///
/// ⚠ **In 8-bit display levels, not raw linear floats.** A linear difference near black reads as
/// enormous while being invisible, and a judgement about a photograph is made in levels — the
/// correction the Whites slider's weights and the M8.4 demosaic comparison each needed.
///
/// ⚠ A size mismatch reports **infinite** divergence rather than comparing what overlaps. Zipping
/// two different lengths silently ignores the tail, so a truncated GPU readback would look like
/// agreement.
pub fn compare(a: &ImageBuf, b: &ImageBuf) -> Divergence {
    if a.width() != b.width() || a.height() != b.height() || a.data().len() != b.data().len() {
        return Divergence {
            worst_levels: f32::INFINITY,
            differing: usize::MAX,
            total: 0,
        };
    }
    let mut worst = 0.0f32;
    let mut differing = 0usize;
    for (x, y) in a.data().iter().zip(b.data()) {
        if x != y {
            differing += 1;
            let d = (color::linear_to_srgb(*x) - color::linear_to_srgb(*y)).abs() * 255.0;
            worst = worst.max(d);
        }
    }
    Divergence {
        worst_levels: worst,
        differing,
        total: a.data().len(),
    }
}
```

//! M8.3a's measurement: what does crossing the seam cost, and do the two paths agree?
//!
//! ⚠⚠ **This exists so the ~6 ms round trip is a number in the repo rather than a claim in a
//! document.** M8.2's spec had to be corrected because a projected figure was quoted as an
//! achieved one; `bench_thumb_cache` and `demosaic_foliage` are the precedent.
//!
//! ⚠ It is also the only END-TO-END proof this slice has, because nothing in the app uses the GPU
//! path (spec §8). A probe is not the app, and that distinction is real.
//!
//! `cargo run --release -p gpu-pipeline --example gpu_equivalence <w> <h>`

use gpu_pipeline::{compare, GpuContext, GpuExposureStage};
use pipeline::PipelineStage;
use std::sync::Arc;
use std::time::Instant;

fn ms(t: Instant) -> f64 {
    t.elapsed().as_secs_f64() * 1000.0
}

fn main() {
    let mut a = std::env::args().skip(1);
    let w: usize = a.next().and_then(|s| s.parse().ok()).unwrap_or(1600);
    let h: usize = a.next().and_then(|s| s.parse().ok()).unwrap_or(1068);

    let t = Instant::now();
    let Some(ctx) = GpuContext::new() else {
        println!("no usable GPU adapter — the CPU path is what would run");
        return;
    };
    println!(
        "adapter: {} ({})   init {:.1} ms",
        ctx.adapter_name(),
        ctx.backend(),
        ms(t)
    );
    let ctx = Arc::new(ctx);

    // ⚠ Scene-referred values, including above 1.0: a shader that clamped would look correct on a
    // 0..1 fixture and destroy every highlight on a real photograph.
    let n = w * h * 3;
    let data: Vec<f32> = (0..n).map(|i| (i % 997) as f32 / 500.0 - 0.1).collect();
    let img = core_image::ImageBuf::from_vec(w, h, data);
    println!(
        "buffer {w}x{h}x3 f32 = {:.1} MB",
        (n * 4) as f64 / 1048576.0
    );

    let cpu_stage = pipeline::ExposureStage::new(1.3);
    let gpu_stage = GpuExposureStage::new(1.3, ctx);

    println!("\n  round   cpu        gpu        ratio");
    let mut last = None;
    for round in 0..3 {
        let t = Instant::now();
        let cpu = cpu_stage.apply(img.clone());
        let cpu_ms = ms(t);

        let t = Instant::now();
        let gpu = gpu_stage.apply(img.clone());
        let gpu_ms = ms(t);

        println!("  {round}       {cpu_ms:6.2} ms   {gpu_ms:6.2} ms   {:.1}x slower", gpu_ms / cpu_ms);
        last = Some((cpu, gpu));
    }

    let (cpu, gpu) = last.expect("three rounds ran");
    let d = compare(&cpu, &gpu);
    println!("\n  divergence: worst {:.4} levels, {} of {} samples ({:.4}%)",
        d.worst_levels, d.differing, d.total, d.differing_percent());
    println!(
        "  {}",
        if d.is_exact() {
            "BIT-EXACT — as expected: the gain is a uniform, so the shader does one multiply"
        } else {
            "⚠ NOT bit-exact. Exposure should be. Suspect the plumbing, not float drift."
        }
    );
}
```
