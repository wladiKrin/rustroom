# M8.11 — a mask's coverage and blend on the GPU: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **⚠ Conventions that are not negotiable:** commit messages carry **no `Co-Authored-By` trailer**; work on the branch `m8.11-mask-gpu`; **never push**. The gate is `cargo fmt --all --check`, `cargo clippy --all-targets --all-features -- -D warnings` and `cargo test --workspace`, **each exit code read from its own command** — `cargo clippy … | grep` reports *grep's* status, and this repo has already shipped a commit that way.

**Goal:** A mask's coverage and blend run on the GPU, so an accelerated mask is one round trip end to end and stops splitting the tail.

**Architecture:** A single `GpuMaskStage` replaces `MaskStage` in the tail via `accelerate`. It asks for `4 + max(sub.scratch_planes())` scratch planes, keeps the first four (3 for `base`, 1 for coverage), lends the rest to its sub-stages' own `encode`, and records seed → coverage → sub-stages → blend in one compute pass. `MaskStage` is untouched and serves as the CPU twin and the equivalence reference.

**Tech Stack:** Rust, `wgpu` 29 compute shaders (WGSL), `rayon` on the CPU side, the existing `GpuStage`/`GpuChain`/`GpuContext` seam.

**Spec:** `docs/superpowers/specs/2026-09-15-mask-gpu-design.md`

```rust
//! ⚠⚠ Extracted rather than copied. `output_transform` carried this inline and a luminance range
```

```rust
/// Run `linear_to_srgb` over `probes` on the GPU and read the results back.
///
/// ⚠ Test-only. It exists so the agreement test can compare behaviour rather than shader text.
#[cfg(test)]
pub(crate) fn run_probe(ctx: &crate::GpuContext, probes: &[f32]) -> Vec<f32> {
    // One pixel per probe, the value in all three channels; read channel 0 back.
    let img = core_image::ImageBuf::from_vec(
        probes.len(),
        1,
        probes.iter().flat_map(|p| [*p, *p, *p]).collect(),
    );
    let shader = format!(
        "{SRGB_WGSL}\n\
         struct P {{ row_groups: u32, pixels: u32, _pad0: u32, _pad1: u32 }};\n\
         @group(0) @binding(0) var<storage, read_write> img: array<f32>;\n\
         @group(0) @binding(1) var<uniform> params: P;\n\
         @compute @workgroup_size(64)\n\
         fn main(@builtin(workgroup_id) wg: vec3<u32>, @builtin(local_invocation_id) li: vec3<u32>) {{\n\
           let i = (wg.y * params.row_groups + wg.x) * 64u + li.x;\n\
           if (i >= params.pixels) {{ return; }}\n\
           let b = i * 3u;\n\
           img[b] = linear_to_srgb(img[b]);\n\
         }}"
    );
    let gpu = crate::GpuImage::new(ctx, img.width(), img.height()).expect("probe image");
    gpu.upload(ctx, &img);
    let (row_groups, _) = crate::dispatch::Dispatch::grid(gpu.pixels());
    let mut params = Vec::new();
    params.extend_from_slice(&row_groups.to_le_bytes());
    params.extend_from_slice(&gpu.pixels().to_le_bytes());
    params.extend_from_slice(&0u32.to_le_bytes());
    params.extend_from_slice(&0u32.to_le_bytes());
    crate::run_single_dispatch(ctx, &gpu, "srgb-probe", &shader, &params);
    let out = gpu.download(ctx).expect("download");
    out.chunks_exact(3).map(|c| c[0]).collect()
}
```

`crates/gpu-pipeline/src/mask_wgsl.rs` builds the shader. The three entry points for this task:

```rust
pub(crate) const SEED: &str = r#"
// ⚠⚠ A dispatch, not `copy_buffer_to_buffer`: the latter is an ENCODER operation and cannot run
// inside a compute pass. `GpuLensCorrectionStage` seeds its planes the same way and for the same
// reason. This is the mask's clone, on the GPU.
@compute @workgroup_size(64)
fn seed(@builtin(workgroup_id) wg: vec3<u32>, @builtin(local_invocation_id) li: vec3<u32>) {
    let i = (wg.y * params.row_groups + wg.x) * 64u + li.x;
    if (i >= params.pixels) { return; }
    let b = i * 3u;
    base_r[i] = img[b];
    base_g[i] = img[b + 1u];
    base_b[i] = img[b + 2u];
}
"#;

pub(crate) const BLEND: &str = r#"
// out = base + (adjusted - base) * coverage, per channel.
//
// ⚠ A multiply-add the GPU fuses, which is M8.3m's recorded divergence class: the GPU rounds once
// where the CPU rounds twice, so it is the MORE accurate of the two. Do not "fix" it.
@compute @workgroup_size(64)
fn blend(@builtin(workgroup_id) wg: vec3<u32>, @builtin(local_invocation_id) li: vec3<u32>) {
    let i = (wg.y * params.row_groups + wg.x) * 64u + li.x;
    if (i >= params.pixels) { return; }
    let c = cov[i];
    let b = i * 3u;
    img[b]      = base_r[i] + (img[b]      - base_r[i]) * c;
    img[b + 1u] = base_g[i] + (img[b + 1u] - base_g[i]) * c;
    img[b + 2u] = base_b[i] + (img[b + 2u] - base_b[i]) * c;
}
"#;
```

The painted-coverage entry point, which reads an uploaded `CoverageMap`:

```rust
pub(crate) const PAINTED: &str = r#"
// ⚠⚠ Mirrors `CoverageMap::at` EXACTLY, box and `outside` value included. That `outside` field is
// load-bearing and its absence was a real bug found in use: an inverted brush covers the whole
// frame except what was painted, so returning 0 outside the box confined the inversion to a
// rectangle around the strokes.
//
// ⚠ Samples are packed 4-per-u32 because WGSL has no u8. At rung 3200 that is 6.5 MB rather than
// 26 MB as f32 — see the spec's §5.5 for why the plane crosses the bus at all.
fn painted_at(fx: u32, fy: u32) -> f32 {
    if (fx < params.box_x0 || fy < params.box_y0
        || fx >= params.box_x0 + params.box_w || fy >= params.box_y0 + params.box_h) {
        return f32(params.outside) / 255.0;
    }
    let idx = (fy - params.box_y0) * params.box_w + (fx - params.box_x0);
    let word = packed[idx >> 2u];
    let byte = (word >> ((idx & 3u) * 8u)) & 255u;
    return f32(byte) / 255.0;
}

@compute @workgroup_size(64)
fn coverage(@builtin(workgroup_id) wg: vec3<u32>, @builtin(local_invocation_id) li: vec3<u32>) {
    let i = (wg.y * params.row_groups + wg.x) * 64u + li.x;
    if (i >= params.pixels) { return; }
    // ⚠ FRAME coordinates, never region-relative — the note `MaskStage::apply` already carries.
    // A region-relative index slides the mask as you pan.
    let x = i % params.w;
    let y = i / params.w;
    cov[i] = clamp(painted_at(params.x0 + x, params.y0 + y), 0.0, 1.0);
}
"#;
```

`crates/gpu-pipeline/src/mask.rs` holds the stage. Its `scratch_planes` and slice arithmetic are the load-bearing part:

```rust
impl GpuStage for GpuMaskStage {
    fn name(&self) -> &'static str { "mask" }

    /// ⚠⚠ **Four for this stage plus the most any sub-stage wants**, because `GpuChain` lends the
    /// SAME planes to every stage — its own doc says *"nothing written here survives the call"*.
    /// A `base` copy parked in shared planes would be clobbered by the first sub-stage wanting
    /// scratch (sharpening 4, local contrast 5, NR 4). Asking for the total and lending the tail
    /// onward keeps that contract intact while giving the sub-stages the shape they expect.
    fn scratch_planes(&self) -> usize {
        4 + self.subs.iter().map(|s| s.scratch_planes()).max().unwrap_or(0)
    }

    fn encode(&self, ctx: &GpuContext, pass: &mut wgpu::ComputePass, img: &GpuImage, scratch: &[wgpu::Buffer]) {
        // 1. seed: img -> scratch[0..3]
        // 2. coverage: -> scratch[3]
        // 3. sub-stages, each against `img`, lent `&scratch[4..]`
        // 4. blend: img = scratch[0..3] + (img - scratch[0..3]) * scratch[3]
    }

    fn cpu(&self) -> &dyn PipelineStage { &self.cpu }
}
```

⚠⚠ **The `&scratch[4..]` offset is the single most dangerous line in this milestone.** Handing the sub-stages the *whole* slice lets them write `base`, and the result is a plausible photograph blended against the wrong thing. Task 12's sabotage list names it explicitly.

Follow `crates/gpu-pipeline/src/sharpen.rs`'s `encode` for the multi-entry-point bind-group pattern: one `ctx.cache.program(..)` lookup returning several pipelines, one bind group, `set_pipeline` + `dispatch_workgroups` per pass in order.

```rust
pub(crate) const ANALYTIC: &str = r#"
fn cov_linear(u: f32, v: f32, aspect: f32, from: vec2<f32>, to: vec2<f32>, invert: u32) -> f32 {
    // ⚠ Work in units of frame HEIGHT, where both axes have the same pixel scale. The aspect is
    // not decoration here: a projection needs a metric, and raw normalised space is anisotropic,
    // so a diagonal gradient's iso-lines would visibly skew without it.
    let a = vec2<f32>(from.x * aspect, from.y);
    let b = vec2<f32>(to.x * aspect, to.y);
    let d = b - a;
    let len2 = dot(d, d);
    // ⚠ Full coverage rather than NaN. The alternative reaches the blend and paints garbage.
    if (len2 <= 1.1920929e-7) { return select(1.0, 0.0, invert == 1u); }
    let t = clamp((((u * aspect) - a.x) * d.x + (v - a.y) * d.y) / len2, 0.0, 1.0);
    return select(t, 1.0 - t, invert == 1u);
}

fn cov_radial(u: f32, v: f32, center: vec2<f32>, radius: vec2<f32>, feather: f32, invert: u32) -> f32 {
    // ⚠⚠ `aspect` is deliberately absent — see the CPU's own note. Adding it is the "fix" the
    // guard exists to prevent.
    var c = 0.0;
    if (radius.x > 1.1920929e-7 && radius.y > 1.1920929e-7) {
        let d = length(vec2<f32>((u - center.x) / radius.x, (v - center.y) / radius.y));
        let f = clamp(feather / 100.0, 0.0, 1.0);
        if (f <= FEATHER_EPS) {
            c = select(0.0, 1.0, d <= 1.0);
        } else {
            // ⚠ Smoothstep rather than a linear ramp: a linear ramp in radial distance leaves a
            // visible crease ring where the derivative jumps.
            let t = clamp((1.0 - d) / f, 0.0, 1.0);
            c = t * t * (3.0 - 2.0 * t);
        }
    }
    return select(c, 1.0 - c, invert == 1u);
}
"#;
```

⚠ `f32::EPSILON` is `1.1920929e-7`; substitute it with `.replace("EPSILON", &format!("{:?}", f32::EPSILON))` rather than typing the digits, so the two cannot drift.

```rust
pub(crate) const COLOUR: &str = r#"
// ⚠⚠ WGSL has no `rem_euclid`. `x % 360` is sign-preserving and therefore WRONG for a negative
// hue; this is the Euclidean form, which is what `ColourRange::coverage_at` uses on both its span
// and its offset so the wrapped and unwrapped cases are ONE expression with no branch.
fn rem_euclid_360(x: f32) -> f32 {
    return x - floor(x / 360.0) * 360.0;
}

fn cov_colour(rgb: vec3<f32>, low: f32, high: f32, feather: f32,
              min_chroma: f32, invert: u32) -> f32 {
    let lab = prophoto_to_oklab(rgb);
    let hue = degrees(atan2(lab.z, lab.y));
    // ⚠ Chroma is NOT clamped and must not be — it is the gate's own input, and a wide-gamut
    // colour legitimately reads above anything sRGB can express.
    let chroma = length(vec2<f32>(lab.y, lab.z));

    let span = rem_euclid_360(high - low);
    let offset = rem_euclid_360(hue - low);
    let w = clamp(feather / 100.0, 0.0, 1.0) * COL_FEATHER_SCALE;
    var band = 0.0;
    if (w <= COL_FEATHER_EPS) {
        band = select(0.0, 1.0, offset <= span);
    } else {
        let past = max(offset - span, 0.0);
        let before = max(360.0 - offset, 0.0);
        let t = clamp(1.0 - min(past, before) / w, 0.0, 1.0);
        band = t * t * (3.0 - 2.0 * t);
    }
    var gate = clamp((chroma - min_chroma) / COL_CHROMA_FADE, 0.0, 1.0);
    gate = gate * gate * (3.0 - 2.0 * gate);
    let c = band * gate;
    return select(c, 1.0 - c, invert == 1u);
}
"#;
```
