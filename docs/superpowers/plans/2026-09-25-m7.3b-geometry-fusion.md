# M7.3b — Geometry fusion and prefix reorder: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One resample for orientation, perspective, straighten and crop, and a prefix reordered to
`NR → lens → dehaze → spots → geometry → masked capture`.

**Architecture:** `GeometryStage` gains an optional `Perspective` (`with_perspective`). When the
perspective is active, one fused inverse map gathers each output pixel. When it is not, today's code
runs byte for byte. `PerspectiveStage` and `PrefixStepKey::Perspective` go. Spots move ahead of
perspective, and the app maps them through a new lib type `pipeline::brush::SpotMap` =
`FrameMap` ∘ homography.

**Tech Stack:** Rust, rayon, egui (overlay only). Spec:
`docs/superpowers/specs/2026-09-25-m7.3b-geometry-fusion-design.md`.

**Gate commands** (one invocation mode per session):
```
cargo test --workspace <filter>
CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --check
```
PKG_CONFIG_PATH must include the homebrew libraw/lcms dirs (see CLAUDE.md).

```rust
//! The fused inverse map — orientation, perspective, straighten and crop in ONE resample.
pub(super) struct FusedMap { x0: f32, y0: f32, rot: Option<(f32, f32, f32, f32)> /* ocx, ocy, sin, cos */,
    orientation: Orientation, w1: f32, h1: f32 /* source w-1, h-1 */, scx: f32, scy: f32, hom: Homography }

impl FusedMap {
    /// `(w, h)` are the SOURCE (pre-orientation) frame's.
    pub(super) fn new(w: usize, h: usize, orientation: Orientation, angle_rad: f32, crop: &CropRect, p: &Perspective) -> Self {
        let (ow, oh) = if orientation.rotate.swaps_axes() { (h, w) } else { (w, h) };
        let (x0, y0, _, _) = super::crop_bounds(ow, oh, crop);
        let rot = (angle_rad != 0.0).then(|| {
            let (sin, cos) = angle_rad.sin_cos();
            ((ow as f32 - 1.0) / 2.0, (oh as f32 - 1.0) / 2.0, sin, cos)
        });
        let scx = (w as f32 - 1.0) / 2.0; let scy = (h as f32 - 1.0) / 2.0;
        Self { x0: x0 as f32, y0: y0 as f32, rot, orientation, w1: w as f32 - 1.0, h1: h as f32 - 1.0,
               scx, scy, hom: Homography::from_edits(p, scx / scy) }
    }
    /// Output pixel (in the cropped frame) → source pixel.
    pub(super) fn source_of(&self, x: f32, y: f32) -> (f32, f32) {
        let (mut px, mut py) = (self.x0 + x, self.y0 + y);
        if let Some((cx, cy, sin, cos)) = self.rot {       // skipped, never sin = 0
            let (dx, dy) = (px - cx, py - cy);
            px = cx + dx * cos + dy * sin; py = cy - dx * sin + dy * cos;
        }
        let (mut sx, sy) = match self.orientation.rotate {  // `orient`'s table, continuous
            Quarter::Zero => (px, py), Quarter::Cw90 => (py, self.h1 - px),
            Quarter::Cw180 => (self.w1 - px, self.h1 - py), Quarter::Cw270 => (self.w1 - py, px) };
        if self.orientation.mirror { sx = self.w1 - sx; }
        let n = ((sx - self.scx) / self.scy, (sy - self.scy) / self.scy);
        let s = self.hom.source_of(n);
        (self.scx + s.0 * self.scy, self.scy + s.1 * self.scy)
    }
}
pub(super) fn render(src: &RegionSrc<'_>, map: &FusedMap, weights: &Weights, rect: Rect) -> ImageBuf { /* rotate_region's
    par_chunks_exact_mut gather, with map.source_of((rect.x+rx) as f32, (rect.y+ry) as f32) */ }
pub(super) fn input_rect(map: &FusedMap, out: Rect, in_w: usize, in_h: usize, pad: usize) -> Option<Rect> { /* four
    corners through source_of, is_finite guard declines, floor/ceil ± pad clamp — perspective's body */ }
```

  ⚠ With identity orientation, `angle == 0` and a full crop, `x0 = y0 = 0`, so `px = x as f32`
  and the arithmetic is `PerspectiveStage::render`'s exactly. That is the byte-identity claim for
  `perspective_*`.

  `mod.rs`: add a field `perspective: Perspective` (default), `pub fn with_perspective(mut self, p) -> Self`,
  and at the top of `apply`, `apply_region` and `input_rect_for`, when `self.perspective.is_active()`
  (and `w >= 2 && h >= 2` for `apply`), branch to the fused path:
  - `apply`: `let (ow, oh) = oriented dims; let (x0,y0,x1,y1) = crop_bounds(..); fused::render(&RegionSrc::whole(&image), &map, &self.weights, Rect{x:0,y:0,w:x1-x0,h:y1-y0})`
  - `apply_region(src, rect)`: bounds-check `rect` against crop dims computed from `src.full`, then `fused::render(src, &map_for(src.full), ..)`
  - `input_rect_for(out, in_w, in_h)`: bounds-check, then `fused::input_rect(..)`.
  `output_dims` is unchanged (perspective preserves dimensions).

```rust
pub struct SpotMap { frame: FrameMap, hom: Option<Homography>, aspect: f32, long_u: f32, long_v: f32, pub radius_scale: f32 }
impl SpotMap {
    pub fn new(g: &Geometry, p: Perspective, frame_w: usize, frame_h: usize) -> Self {
        let frame = FrameMap::new(g, frame_w, frame_h);
        // The spot space is the pre-orientation, pre-crop frame: undo the crop and the axis swap.
        let cw = (g.crop.right - g.crop.left).max(1e-6); let ch = (g.crop.bottom - g.crop.top).max(1e-6);
        let (ow, oh) = (frame_w as f32 / cw, frame_h as f32 / ch);
        let (sw, sh) = if g.orientation.rotate.swaps_axes() { (oh, ow) } else { (ow, oh) };
        let aspect = sw / sh.max(1e-6); let long = sw.max(sh);
        Self { radius_scale: frame.radius_scale, frame,
               hom: p.is_active().then(|| Homography::from_edits(&p, aspect)),
               aspect, long_u: long / sw.max(1e-6), long_v: long / sh.max(1e-6) }
    }
    fn to_n(&self, q: [f32; 2]) -> (f32, f32) { ((q[0] - 0.5) * 2.0 * self.aspect, (q[1] - 0.5) * 2.0) }
    fn from_n(&self, n: (f32, f32)) -> [f32; 2] { [n.0 / (2.0 * self.aspect) + 0.5, n.1 / 2.0 + 0.5] }
    pub fn point(&self, p: [f32; 2]) -> (f32, f32) {
        let q = match &self.hom { Some(h) => self.from_n(h.output_of(self.to_n(p))), None => p };
        self.frame.point(q)
    }
    pub fn inverse_point(&self, x: f32, y: f32) -> [f32; 2] {
        let q = self.frame.inverse_point(x, y);
        match &self.hom { Some(h) => self.from_n(h.source_of(self.to_n(q))), None => q }
    }
    /// Frame pixels per long-edge unit AT `p`, from the map's Jacobian.
    pub fn radius_scale_at(&self, p: [f32; 2]) -> f32 {
        if self.hom.is_none() { return self.radius_scale; }
        const E: f32 = 1e-3;
        let a = self.point(p); let b = self.point([p[0] + E * self.long_u, p[1]]);
        let c = self.point([p[0], p[1] + E * self.long_v]);
        let det = (b.0 - a.0) * (c.1 - a.1) - (b.1 - a.1) * (c.0 - a.0);
        det.abs().sqrt() / E
    }
}
```
