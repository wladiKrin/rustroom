# M6.4c — Rendering intents: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** perceptual and relative-colorimetric gamut mapping (hue-preserving, Oklab, boundary
table) in the output transform, CPU and GPU, driven by a canvas setting and an export-preset field.
Spec: `docs/superpowers/specs/2026-09-26-m6.4c-rendering-intents-design.md`.

**Gate:** fmt · `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings` · `cargo test --workspace`.

⚠ **One amendment to the spec:** thumbnails render with `RenderingIntent::default()`, not the canvas
setting — they are cached on disk, so following a view toggle would leave a library of mixed
thumbnails. The default is what the author picks from the crops.

### Task 1 — `color::gamut`
- [ ] `RenderingIntent { RelativeColorimetric (provisional default), Perceptual }`: `ALL`, `label`,
  serde. Re-exported from `color`.
- [ ] `GamutMap { space, target: Vec<f32>, source: Vec<f32> }` on an `NL = 65` × `NH = 256`
  (lightness × hue) grid; `for_space(space) -> &'static GamutMap` via one `OnceLock` per space;
  boundary by bisection (32 steps, `C ∈ [0, 0.6]`) of "from_working(oklab_to_prophoto(L, C·cos h,
  C·sin h)) ∈ [0,1]³"; `boundary(L, h)` / `source_boundary(L, h)` bilinear, hue wrapping.
- [ ] `map(&self, intent, rgb) -> rgb`: ProPhoto → identity. Relative: in-gamut → input returned
  as is. Otherwise Oklab; `L ≤ 0` → black, `L ≥ 1` → white; `b = boundary`, and
  - relative: `c' = min(c, b)`;
  - perceptual: `t = KNEE·b` (`KNEE = 0.8`); `c ≤ t` → input as is; else `s = max(source, b)`,
    `k = (s−t)/(b−t)`, `x = (c−t)/(s−t)`, `c' = min(t + (b−t)·k·x/(1+(k−1)·x), b)`
    (value and slope continuous at the knee, ProPhoto's edge onto the target's).
  - back to ProPhoto with `(L, c'·a/c, c'·b/c)`.
- [ ] Tests: table entries in gamut and 1% more out; output in gamut (after the encode's clamp the
  residue is measured, and the bound set from it); L and hue preserved (measured bound); relative
  bit-identical in gamut; perceptual monotone in chroma along a ray and continuous at the knee;
  ProPhoto identity; a P3-inside-sRGB-outside colour maps to itself for P3 and changes for sRGB;
  **done-when**: a saturated ProPhoto red → sRGB keeps its Oklab hue under both intents, and the
  old per-channel clip is first asserted to shift it.

### Task 2 — `OutputTransform::new(space, intent)` and `RenderSpec.intent`
- [ ] map → matrix → encode. `RenderSpec { intent, .. }`, default the provisional default; every
  `RenderSpec {` literal gains `intent` (the compiler lists them). `build_pipeline_split_*` passes it.
- [ ] Test: relative on an in-gamut image is bit-identical to the old transform; an out-of-gamut
  pixel differs and keeps hue.

### Task 3 — GPU twin
- [ ] `GpuOutputTransformStage::new(space, intent, ctx)`; the WGSL `map` using the Oklab prelude and
  the two tables from `base` (`target` then `source`); params gain `intent`, `nl`, `nh`, and a flag
  "identity" for ProPhoto. `accelerate` passes `spec.intent`.
- [ ] Parity: every space × intent against the CPU on a spread including out-of-gamut colours;
  existing tests updated.

### Task 4 — The canvas
- [ ] `Settings.canvas_intent` (container serde default), round-trip test; `FrameSpec.intent`;
  `Session.canvas_intent` fed from settings and folded into every request (the `display_space`
  pattern); `render_engine` builds the tail's `RenderSpec` with it and `proof_texture` maps with it.
- [ ] View menu: `Command::RenderingIntent(i)` per intent, appended after Gamut warning, handled in
  `commands.rs` (guarded, re-render, status line, persisted to settings). Menu test: every intent
  reachable.

### Task 5 — Export
- [ ] `ExportOptions.intent`; old preset JSON without it loads the default (test). `batch_export`
  render passes it. Dialog: an "Intent" combo under Colour space, disabled for ProPhoto.
- [ ] Thumbnails: `RenderingIntent::default()` (the amendment above).

### Task 6 — Goldens, crops, default
- [ ] Regenerate goldens under the provisional default; report how many moved and by how much.
  New golden `gamut_perceptual`.
- [ ] A probe renders the author's most saturated photos (clip / relative / perceptual) as
  magnified crops; the author picks the default; regenerate if it changes.
