# M9.12 Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** File → Import… copies ticked photos from a detected card (or any folder) into
`Destination/YYYY/YYYY-MM-DD/<template name>`, optionally to a backup, and applies Copyright /
Creator / Keywords and a develop preset on entry.

**Architecture:** lib `crates/app/src/ingest/` (`source`, `plan`, `copy`, `options`, `worker`,
`entry`) with no egui; a catalog query in `crates/catalog/src/db/imported.rs`; bin `import_flow.rs`
and `modals/import.rs`.

**Spec:** `docs/superpowers/specs/2026-09-27-m9.12-import-design.md`.

**Gate** (one mode per session): `cargo test --workspace <filter>`;
`CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings`;
`cargo fmt --all -- --check`. ⚠ Read the `N passed` count — a filter matching nothing exits 0.

**Test temp dirs:** every test builds its own tree under a counter-suffixed dir
(`immich_list_cache::tests::temp_dir`'s shape: pid + `AtomicU64`), never a bare pid.

```rust
//! What an import compares a card against (M9.12): every catalogued photo's size and capture time.
//!
//! ⚠ Its own file: `db.rs` is the crate's largest. A child module, so it reaches the connection.

use super::{Catalog, CatalogError};

/// One catalogued photo, as an import sees it.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Fingerprint {
    pub file_name: String,
    pub size: i64,
    /// `None` until the metadata scan (or an import) has recorded a capture.
    pub taken: Option<i64>,
}

impl Catalog {
    /// Every photo's file name, size and capture time — originals only (`copy = 0`).
    pub fn import_fingerprints(&self) -> Result<Vec<Fingerprint>, CatalogError> {
        let mut stmt = self.conn.prepare(
            "SELECT p.file_name, p.size, c.taken
             FROM photos p
             LEFT JOIN photo_capture c
               ON c.folder_id = p.folder_id AND c.file_name = p.file_name
             WHERE p.copy = 0 AND p.size IS NOT NULL",
        )?;
        let rows = stmt.query_map([], |r| {
            Ok(Fingerprint { file_name: r.get(0)?, size: r.get(1)?, taken: r.get(2)? })
        })?;
        Ok(rows.collect::<Result<_, _>>()?)
    }
}
```

```rust
//! Where an import reads from: cards (mounted volumes holding a `DCIM` folder) and the photos on
//! them. ⚠ Read-only by construction — nothing here opens a file for writing.

use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq)]
pub struct Card {
    pub name: String,
    pub root: PathBuf,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Candidate {
    pub path: PathBuf,
    pub size: u64,
    /// Seconds since the epoch; the fallback date when the file has no capture time.
    pub mtime: i64,
}

/// Where removable volumes mount on this platform. Injected into [`cards`] so tests use a temp tree.
pub fn default_roots() -> Vec<PathBuf> {
    if cfg!(target_os = "macos") {
        vec![PathBuf::from("/Volumes")]
    } else if cfg!(windows) {
        ('D'..='Z').map(|c| PathBuf::from(format!("{c}:\\"))).filter(|p| p.exists()).collect()
    } else {
        let user = std::env::var("USER").unwrap_or_default();
        vec![PathBuf::from(format!("/media/{user}")), PathBuf::from(format!("/run/media/{user}"))]
    }
}

/// Every direct child of each root that holds a `DCIM` directory (any case), sorted by name. On
/// Windows a root *is* the volume, so the root itself is checked too.
pub fn cards(roots: &[PathBuf]) -> Vec<Card> {
    let mut out = Vec::new();
    for root in roots {
        let mut candidates = vec![root.clone()];
        if let Ok(rd) = std::fs::read_dir(root) {
            candidates.extend(rd.flatten().map(|e| e.path()).filter(|p| p.is_dir()));
        }
        for vol in candidates {
            if has_dcim(&vol) && !out.iter().any(|c: &Card| c.root == vol) {
                let name = vol.file_name().map_or_else(
                    || vol.display().to_string(),
                    |n| n.to_string_lossy().into_owned(),
                );
                out.push(Card { name, root: vol });
            }
        }
    }
    out.sort_by(|a, b| a.name.cmp(&b.name));
    out
}

fn has_dcim(vol: &Path) -> bool {
    std::fs::read_dir(vol).is_ok_and(|rd| {
        rd.flatten()
            .any(|e| e.file_name().to_string_lossy().eq_ignore_ascii_case("DCIM") && e.path().is_dir())
    })
}

/// Every supported photo under `dir`, sorted by path. Hidden entries (a leading `.`, which covers
/// macOS's `._` AppleDouble files, `.Trashes` and `.Spotlight-V100`) are skipped.
pub fn scan(dir: &Path) -> Vec<Candidate> {
    let mut out = Vec::new();
    walk(dir, &mut out);
    out.sort_by(|a, b| a.path.cmp(&b.path));
    out
}

fn walk(dir: &Path, out: &mut Vec<Candidate>) {
    let Ok(rd) = std::fs::read_dir(dir) else { return };
    for e in rd.flatten() {
        if e.file_name().to_string_lossy().starts_with('.') {
            continue;
        }
        let p = e.path();
        let Ok(md) = e.metadata() else { continue };
        if md.is_dir() {
            walk(&p, out);
        } else if catalog::is_supported(&p) {
            let mtime = md
                .modified()
                .ok()
                .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
                .map_or(0, |d| d.as_secs() as i64);
            out.push(Candidate { path: p, size: md.len(), mtime });
        }
    }
}
```

```rust
/// Copy `src` to `dest` without ever leaving a half-file under `dest`'s name: write to a sibling
/// `dest.partial-<pid>`, check its size against the source's, then rename into place.
pub fn copy_verified(src: &Path, dest: &Path) -> std::io::Result<()> {
    if let Some(dir) = dest.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let partial = partial_path(dest);
    let result = (|| {
        let expected = std::fs::metadata(src)?.len();
        std::fs::copy(src, &partial)?;
        verify_size(expected, &partial)?;
        std::fs::rename(&partial, dest)
    })();
    if result.is_err() {
        let _ = std::fs::remove_file(&partial);
    }
    result
}
```

### Task 6: `ingest::worker` — survey and copy

`ImportWorker` owns a thread, `events: Receiver<ImportEvent>`, `cancel: Arc<AtomicBool>`.
`ImportWorker::survey(Vec<Candidate>)` and `ImportWorker::import(ImportJob)` are two spawns (a
survey worker is dropped when the dialog closes or the source changes; the import worker runs after).

```rust
pub enum ImportEvent {
    Surveyed { index: usize, taken: Option<i64>, camera: Option<String>, thumb: Option<Thumbnail> },
    SurveyDone,
    Progress { done: usize, total: usize, name: String },
    Copied { index: usize, dest: PathBuf, capture: Capture, backup_error: Option<String> },
    Failed { index: usize, error: String },
    Finished { copied: usize, failed: usize, cancelled: bool },
}

pub struct ImportJob {
    pub items: Vec<(usize, Candidate, PathBuf /* dest */, Option<PathBuf> /* backup dest */)>,
}
```

- Survey per candidate: capture via `raw_decode::read_capture` when `catalog::is_raw`, else
  `image_decode::read_capture`; thumbnail via `raw_decode::extract_thumbnail` /
  `image_decode::thumbnail`; errors become `None`. Checks `cancel` between files.
- Import per item: `copy::copy_verified(src, dest)`; then, if a backup dest, `copy_verified(src,
  backup)` whose error is carried as `backup_error`; `Copied` carries the capture read for the plan
  (re-read cheaply if the survey never reached it). Checks `cancel` between files.
- ⚠ The destination paths are planned on the UI thread **before** spawning (Task 3's `destination`
  with the `planned` list), so the worker never decides a name.

- [ ] **Tests** (on temp trees, with plain byte files — capture and thumbnail simply come back

  set, `Finished{copied:2, failed:0}`; cancel set before start → `Finished{cancelled:true, copied:0}`;

### Task 8: `import_flow.rs` (bin) — start, pump, finish

App fields (with docs): `import_draft: ImportOptions`, `import_source: Option<PathBuf>`,

- `pump_import_survey(ctx)`: `Surveyed` → fill `taken`/`camera`, texture from the thumbnail,

  only `known` flips it off, never on).
- `start_import()`: persist `settings.import` if changed; plan every ticked item's destination (and
  backup) with a running `planned` list and `seq` from 1; spawn the import worker.
- `pump_import(ctx)`: `Progress` → `import_progress`; `Copied` → push `(dest, capture)`;
  `Finished` → `scan_and_relink(destination)` (and `backup` too? **no** — the backup is not a
  working folder), then `ingest::entry::apply` per copied file with the chosen preset from
  `preset_store.list()`, `write_xmp_for(all copied)`, the summary text, and
  `open_folder_at(first copied file's parent)`.
- Repaint every 100 ms while a worker runs (`pump_export`'s rule). Called beside `pump_export`.
