# M9.13 AI Masks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** *Subject* and *Select by click* mask components, computed once by a neural network (IS-Net
or BiRefNet_lite; MobileSAM for clicks) through `tract`, cached on disk in decode space, refined by a
threshold, combinable like every other mask.

**Architecture:** a new zero-GUI crate `ai-mask` (registry, download, preprocessing, `tract`
inference, the decode-space `ProbMap`); `edit-model` gets `Mask::Ai`; `pipeline` gets a
`CoverageSource::Raster` fed by the existing `BrushCoverage` side channel; the app lib maps frames to
decode space, resamples maps, caches them and runs inference on a worker; the bin adds the panel
entries, the click gesture, the tint arm and the download dialog.

**Spec:** `docs/superpowers/specs/2026-09-28-m9.13-ai-masks-design.md` — ⚠ read its last section,
which supersedes earlier lines.

**Gate:** `cargo test --workspace <filter>`; `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace
--all-targets -- -D warnings`; `cargo fmt --all -- --check`. ⚠ **Compare the test total against the
expected total after every scripted edit** (the M9.12 lesson: a Python edit deleted five tests and the
gate stayed green).

### Task 1: crate `ai-mask` — registry and verified download

**Files:** `crates/ai-mask/{Cargo.toml,src/lib.rs,src/registry.rs,src/download.rs}`; workspace
`Cargo.toml` members.

- `registry.rs`: `pub enum ModelId { IsNet, BiRefNetLite, SamEncoder, SamDecoder }` with
  `const fn spec(self) -> ModelSpec { file, url, bytes, sha256, licence, licence_url }` and
  `ModelId::ALL`; `pub enum SubjectModel { IsNet, BiRefNetLite }` (serde, default IsNet) with
  `fn model(self) -> ModelId`; `fn needed_for_subject(SubjectModel) -> [ModelId; 1]`,
  `fn needed_for_click() -> [ModelId; 2]`.
- `download.rs`: `pub fn fetch_from(reader: impl Read, spec: &ModelSpec, dir: &Path, progress: impl
  FnMut(u64)) -> Result<PathBuf, FetchError>` — stream into `<file>.partial`, SHA-256 while writing
  (`sha2` crate), on mismatch delete the partial and `Err(HashMismatch)`, on match rename; `pub fn
  fetch(spec, dir, progress)` = `ureq::get(url)` into `fetch_from`; `pub fn present(spec, dir) -> bool`
  (exists and size matches — the hash was checked when it arrived).
- **Tests** (no network): a reader over bytes whose hash is put into a test `ModelSpec` → file lands,
  no partial; wrong hash → `HashMismatch`, no file, no partial; `present` false for a wrong size.
  Registry: every URL is `https://github.com/`, every hash is 64 hex chars, every licence non-empty.
- **Commit** `feat(ai-mask): the model registry and a hash-verified download`.

### Task 2: `ai-mask` — preprocessing, `ProbMap`, and `tract` inference

**Files:** `src/prep.rs`, `src/map.rs`, `src/infer.rs`.

- `map.rs`: `pub struct ProbMap { pub w: u32, pub h: u32, pub data: Vec<u8> }` (0–255 probability,
  row-major) with `at(u, v) -> f32` (bilinear, normalised coords, clamp at edges), `rotate_back(q:
  quarter turns)`, `to_bytes`/`from_bytes` (a 12-byte header `b"RRAI" w h` then data).
- `prep.rs` (pure, tested): `nchw(rgb8, side, mean, std) -> Vec<f32>` (bilinear resize to side²);
  `hwc_long_side(rgb8, 1024) -> (Vec<f32>, rw, rh)`; `sigmoid`; `min_max`; `sam_low_res_to_map(low:
  &[f32; 256*256], rw, rh) -> ProbMap` (upscale to 1024², crop `[0..rh, 0..rw]`, logits > 0 soft via
  sigmoid).
- `infer.rs`: `pub struct Subject { model: TypedRunnable, kind }` with `load(path, kind)` and
  `run(rgb8) -> ProbMap` (IS-Net: mean 0.5 std 1, output 0, min–max; BiRefNet: ImageNet, last output,
  sigmoid; both 1024² then resized to the input's size); `pub struct Sam { encoder_path, decoder_path }`
  with `embed(rgb8) -> Embedding { tensor, rw, rh }` (encoder built for `[rh, rw, 3]`) and
  `click(&Embedding, [x, y] normalised) -> ProbMap` (decoder built with `orig_im_size` as a **constant
  fact** `[rh, rw]`, cached per `(rw, rh)`; point in resized pixels plus `(0,0)` label −1; **output 2,
  `low_res_masks`**).
- **Tests:** prep on synthetic images (mean/std applied, shape, bilinear corners); `sam_low_res_to_map`
  crops a known pattern correctly **for a portrait size** (the frozen-crop trap); `ProbMap` round-trip
  and `rotate_back` of a marked pixel. Model tests are `#[ignore]` and read `RUSTROOM_AI_MODELS`.
- **Commit** `feat(ai-mask): preprocessing and tract inference for IS-Net, BiRefNet_lite and MobileSAM`.

### Task 3: `Mask::Ai` in the edit model

- `pub struct AiMask { pub prompt: AiPrompt, pub threshold: f32, pub invert: bool }` (serde, `Default`
  threshold 0, invert false), `pub enum AiPrompt { Subject, Click { point: [f32; 2] } }` — the point
  **decode-normalised**. `Mask::Ai(AiMask)` **appended**. Arms in `analytic_coverage` (→ `None`),
  `label` ("Subject" / "Selection"), `invert_mut`.
- Fixtures: add an `Ai` refinement or mask to the three exhaustive fixtures.
- **Tests:** round-trip of both prompts; an old sidecar without it loads; `invert_mut` flips.
- **Commit** `feat(edit-model): Mask::Ai — a subject or a click, a threshold and an invert`.

### Task 4: pipeline — `CoverageSource::Raster`, CPU and GPU

- `mask_coverage.rs`: `CoverageSource::Raster` (no payload — the map arrives in `prebuilt`);
  `source_for(Mask::Ai(_)) -> Raster`; `Composite::source_at`: Raster reads `maps[j]` exactly as
  `Painted` does, **0.0 when `maps[j]` is `None`** (the map is not computed yet — the spec's "renders
  empty").
- `gpu-pipeline/src/mask.rs::component`: `Mask::Ai(_)` → `Component::Prebuilt{map}` when a prebuilt map
  exists, else a component with zero coverage (read how `Painted` without a map is handled and mirror
  it; if there is no such path, return `None` so the CPU runs).
- **Tests:** a `MaskStage` with an `Ai` mask and an injected `CoverageMap` of a left-half 255 pattern
  darkens the left half only (exposure −1); without the map it changes nothing; a GPU parity test in
  the existing CPU/GPU comparison harness with the same injected map. **Golden** `mask_ai_injected`.
- **Commit** `feat(pipeline): AI mask coverage — a prebuilt raster through the brush side channel`.

### Task 5: app lib — decode-space mapping, resampling, disk cache

**Files:** `crates/app/src/ai_space.rs`, `crates/app/src/ai_coverage.rs`, `crates/app/src/ai_cache.rs`.

- `ai_space`: `pub struct DecodeMap` built from `(&Geometry, Perspective, frame_w, frame_h,
  Option<lens Corrector>, decode_w, decode_h)` with `frame_to_decode(fx, fy) -> [f32; 2]` (SpotMap
  inverse, then the corrector's `source`, normalised) — the chain lifted **out of**
  `spot_overlay::sampler_for` so the two share it (make `sampler_for` call it).
- `ai_coverage`: `pub fn refine(p: f32, threshold: f32, invert: bool) -> f32` (`smoothstep(t−0.15,
  t+0.15, p)`, `t = 0.5 − threshold/250`, then invert); `pub fn to_frame(map: &ProbMap, mask: &AiMask,
  fw, fh, region, &DecodeMap) -> CoverageMap` (walk the region's frame pixels, sample, refine, 8-bit,
  bbox of non-zero, `outside` = 255 when inverted else 0).
- `ai_cache`: key = SHA-256 of `(path, size, mtime, decode w×h, ModelId, prompt)` →
  `dirs::cache_dir()/rustroom/ai_masks/<hex>.map`; `load(key) -> Option<ProbMap>`, `store(key, &map)`.
- **Tests:** `refine` monotone in threshold, symmetric around 0.5 at 0, invert complements; `to_frame`
  with an identity `DecodeMap` reproduces a synthetic map; with a 90° orientation moves a marked pixel
  where `SpotMap` says; cache key changes with every input and a stored map loads back.
- **Commit** `feat(app): decode-space mapping, threshold/invert resampling and the AI map cache`.

### Task 6: app lib — the inference worker

**File:** `crates/app/src/ai_worker.rs` (the `decode_worker` shape).

- `AiRequest { key, photo_rgb: Arc<RgbImage> (upright), rotate_back: u8, model: SubjectModel or Click
  point, models_dir }` → `AiResult { key, map: Result<ProbMap, String> }`. The thread keeps loaded
  `Subject` models and the last photo's SAM `Embedding` (keyed by photo) so a second click is 0.1 s.
  On success it `ai_cache::store`s before replying. `request()` returns a sequence number; `poll()`.
- `fn model_input(buffer: &ImageBuf, orientation) -> (RgbImage, quarter_turns)`: ProPhoto → sRGB,
  exposure normalised to mean luminance 0.18, encoded, clipped, rotated upright, long side ≤ 1024·2.
- **Tests:** `model_input` of a mid-grey linear buffer encodes to ~118 and rotates a marked pixel; the
  worker with a fake runner (a trait `Runner` injected for tests) replies in order and stores to cache.
- **Commit** `feat(app): the AI mask worker — cached models and embeddings, results to the disk cache`.

### Task 7: rendering — preview and export

- `render_engine::BrushCache`: an `Ai` component whose map is in the in-memory `AiMaps` store (an
  `Arc<Mutex<HashMap<key, Arc<ProbMap>>>>` on the session, filled from the worker and the disk cache)
  becomes `ai_coverage::to_frame(...)` in `BrushCoverage.maps[i][j]`; the key gains the map's key.
- `batch_export::render`: build a `BrushCoverage` with those maps (loaded from `ai_cache`, the export's
  own `DecodeMap`); a photo with an uncomputed AI mask is reported in the export summary.
- **Tests:** a render-engine test with an injected `ProbMap` changes the rendered half; export of a
  photo whose map is cached applies it; missing → reported and renders without it.
- **Commit** `feat(app): AI masks in the preview and the export`.

### Task 8: the UI

- `mask_kind`: `Subject` and `Select` (click) kinds with templates, labels, hovers, glyphs.
- Panel: adding **Subject** requests inference at once; adding **Select** arms a click on the canvas
  (`eye_overlay`'s click shape) whose point becomes `AiPrompt::Click` in decode space; a selected Select
  mask re-aims on a click (one undo step). Shape block: **Refine** slider (−100..100, default 0) and
  **Invert**; a spinner row while computing.
- First use: a modal listing each missing file (name, size, licence, link) with *Download* / *Cancel*,
  then progress; downloads on a thread with `ai_mask::download::fetch`.
- `mask_tint`: an `Ai` arm sampling the `ProbMap` through `DecodeMap` + `refine`; `TintCache` key gains
  the map key. `mask_overlay::paint_mask`: nothing to draw for Subject, a small ring at a Select point.
- Settings: **AI subject model** — IS-Net (fast) / BiRefNet_lite (high quality, 224 MB).
- **Tests:** the panel adds both kinds; a Select click stores a decode-space point; the exhaustive
  `MaskKind::ALL` guards still pass.
- **Commit** `feat(app): Subject and Select-by-click masks in the panel, the canvas and Settings`.
