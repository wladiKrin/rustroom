# M10.6a — The Immich Timeline at the top: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** the Immich section of the Library rail shows a **Timeline** row, then an **Albums** row, both
rail tree rows with counts; Albums open by default, the Timeline's old open state kept.

**Architecture:** two small lib additions (`immich_source::photo_total`, `ImmichWorker`'s per-kind
listing checks), a `date_rows::branch_with` variant taking a `BranchSpec`, and `immich_panel::body`
redrawn as the two branches.

**Spec:** `docs/superpowers/specs/2026-09-29-m10.6a-immich-timeline-design.md`.

**Gate:** `cargo fmt --all --check` · `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace
--all-targets -- -D warnings` · `cargo test --workspace` (filter by test **name**, never `-p`). Set
`PKG_CONFIG_PATH` first (CLAUDE.md, *Run the GUI*).

**Found while planning — the spec's id is wrong as written.** egui's `CollapsingHeader` wraps its salt
in an `IdSalt` (a hash of the source) and calls `ui.make_persistent_id(IdSalt::new(salt))`, so
`make_persistent_id("immich_timeline")` is a **different** id and would reset every open Timeline. The
faithful id is `ui.make_persistent_id(egui::IdSalt::new("immich_timeline"))`, and Task 4's first test
proves it against the real old header. ⚠ The years' own open states were keyed inside the old header's
body `Ui`, whose id differs from the section's, so an open **year** closes once after the update —
accepted, and said in the report.

```rust
/// A branch row's description, for [`branch_with`].
pub(crate) struct BranchSpec<'a> {
    pub name: &'a str,
    /// `None` paints no count — a list not yet in hand.
    pub count: Option<i64>,
    pub depth: usize,
    /// The state for an id nothing has stored yet.
    pub default_open: bool,
    /// One sentence, or empty for none.
    pub hover: &'a str,
}

/// A year or a month: a row that opens and closes the level beneath, by a click anywhere on it or
/// on its triangle. Returns whether it is open now.
pub(crate) fn branch(
    ui: &mut egui::Ui,
    id: egui::Id,
    name: &str,
    count: i64,
    depth: usize,
) -> bool {
    branch_with(
        ui,
        id,
        BranchSpec {
            name,
            count: Some(count),
            depth,
            default_open: false,
            hover: "",
        },
    )
}

/// [`branch`] with a default open state, an optional count and a hover — the Immich section's two
/// rows (M10.6a).
pub(crate) fn branch_with(ui: &mut egui::Ui, id: egui::Id, spec: BranchSpec<'_>) -> bool {
    let mut state = CollapsingState::load_with_default_open(ui.ctx(), id, spec.default_open);
    let open = state.is_open();
    let indent = list_row::tree_indent(spec.depth);
    let r = list_row::row(
        ui,
        RowSpec {
            name: spec.name,
            count: spec.count,
            meta: "",
            selected: false,
            indent,
            hover: spec.hover,
            actions: &[],
        },
    );
    let toggled = list_row::disclosure(ui, r.rect, indent, open, id.with("disclosure"));
    if r.clicked || toggled {
        state.set_open(!open);
        state.store(ui.ctx());
    }
    state.is_open()
}
```

```rust
/// Ask for a list unless something this frame already asked for something — `body` returns one
/// `Action`, and a click must never lose to a background request (which is re-made next frame).
fn ask(action: &mut Action, request: Action) {
    if matches!(action, Action::None) {
        *action = request;
    }
}

/// A quiet line under an open row: loading, empty, or the server's own error.
fn note(ui: &mut egui::Ui, text: &str) {
    ui.horizontal(|ui| {
        ui.add_space(list_row::tree_indent(1));
        ui.label(egui::RichText::new(text).weak().small());
    });
}

/// The Timeline row's id — the old `CollapsingHeader`'s exactly, so an open Timeline stays open.
///
/// ⚠⚠ **`IdSalt::new`, not the bare string.** The header hashed its salt into an `IdSalt` before
/// `make_persistent_id`, and `make_persistent_id("immich_timeline")` is a different id.
/// `the_timeline_keeps_the_old_headers_open_state` holds this to the real header.
fn timeline_id(ui: &egui::Ui) -> egui::Id {
    ui.make_persistent_id(egui::IdSalt::new("immich_timeline"))
}

/// The Timeline row and, open, its years and months.
fn timeline(app: &RustroomApp, ui: &mut egui::Ui, action: &mut Action) {
    // ⚠ Asked for with the section, not with the row: the closed row shows its count.
    if app.immich_buckets.is_none() && !app.immich.is_listing_buckets() {
        ask(action, Action::RefreshBuckets);
    }
    let total = match &app.immich_buckets {
        Some(Ok(b)) => Some(rustroom_app::immich_source::photo_total(b) as i64),
        _ => None,
    };
    let open = crate::date_rows::branch_with(
        ui,
        timeline_id(ui),
        crate::date_rows::BranchSpec {
            name: "Timeline",
            count: total,
            depth: 0,
            default_open: false,
            hover: "Shows the server's whole library by year and month",
        },
    );
    if !open {
        return;
    }
    match &app.immich_buckets {
        None => note(ui, "Loading…"),
        Some(Err(e)) => note(ui, e),
        Some(Ok(buckets)) => {
            let years = rustroom_app::immich_source::group_buckets(buckets);
            if years.is_empty() {
                note(ui, "Nothing on the server");
            }
            for y in years {
                // (the existing year/month loop, with the year at depth 1 and the months at
                // `list_row::tree_indent(2)`; `*action = Action::OpenBucket {..}` on a click)
            }
        }
    }
}

/// The Albums row and, open, the album rows.
fn albums(app: &RustroomApp, ui: &mut egui::Ui, action: &mut Action) {
    if app.immich_albums.is_none() && !app.immich.is_listing_albums() {
        ask(action, Action::Refresh);
    }
    let n = match &app.immich_albums {
        Some(Ok(a)) => Some(a.len() as i64),
        _ => None,
    };
    // ⚠ Open by default: the albums were always in view, and stay there one row lower.
    let open = crate::date_rows::branch_with(
        ui,
        ui.make_persistent_id("immich_albums"),
        crate::date_rows::BranchSpec {
            name: "Albums",
            count: n,
            depth: 0,
            default_open: true,
            hover: "Shows the server's albums",
        },
    );
    if !open {
        return;
    }
    match &app.immich_albums {
        None => note(ui, "Loading albums…"),
        Some(Err(e)) => {
            note(ui, e);
            ui.horizontal(|ui| {
                ui.add_space(list_row::tree_indent(1));
                if ui.small_button("Retry").clicked() {
                    *action = Action::Refresh;
                }
            });
        }
        Some(Ok(albums)) => {
            if albums.is_empty() {
                note(ui, "No albums on the server");
            }
            // (the existing album loop, with `indent: list_row::tree_indent(1)` and `*action = …`
            // for Open / DownloadAlbum / RemoveAlbum)
        }
    }
}
```

```rust
    fn labels(ctx: &egui::Context, app: &RustroomApp) -> Vec<(String, egui::Pos2)> {
        test_ui::labelled_centres(ctx, Vec::new(), |ui| {
            let _ = body(app, ui);
        })
    }

    fn y_of(all: &[(String, egui::Pos2)], label: &str) -> f32 {
        all.iter()
            .find(|(l, _)| l == label)
            .map(|(_, p)| p.y)
            .unwrap_or_else(|| panic!("no {label:?} drawn: {all:?}"))
    }

    /// Every all-digit text painted, i.e. the counts.
    fn painted_counts(ctx: &egui::Context, app: &RustroomApp) -> Vec<String> {
        let out = ctx.run_ui(
            egui::RawInput {
                screen_rect: Some(test_ui::screen()),
                ..Default::default()
            },
            |ui| {
                let _ = body(app, ui);
            },
        );
        fn walk(shape: &egui::Shape, found: &mut Vec<String>) {
            match shape {
                egui::Shape::Vec(v) => v.iter().for_each(|s| walk(s, found)),
                egui::Shape::Text(t) => {
                    let text = t.galley.text();
                    if !text.is_empty() && text.chars().all(|c| c.is_ascii_digit()) {
                        found.push(text.to_owned());
                    }
                }
                _ => {}
            }
        }
        let mut found = Vec::new();
        for c in &out.shapes {
            walk(&c.shape, &mut found);
        }
        found.sort();
        found
    }
```
