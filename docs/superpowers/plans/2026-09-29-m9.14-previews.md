# M9.14 Previews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sharp picture at 1:1 the moment a photo is looked at in Develop, Compare or Survey — the camera's embedded JPEG for an untouched photo, Rustroom's own rendering for an edited one, built on leaving the photo or on demand — with nothing built for photos that are never edited or asked for.

**Architecture:** Two lib modules feed pixels (`preview_loader` resolves a request to a rendered preview in `preview_store`, else the camera JPEG via `raw_decode::extract_preview`), one lib module schedules builds (`preview_build`: a `LeaveQueue` and export-job shaping, the build itself being the existing `ExportWorker`), and one pure rule (`stand_in::prefer_preview`) tells Develop when to show the preview instead of the live render. The bin holds textures in a second `ThumbCache`, wires the pumps, the Develop stand-in, and preview panes for Compare and Survey.

**Tech Stack:** Rust, egui 0.35, libraw via rsraw (`extract_thumbs`), `image` for JPEG decode/encode, the existing `batch_export` worker.

**Spec:** `docs/superpowers/specs/2026-09-28-m9.14-previews-design.md`. **Branch:** `m9.14-previews`.

```rust
/// The largest embedded thumbnail as a decoded image, plus libraw's flip code — not yet
/// oriented, so a caller can shrink first and rotate a fraction of the pixels.
fn largest_embedded(bytes: &[u8]) -> Result<(image::DynamicImage, i32), DecodeError> {
    let mut raw =
        RawImage::open(bytes).map_err(|e| DecodeError::Backend(format!("open: {e:?}")))?;
    let flip = raw.as_ref().sizes.flip;
    let thumbs = raw
        .extract_thumbs()
        .map_err(|e| DecodeError::Backend(format!("thumbs: {e:?}")))?;
    let t = thumbs
        .into_iter()
        .max_by_key(|t| t.width as u64 * t.height as u64)
        .ok_or_else(|| DecodeError::Format("no embedded thumbnail".into()))?;
    let dynimg = match t.format { /* the existing Jpeg / Bitmap / other arms, unchanged */ };
    Ok((dynimg, flip))
}

fn to_thumbnail(img: image::RgbaImage) -> Thumbnail {
    Thumbnail { width: img.width() as usize, height: img.height() as usize, rgba: img.into_raw() }
}

pub(crate) fn extract_thumbnail(bytes: &[u8]) -> Result<Thumbnail, DecodeError> {
    let (img, flip) = largest_embedded(bytes)?;
    const THUMB_MAX_DIM: u32 = 512;
    Ok(to_thumbnail(apply_flip(img.thumbnail(THUMB_MAX_DIM, THUMB_MAX_DIM), flip).to_rgba8()))
}

/// The largest embedded JPEG at **its own size**, oriented — M9.14's camera preview.
pub(crate) fn extract_preview(bytes: &[u8]) -> Result<Thumbnail, DecodeError> {
    let (img, flip) = largest_embedded(bytes)?;
    Ok(to_thumbnail(apply_flip(img, flip).to_rgba8()))
}
```

```rust
//! What a **rendered** preview is of: a photo at a version, the edits it was rendered with,
//! and the demosaic tier — and the one rule that says a photo is untouched.
//!
//! ⚠ The edits fingerprint here is **stable** (FNV-1a over the serialized edits), unlike
//! `thumb_key::edits_fingerprint`, because this key names a file on disk. `DefaultHasher`
//! may change between toolchains, which would turn every stored preview into a miss.

use crate::photo_id::PhotoId;
use crate::thumb_store::{fnv1a, Identity};
use edit_model::Edits;
use raw_decode::Demosaic;

pub fn stable_fingerprint(edits: &Edits) -> u64 {
    match serde_json::to_vec(edits) {
        Ok(bytes) => fnv1a(&bytes),
        Err(_) => 0,
    }
}

/// Untouched means **equal to the edits a fresh open assigns** (`Settings::initial_edits(None)`:
/// the camera rendering and the lens decision from the settings, everything else default).
///
/// ⚠ Not the sidecar's `is_neutral`, which compares against `Edits::default()` and would call
/// every freshly opened photo edited — `a_fresh_photo_is_untouched_while_the_sidecar_rule_calls_it_edited`.
pub fn is_untouched(edits: &Edits, fresh: &Edits) -> bool {
    edits == fresh
}

#[derive(Clone, PartialEq, Eq, Debug)]
pub struct PreviewKey {
    pub id: PhotoId,
    pub edits: u64,
    pub tier: Demosaic,
}

impl PreviewKey {
    pub fn new(id: PhotoId, edits: &Edits, tier: Demosaic) -> Self {
        Self { id, edits: stable_fingerprint(edits), tier }
    }

    /// The hash the file is named by: the file's identity (path, mtime, size — a re-shot or
    /// re-saved original is a different photo), the copy, the edits and the tier.
    pub fn file_stem(&self) -> String {
        let mut bytes = match Identity::of(&self.id.path) {
            Some(i) => i.key_bytes(),
            None => self.id.path.to_string_lossy().as_bytes().to_vec(),
        };
        bytes.extend_from_slice(&self.id.copy.to_le_bytes());
        bytes.extend_from_slice(&self.edits.to_le_bytes());
        bytes.extend_from_slice(self.tier.label().as_bytes());
        format!("{:016x}", fnv1a(&bytes))
    }

    pub fn file_name(&self) -> String {
        format!("{}.jpg", self.file_stem())
    }
}
```

```rust
//! Rendered previews on disk: `<hash>.jpg` under `<config>/rustroom/previews`, written by the
//! export worker, named by `PreviewKey`, evicted oldest-first when over budget.
//!
//! ⚠ Plain JPEGs, not `ThumbStore`'s headered entries: the key already carries identity,
//! edits and tier, so a different photo or edit state is a different file name and there is
//! nothing to verify inside the file. The export worker writes the file; this store only
//! names, opens, counts and sweeps.

use crate::preview_key::PreviewKey;
use core_image::Thumbnail;
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::Arc;

#[derive(Debug, Clone)]
pub struct PreviewStore {
    dir: PathBuf,
    budget: u64,
    written: Arc<AtomicU64>,
}

impl PreviewStore {
    pub fn new(dir: PathBuf, budget_bytes: u64) -> Self { Self { dir, budget: budget_bytes, written: Arc::new(AtomicU64::new(0)) } }

    /// `<platform config dir>/rustroom/previews/`, beside `thumbs`.
    pub fn user_default(budget_bytes: u64) -> Self {
        Self::new(dirs::config_dir().unwrap_or_else(|| PathBuf::from(".")).join("rustroom").join("previews"), budget_bytes)
    }

    pub fn dir(&self) -> &Path { &self.dir }
    pub fn path_for(&self, key: &PreviewKey) -> PathBuf { self.dir.join(key.file_name()) }
    pub fn has(&self, key: &PreviewKey) -> bool { self.path_for(key).is_file() }

    /// Decode the stored JPEG; touch its mtime so eviction is LRU. Every failure is a miss.
    pub fn open(&self, key: &PreviewKey) -> Option<Thumbnail> {
        let path = self.path_for(key);
        let bytes = std::fs::read(&path).ok()?;
        let img = image::load_from_memory_with_format(&bytes, image::ImageFormat::Jpeg).ok()?.to_rgba8();
        if let Ok(f) = std::fs::File::options().write(true).open(&path) {
            let _ = f.set_times(std::fs::FileTimes::new().set_modified(std::time::SystemTime::now()));
        }
        Some(Thumbnail { width: img.width() as usize, height: img.height() as usize, rgba: img.into_raw() })
    }

    /// The export worker wrote `bytes` into the directory: sweep once a tenth of the budget has
    /// accumulated, `ThumbStore::put`'s amortisation.
    pub fn note_written(&self, bytes: u64) {
        if self.budget == u64::MAX { return; }
        let before = self.written.fetch_add(bytes, Ordering::Relaxed);
        let slack = (self.budget / 10).max(1);
        if before + bytes >= slack {
            self.written.store(0, Ordering::Relaxed);
            self.sweep();
        }
    }

    pub fn sweep(&self) { /* ThumbStore::sweep verbatim: .tmp litter removed, oldest mtime first until total <= budget */ }
    pub fn size_bytes(&self) -> u64 { /* ThumbStore::size_bytes verbatim */ }
    pub fn clear(&self) { /* ThumbStore::clear verbatim */ }
}
```

```rust
pub fn cap_to(t: Thumbnail, max_side: usize) -> Thumbnail {
    let long = t.width.max(t.height);
    if long <= max_side || long == 0 { return t; }
    let k = max_side as f64 / long as f64;

    Thumbnail { width: w as usize, height: h as usize, rgba: out.into_raw() }
}
```

```rust
//! Scheduling rendered previews: the queue of edited photos left behind, and the shape of a
//! build — which **is an export job** into the store, so one render path serves both.

use crate::batch_export::{ExportFormat, ExportJob, ExportOptions};
use crate::photo_id::PhotoId;
use crate::preview_key::PreviewKey;
use edit_model::Edits;
use raw_decode::Demosaic;

/// JPEG quality for a rendered preview. Like the thumbnail store's, a tunable with its number here.
pub const PREVIEW_QUALITY: u8 = 90;

#[derive(Default, Debug)]
pub struct LeaveQueue { entries: Vec<(PhotoId, Edits)> }

impl LeaveQueue {
    /// A photo already queued is replaced in place — edited again before its build ran, it is
    /// built once, with the latest edits.
    pub fn push(&mut self, id: PhotoId, edits: Edits) {
        match self.entries.iter_mut().find(|(i, _)| *i == id) {
            Some(e) => e.1 = edits,
            None => self.entries.push((id, edits)),
        }
    }
    pub fn pop(&mut self) -> Option<(PhotoId, Edits)> { if self.entries.is_empty() { None } else { Some(self.entries.remove(0)) } }
    pub fn remove(&mut self, id: &PhotoId) { self.entries.retain(|(i, _)| i != id); }
    pub fn len(&self) -> usize { self.entries.len() }
    pub fn is_empty(&self) -> bool { self.entries.is_empty() }
}

pub fn build_options(store_dir: std::path::PathBuf, tier: Demosaic) -> ExportOptions {
    ExportOptions {
        dest_dir: store_dir,
        quality: PREVIEW_QUALITY,
        max_edge: None,
        demosaic: tier,
        format: ExportFormat::Jpeg,
        space: color::OutputSpace::Srgb,
        // ⚠ `{copy}` renders the job's `name` when one is set — the key's hash, below.
        filename_template: "{copy}".to_string(),
        ..ExportOptions::default()
    }
}

pub fn build_job(id: PhotoId, edits: Edits, tier: Demosaic) -> ExportJob {
    let name = PreviewKey::new(id.clone(), &edits, tier).file_stem();
    ExportJob { id, name: Some(name), edits, capture: Default::default(), description: Default::default(), marks: Default::default(), keywords: Vec::new() }
}
```

```rust
//! M9.14: previews in the app — shaping requests from the settings, the texture window, the
//! pumps, the leave hook and the two kinds of build. Logic that needs no egui lives in the lib
//! (`preview_loader`, `preview_build`, `preview_key`, `stand_in`).

impl RustroomApp {
    pub(crate) fn preview_request(&self, id: PhotoId, edits: Edits) -> PreviewRequest {
        let fresh = self.settings.initial_edits(None);
        PreviewRequest { untouched: is_untouched(&edits, &fresh), tier: self.settings.preview_tier(), id, edits }
    }

    /// The previews on screen now: pin them, ask the loader for the missing ones (once per change).
    pub(crate) fn sync_preview_window(&mut self, window: &[PreviewRequest]) {
        let keys: Vec<ThumbKey> = window.iter().map(|r| r.key()).collect();
        self.preview_textures.retain_window(&keys);
        let missing: Vec<PreviewRequest> = window.iter().filter(|r| !self.preview_textures.contains(&r.key())).cloned().collect();
        if missing != self.preview_want { self.previews.want(&missing); self.preview_want = missing; }
    }

    pub(crate) fn pump_previews(&mut self, ctx: &egui::Context) {
        for res in self.previews.drain() {
            let Some((t, source)) = res.preview else { continue };  // a miss: the thumbnail stays
            let bytes = t.rgba.len();
            let img = egui::ColorImage::from_rgba_unmultiplied([t.width, t.height], &t.rgba);
            let tex = ctx.load_texture(format!("preview:{}#{}:{}", res.key.id.path.display(), res.key.id.copy, res.key.edits), img, egui::TextureOptions::LINEAR);
            self.preview_textures.insert(res.key, (tex, source), bytes);
            ctx.request_repaint();
        }
    }

    /// Develop's window: the pending photo's preview, or the open one's until the full decode lands.
    pub(crate) fn sync_develop_previews(&mut self) {
        let window: Vec<PreviewRequest> = if let Some(p) = &self.pending {
            vec![p.preview_request.clone()]
        } else if let Some(s) = &self.session {
            if s.buffer_is_full_res { Vec::new() } else { vec![self.preview_request(PhotoId::new(s.path.clone(), s.copy), s.edits.clone())] }
        } else { Vec::new() };
        self.sync_preview_window(&window);
    }

    /// Leaving an edited photo: queue its preview unless the store already has it.
    pub(crate) fn queue_leave_build(&mut self, id: PhotoId, edits: Edits) {
        let req = self.preview_request(id.clone(), edits.clone());
        if req.untouched || self.preview_store.has(&req.store_key()) { return; }
        self.leave_queue.push(id, edits);
    }

    fn spawn_build(&mut self, jobs: Vec<ExportJob>, width: usize, kind: BuildKind) { /* ExportWorker::spawn as start_export does, with build_options(store.dir, preview_tier()), decode_for_export(p, tier, camera_profile_path()), the export's ExportRender and looks_dir, upload None */ }

    pub(crate) fn start_preview_build(&mut self) {
        let tier = self.settings.preview_tier();
        let jobs: Vec<ExportJob> = self.export_jobs().into_iter()
            .filter(|j| !self.preview_store.has(&PreviewKey::new(j.id.clone(), &j.edits, tier)))
            .map(|j| build_job(j.id, j.edits, tier)).collect();
        if jobs.is_empty() { self.status = "Every selected photo already has a preview".to_string(); return; }
        if let Some((w, _)) = &self.preview_builder { w.cancel(); }   // on-demand goes first
        self.preview_progress = format!("Building previews 0 of {}…", jobs.len());
        let width = self.settings.export_width();
        self.spawn_build(jobs, width, BuildKind::OnDemand);
    }

    pub(crate) fn cancel_preview_build(&mut self) { /* cancel, drop, clear progress, status "Preview build cancelled" */ }

    pub(crate) fn pump_preview_builds(&mut self, ctx: &egui::Context) {
        if self.preview_builder.is_none() {
            if let Some((id, edits)) = self.leave_queue.pop() {
                let tier = self.settings.preview_tier();
                self.spawn_build(vec![build_job(id, edits, tier)], 1, BuildKind::Leave);
            }
        }
        let Some((worker, kind)) = &self.preview_builder else { return };
        let mut finished = None;
        while let Ok(ev) = worker.events().try_recv() {
            match ev {
                ExportEvent::Item { done, total, .. } if *kind == BuildKind::OnDemand => self.preview_progress = format!("Building previews {done} of {total}…"),
                ExportEvent::Collision { .. } => worker.decide(Decision::Resolve { collision: Collision::Overwrite, apply_to_all: true }),
                ExportEvent::Finished(r) => finished = Some(r),
                _ => {}
            }
        }
        if let Some(r) = finished {
            let kind = *kind;
            self.preview_builder = None;
            self.preview_progress.clear();
            self.preview_store.note_written(r.exported as u64 * 8 * 1024 * 1024);  // ~8 MB a preview; the sweep measures the truth
            self.preview_textures.clear();   // reload as Rendered on the next want
            self.preview_want.clear();
            self.preview_cache_bytes = None;
            if kind == BuildKind::OnDemand { self.status = format!("Built {} previews{}", r.exported, if r.cancelled { ", cancelled" } else { "" }); }
        }
        if self.preview_builder.is_some() || !self.leave_queue.is_empty() { ctx.request_repaint_after(std::time::Duration::from_millis(100)); }
    }
}
```
