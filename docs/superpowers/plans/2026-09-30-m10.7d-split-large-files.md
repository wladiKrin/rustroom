# M10.7d — split the large files: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** the nine files over 1,000 lines of code + doc become focused modules, their four giant
functions become orchestrators over named phases, and a guard keeps every file under 1,000 — with no
behaviour change, proven per commit.

**Spec:** `docs/superpowers/specs/2026-09-30-m10.7d-split-large-files-design.md`.

**Architecture:** code is never retyped. Items move as exact byte spans, found by NAME by a parser;
function phases move as exact line ranges, found by unique marker text, dedented. The compiler then
names every import and visibility the move needs, and nothing else is edited by hand.

## Tooling (scratch, `$S = scratchpad/m107d`) — built and self-checked before this plan

- `rsmove.py` — parses a file or an item body (impl, mod) into spans that **tile it byte for byte**;
  an item's span includes its contiguous leading docs/attributes. `take(path, sels)`,
  `take_members(path, container, sels)`, `put(path, text, before=, prelude=)`, `wrap(header, texts)`,
  `lines_between(path, start_marker, end_marker)`, `cut_lines`, `dedent`. Selectors: `fn:name`,
  `struct:Name`, `impl:Type`, `impl:Trait for Type`, `const:NAME`, `mod:tests`, `#N` for the Nth.
  Checked: all nine files and their test modules tile exactly, every item is bracket-balanced, and the
  parser's `#[test]` counts equal `grep`'s in every module.
- `conserve.py BASE` — over every changed `.rs` file: **comment lines removed** (a move removes none)
  and the **code-token multiset** (use/mod lines, visibility and commas normalised away; a move
  removes none). Sabotaged: one doc line and one code line deleted → both reported, to the token.
- `verify.sh [BASE]` — fmt; build all targets; **the test-name multiset against the baseline**
  (3,297 listed, 24 names shared, so a multiset); tests; clippy in `target/clippy`; goldens untouched;
  `conserve.py`.
- Baselines: `tests-base.txt`; `timing-base-{1,2}.log` (`probe_straighten_drag` on
  `~/Pictures/fuji/DSCF6263.RAF`, rung 3200: drag median **30.5 / 33.5 ms** at load 11) and the
  baseline binary `probe-base`, for an interleaved before/after at the end.

**Every task ends the same way:** `verify.sh` green (build, names identical, tests, clippy, goldens 0),
`conserve.py` shows **no comment line and no code token removed** — except where the task says what
and why — then one commit.
