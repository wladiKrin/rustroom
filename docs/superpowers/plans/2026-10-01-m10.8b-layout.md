## Task 1: the lib — layout, setting, menu

- `crates/app/src/layout.rs` (`pub mod layout;`):
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
  pub enum Side { Left, Right }            // other()
  #[derive(... Default ...)] pub enum StripPlace { #[default] Bottom, Left, Right }  // side() -> Option<Side>
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
  pub struct Layout { pub library_rail: Side, pub edit_panel: Side, pub filmstrip: StripPlace }
  impl Default for Layout { left, right, bottom }
  pub enum Piece { Filmstrip, ToolRail, EditPanel }
  pub fn develop_order(l: &Layout) -> [Piece; 3];
  ```
- `settings/mod.rs`: `pub layout: Layout` (the container-level default covers older files).
- `menu.rs`: `Command::{ToggleLibraryRailSide, ToggleEditPanelSide, FilmstripAt(StripPlace)}`;
  `pub struct MenuState { pub layout: Layout, pub filmstrip_shown: bool }`;
  `pub fn checked(c: Command, s: &MenuState) -> Option<bool>`; the View items after *Hide panels*.
- Tests: defaults; `{}` parses to them; the six orders; `checked`; the View menu's labels in order.
  Commit.

## Task 2: commands and the two side panels

- `commands.rs`: the three commands (toggle / set, then `save_settings`; `FilmstripAt` also sets
  `show_filmstrip`).
- `side_panel.rs` (bin): `pub(crate) fn side(s: Side, id: impl Into<egui::Id>) -> egui::Panel`.
- `collections_panel.rs`: the rail on `settings.layout.library_rail`.
- `develop/mod.rs::body`: a loop over `develop_order`; `develop/panel/mod.rs` and `develop/rail.rs` take
  the edit panel's side.
- Tests: commands flip and save, a place shows the strip; the Library rail on the right of the grid
  (drawn); the six Develop layouts drawn (`open_test_photo`, `library_of(30)`), pieces ordered by x as
  the layout says, none overlapping. Commit.

## Task 3: the filmstrip along either axis

`filmstrip.rs`: the panel by place (`Panel::bottom("filmstrip")`, or `side(.., "filmstrip_side")`
resizable, default 150, min 96); cross size → cell (3:2 either way), step and extent along the main
axis; `ScrollArea::vertical` with `vertical_scroll_offset` on a side; `visible_span` on `viewport.min.y`;
`ui.vertical` rows. Tests: a 200-photo side strip draws far fewer cells; a click selects; resizing the
side strip keeps the active photo's centre (the bottom test's twin, on `filmstrip_side`). Commit.

## Task 4: the menus draw the marks

`menu_bar.rs`: `show(ui, recent, &MenuState)`; a checked item is a `checkbox` (toggles) or a `radio`
(`FilmstripAt`). `native_menu.rs`: a `CheckMenuItem` for every command `checked` answers for, kept by
command; `sync(&MenuState)` sets them when the state differs from the last synced one (reset by
`install`). `shell`: build the `MenuState`, pass it to the bar, call `sync` on macOS. Test: the bar
renders with the state (both values). Commit.
