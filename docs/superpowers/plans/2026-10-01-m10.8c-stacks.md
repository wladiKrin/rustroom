## Task 1: the catalog

- `schema.rs`: `from < 11` → `photo_stacks (folder_id … ON DELETE CASCADE, file_name, stack_id INTEGER
  NOT NULL, top INTEGER NOT NULL DEFAULT 0, PRIMARY KEY (folder_id, file_name))`; `SCHEMA_VERSION = 11`;
  the roll-back tests drop it too.
- `db/stacks.rs`: `hand_stacks_in(folder) -> Vec<(PathBuf, i64, bool)>`, `set_hand_stack(photo,
  Option<(i64, bool)>)` (upsert or delete), `next_stack_id() -> i64`.
- `moves.rs`: `"photo_stacks"` joins `PER_FILE_TABLES`.
- `snapshot.rs` + `restore.rs`: the folder snapshot carries `stacks: Vec<(String, i64, bool)>`.
- Tests: round trip and removal; `next_stack_id` grows; a move carries it; forget + restore brings it
  back. Commit.

## Task 2: the lib

- `stack.rs`: `pub type HandStacks = HashMap<PathBuf, (i64, bool)>`; `key_for(path, remote, hand)` —
  hand first (`(dir, "hand:<id>")`), then `key_of_with`. `group(entries, s, expanded, remote, hand)`:
  a hand-keyed row always takes part (name/remote keys only when `enabled` and the format takes part);
  a collapsed hand stack shows its top member if it has one. `stacked_keys(entries, remote, hand)`.
- `stack_by_hand.rs` (`pub mod`): `type Change = (PathBuf, Option<(i64, bool)>)`;
  `stack(files, top, current, next_id) -> Vec<Change>`; `unstack(files, current)`; `make_top(file,
  current)`; `by_capture_time(files_with_times, gap_secs, current, next_id)`; `tidy(current, changes)`
  — appended dissolutions for any stack left under two.
- Tests (spec list). Commit.

## Task 3: the app

- `library_state.rs`: `Library::hand_stacks: HandStacks`, loaded (`reload_hand_stacks`, one query per
  folder) before entries are built in `open_scan` and passed by `browser_entries`/`rebuild_entries`.
- `move_flow::files_to_move` and `status_bar`'s `stacked_keys` use the shared key.
- `action_log.rs`: `ActionKind::StackChange { changes: Vec<(PathBuf, Option<(i64, bool)>, Option<(i64,
  bool)>)> }`, global.
- `stack_ops.rs` (bin, new): the files of a set of ids; `stack_selection`, `unstack_selection`,
  `make_top_of_stack(index)`, `stack_by_capture_time(secs)`; `apply_stack_changes` (write, push one
  step, reload, rebuild, status); `replay_stack_change`.
- `menu.rs`: Photo → Stack ⌘G, Unstack ⇧⌘G, Make top of stack, *Stack by capture time* submenu;
  `Command::{Stack, Unstack, MakeTopOfStack, StackByTime(u32)}`. `commands.rs`, `undo.rs`.
- `cell_menu.rs`: the same four, on the targets (Stack with two or more; Unstack and Make top only on a
  hand-stack member).
- Tests (spec list). Commit.

## After use — tasks

5. **Badge key** (`library/cell.rs`): `key_for(path, remote, hand)` — `CellInputs` carries both maps.
   Test: a click on a hand stack's badge unfurls it (drawn grid).
6. **Catalog v12**: `photo_stacks` rebuilt with `ord`, `by_time` (`ROW_NUMBER() OVER (PARTITION BY
   stack_id ORDER BY top DESC, file_name) - 1`); `HandMember { stack, ord, by_time }`; the snapshot
   carries both. Test: a v11 catalog keeps its stacks, top as order 0.
7. **Lib**: `HandStacks` of `HandMember`; `group_with` orders a hand stack's members by `ord`, collapses to
   the lowest, and `group_with_below` also returns each collapsed row's members below it, in order;
   `stack_by_hand`: `set_order` (reuse the id if all share one, else a new one; `by_time: false`),
   `make_top` via it, `by_capture_time(files, gap: Option<i64>, …)` with the layer rules. Tests.
8. **App**: `StackByTime(Option<u32>)` with *None* first; `move_in_stack(from, to)` (adopts a name stack,
   keeps it unfurled); `StackDrag { Drag, AltDrag }` in Settings → Input; the drag in `cell.rs`
   (payload, target stroke, `out.stack_move`). Tests: None, replace, manual untouched; a drawn drag
   reorders; a name pair reordered becomes a hand stack, still unfurled.
9. **Pile**: `Stacking.look: StackLook { Peek, Cards, Off }` (Appearance; `Off` = no pile, added after use); `cell_layout::pile(count, cell)`
   (layers ≤ 7, step); `thumb::cell_with` paints the layers behind a shrunk picture; peek requests the
   below members' thumbnails. Tests: the geometry; peek requests them, cards does not; the drawn cell
   paints `count − 1` layers (≤ 7).
