# M10.9b — user-defined keyboard shortcuts: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** Any menu command can be given any recordable chord in Settings → Keyboard; a taken chord moves
to it; every reader of a shortcut — the key handler, both menu bars, the reference, hover text — follows.

**Architecture:** `Settings::shortcuts` stores only the changed bindings, keyed by `command_key`;
`menu::model_for(recent, overrides)` is the one bound model every reader uses; `shortcuts.rs` (lib) owns
take-over, reset and refusal; the tab (bin) records chords into the Settings draft.

**Spec:** `docs/superpowers/specs/2026-10-10-m10.9b-shortcuts-design.md`.

**Gate:** `$SCRATCH/gate.sh` (exits non-zero unless fmt, clippy and tests all pass) — `gate.sh && git
commit`. Filters after `--` as a zsh array, with a control count. **Sabotage only a committed tree;
restore the OLD code, not a loosened new one.**

## Task 1: the chord model

**Files:** `crates/app/src/menu.rs`.

- [ ] `Shortcut`: `#[derive(…, Hash, serde::Serialize, serde::Deserialize)]`, `#[serde(default)] pub alt:
  bool`; constructors set `alt: false`; `pub const fn with_alt(self) -> Self`. `pub const F1: char =
  '\u{F704}'` … (`fn_key(n)`), `key_name` → "F1"…"F12". `label`: macOS `⌥⇧⌘`-order (`⌥` before `⇧`),
  others `Ctrl+Alt+Shift+`. `safe_as_native_accelerator` unchanged (⌥ is fine).
- [ ] `pub fn model_for(recent: &[PathBuf], overrides: &[crate::shortcuts::Rebinding]) -> Vec<Section>`
  — `model_with` then `shortcuts::apply`.
- [ ] Tests: labels for `⌥⌘S`, `F5`, `⇧F12`; a `Shortcut` round-trips through JSON and an old one
  without `alt` reads.

## Task 2: `shortcuts.rs`

**Files:** create `crates/app/src/shortcuts.rs` (`pub mod` in `lib.rs`); `settings/mod.rs`
(`pub shortcuts: Vec<Rebinding>`), `settings/compat_tests.rs`.

- [ ] `Rebinding { command: String, shortcut: Option<Shortcut> }` (serde). `command_key(c) ->
  String` = `format!("{c:?}")`. `apply(sections, overrides)` rewrites each `Item::Action`'s shortcut
  whose key has an override. `shortcut_of(c, overrides)` (through `model_for(&[], …)`, so a
  recent-folder command reads its default). `default_of(c)`.
- [ ] `FIXED: [Command; 4]` = Undo, Redo, CopySettings, PasteSettings. `refusal(sc) -> Option<&'static
  str>`: culling (bare or ⇧ + 0–9/P/X/U) "Rates and flags photos"; ⌘A "Selects all"; ⌘X "Cuts"; ⌘Q
  "Quits"; ⌘H "Hides the app"; ⌘M "Minimises the window"; ⌘W "Closes the window"; a fixed command's
  chord "Is <label>'s, kept for the system". 
- [ ] `assign(overrides, c, sc: Option<Shortcut>) -> Option<Command>`: when `sc` is set, find the command
  holding it in the bound model (not `c`), set that one to `None`; then set `c`. An override equal to the
  default is removed (keeps the list minimal). `reset(overrides, c)`, `reset_all`.
- [ ] Tests: override replaces and `None` removes; take-over returns the loser and clears it; reset;
  refusals (each class); an entry for an unknown command is ignored; every command key unique; a
  default-equal override drops out; Settings round-trip with a non-default list.
- [ ] Gate, commit `feat(app): shortcuts — overrides over the menu's defaults, take-over, refusal
  (M10.9b)`.

## Task 3: every reader follows the bindings

**Files:** `shell/keys.rs`, `shell/mod.rs`, `menu_bar.rs`, `native_menu.rs`, `bootstrap.rs`,
`sources.rs`, `modals/mod.rs` (reference), `theme.rs` (glyph audit uses `model_with` — keep defaults),
the hover sites (`develop/mod.rs`, `develop/canvas/mod.rs`, `shell/top_bar.rs`, `library/mod.rs`).

- [ ] `keys.rs`: `pressed_command(ctx, overrides)` walks `model_for(&[], overrides)`; the full map
  `egui_key(char)` and its inverse `key_char(egui::Key) -> Option<char>` over A–Z, 0–9, punctuation,
  F1–F12; ⌥ compared too; the alias only when no bound shortcut is a bare `Y`.
- [ ] `menu_bar::show(ui, recent, overrides, state)`; `native_menu::install/refresh(ctx, recent,
  overrides, accelerators: bool)` with the full `Code` map, ⌥, and Settings… from `shortcut_of(Settings)`.
- [ ] `RustroomApp::shortcut_hint(c) -> String` — `" (⌘1)"` or `""`; the ~10 hover sites use it.
- [ ] Sweep test (`theme::tests::production_code` pattern): no string literal in bin code contains a
  `⌘`/`⇧⌘` chord inside parentheses.
- [ ] Tests: a rebound chord fires the new command and the old one does not; an alias yields to a bound
  `Y`; `key_char(egui_key(c)) == c` for every recordable char.
- [ ] Gate, commit `feat(app): the key handler, both menu bars, the reference and hover text follow the
  bindings (M10.9b)`.

## Task 4: Settings → Keyboard

**Files:** create `modals/settings_keyboard.rs`; modify `modals/settings.rs` (draft field `keyboard:
KeyboardDraft`, tab "Keyboard", apply → `settings.shortcuts`, native refresh; Esc taken while
recording), `app.rs` (`native_accelerators_off: bool`).

- [ ] `KeyboardDraft { overrides, recording: Option<Command>, filter: String, note: Option<(Command,
  String)> }`. `show(ui, d)`: search; per menu section a header; rows: label (submenu path), a button
  with the chord or "—" (accessible name `"Shortcut for {label}"`, hover "Click, then press the new
  keys"), ↺ when changed; fixed rows disabled with their reason; note line; "Reset all".
- [ ] Recording: read this frame's `Event::Key { pressed: true }` → Delete/Backspace clear, a mapped key
  builds a `Shortcut` (cmd, shift, alt) → `refusal` → note, else `assign` → note "Taken from {label}".
  The recording button holds focus, so `pressed_command` is gated off.
- [ ] `settings::show`: before `dialog`, if recording and Esc pressed → consume Esc, stop recording.
  On recording on/off → `native_menu::refresh(…, accelerators: !recording)` (macOS only).
- [ ] Tests (drawn): click "Shortcut for Take snapshot", press ⌥⌘S → set; press a chord another command
  has → moved, note names it; press `5` → refused note; Esc cancels and Settings stays open; ↺; Reset
  all; Apply writes `settings.shortcuts`.
- [ ] Gate, commit `feat(app): Settings → Keyboard — record a chord, take-over, reset (M10.9b)`.
