# M10.9c — import Lightroom presets: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** Import presets… reads Lightroom `.xmp`, `.lrtemplate` and `.zip` packs, mapping each setting
with a Rustroom counterpart, filing each preset under its Lightroom group, as one undo step.

**Architecture:** A new GUI-free crate `lr-preset` turns each file into `Imported { name, group, mapped
}` — two readers into one `Settings` map, a zip walker, and one mapping table; the app's
`import_presets` dispatches by extension and keeps its undo and naming.

**Tech Stack:** Rust, `quick-xml` (as the `xmp` crate), `flate2` (already in the build), `edit-model`,
`color` (Oklab).

**Spec:** `docs/superpowers/specs/2026-10-10-m10.9c-lightroom-presets-design.md`.

## Global Constraints

- No egui in `lr-preset`; nothing in the app crate parses a Lightroom file.
- No new crates downloaded: `flate2` at the version already in `Cargo.lock`.
- Every fixture is real and says where it came from (`crates/lr-preset/tests/fixtures/README.md`);
  committed only under a licence compatible with GPL-3.0; the unlicensed Lightroom-written
  `.lrtemplate`s are used locally only (`#[ignore]`, `LR_PRESET_SAMPLES`).
- A broken file is an error or a count, never a panic.
- Gate: `$SCRATCH/gate.sh && git commit`; filters after `--`; sabotage only a committed tree.

## Review Focus

1. **A zip from macOS carrying `__MACOSX/._Name.xmp` resource forks** — skipped silently, not counted
   as "not a preset" and never imported. (Task 3 test.)
2. **A Lightroom *profile* `.xmp` (`crs:PresetType="Look"`) or a photo's XMP sidecar picked by
   mistake** — not a develop preset: counted, not imported as an empty preset. (Task 1 test.)
3. **A preset with no `crs:Name` / `title`** — named after its file. (Task 1 and 2 tests.)
4. **An `.lrtemplate` in Latin-1 or with a UTF-8 BOM, or a `.xmp` with CRLF line ends** — read, not
   refused. (Task 2 test; Task 1 test.)
5. **The same preset name in two folders of one pack, or twice in one folder** — kept apart by folder,
   numbered within one. (Task 5 test.)

## Task 1: the crate, the fixtures, `Settings` and the `.xmp` reader

**Files:** create `crates/lr-preset/{Cargo.toml,src/lib.rs,src/value.rs,src/xmp.rs}`,
`crates/lr-preset/tests/fixtures/{README.md,questtion/LICENSE,questtion/*.xmp}`; workspace `Cargo.toml`
members.

**Interfaces:** Produces `pub enum Value { Num(f64), Text(String), Bool(bool), List(Vec<Value>) }`,
`pub type Settings = BTreeMap<String, Value>`, `pub struct Raw { pub name: Option<String>, pub group:
Option<String>, pub settings: Settings }`, `pub fn xmp::read(text: &str) -> Result<Raw, Error>`,
`pub enum Error { NotAPreset(&'static str), Malformed(String) }`.

- [ ] Download (curl) three Questtion presets — the richest: one with colour grading, one with HSL, one
  with a custom tone curve — and its `LICENSE`; write the fixtures README (source URL, commit, licence).
- [ ] `Value` helpers: `num()`, `text()`, `as_bool()` (`"True"`/`true`). `xmp::read`: `NsReader`; the
  `crs:` attributes of an `rdf:Description` (values: number when it parses — `"+0.30"` too — else
  `True`/`False` → bool, else text); child `crs:Name`/`crs:Group` → the first `rdf:li`; `crs:ToneCurvePV2012`
  and `…Red/Green/Blue` → `List` of the `"x, y"` numbers flattened; `crs:Look` → `Settings["Look"] =
  Text(name)`. Not a preset: no `crs:` namespace at all (a photo sidecar), or `crs:PresetType="Look"`.
- [ ] Tests on the real files: name, group, `Exposure2012`, a curve's points, `HasSettings`; a profile
  `PresetType="Look"` (the fixture with the attribute swapped in a test string built from a real file) and
  a Rustroom sidecar → `NotAPreset`; a nameless one keeps `name: None`; CRLF read; truncated XML →
  `Malformed`, no panic.
- [ ] Gate, commit.

## Task 2: the `.lrtemplate` reader

**Files:** `crates/lr-preset/src/lrtemplate.rs`; fixture `yuzukumo/minimal.lrtemplate` (+ licence note).

**Interfaces:** `pub fn lrtemplate::read(text: &str) -> Result<Raw, Error>`.

- [ ] A tokenizer + recursive reader for `s = { … }`: identifiers, `["key"]`, strings (`"…"` with `\"`,
  `\\`, `\n`), numbers (sign, decimals, exponent), `true`/`false`, `{ … }` (keyed → map, positional → list),
  `,`/`;`, `--` comments. Name from `title`, else `internalName`; settings from `value.settings` (numbers,
  bools, text, lists of numbers).
- [ ] Bytes in: `read_bytes(&[u8])` decodes UTF-8 (BOM stripped), else Latin-1.
- [ ] Tests: the GPL fixture (title, `Exposure2012`, the curve list, `Temperature`); a BOM and a Latin-1
  `é` title; truncated → `Malformed`; `#[ignore] fn real_lightroom_templates()` reads every `.lrtemplate`
  under `$LR_PRESET_SAMPLES` and asserts each parses with a name and ≥1 setting (run locally, result to
  the journal).
- [ ] Gate, commit.

## Task 3: the zip walker

**Files:** `crates/lr-preset/src/zip.rs`; fixture `questtion.zip` (GitHub's archive of the repo).

**Interfaces:** `pub fn zip::entries(bytes: &[u8]) -> Result<(Vec<(String, Vec<u8>)>, usize), Error>` —
the files (path, bytes) and how many could not be read.

- [ ] End-of-central-directory search (last 64 KiB), the central directory, each local header; methods 0
  (stored) and 8 (deflate, `flate2::read::DeflateDecoder`); encrypted (flag bit 0), zip64 or other methods
  counted. Paths `/`-separated; `__MACOSX/` and `._*` skipped silently; directories skipped.
- [ ] Tests: the real archive lists its `.xmp`s under their folder, each byte-identical to its own
  committed copy; a macOS resource fork (a real entry renamed in a test-built zip — stored method, built
  by hand **from the real file's bytes**) is skipped; a truncated archive → `Malformed`.
- [ ] Gate, commit.

## Task 4: the mapping

**Files:** `crates/lr-preset/src/map.rs`.

**Interfaces:** `pub struct Mapped { pub edits: Edits, pub groups: EditGroups, pub left_out:
Vec<&'static str> }`, `pub fn map::to_edits(s: &Settings) -> Mapped`.

- [ ] The table (spec §map). Groups: `white_balance` ← Temperature/Tint/WhiteBalance; `tone` ← the
  2012 tone sliders, curves, parametric, Texture, Clarity2012, Dehaze; `color` ← Vibrance, Saturation,
  HSL, colour grading, split toning, ConvertToGrayscale; `detail` ← sharpening, NR; `vignette` ←
  PostCropVignette*; `lens` ← LensProfileEnable.
- [ ] Hue: LR hue `h` (degrees) → sRGB of HSV(h, 1, 1) → Oklab → `atan2(b, a)` in degrees, 0..360.
- [ ] Left out (only when non-neutral): `GrainAmount` ≠ 0 → "grain"; any `MaskGroupBasedCorrections` /
  `PaintBasedCorrections` / `GradientBasedCorrections` / `CircularGradientBasedCorrections` → "masks";
  `HasCrop` true → "crop"; `Look` present or `CameraProfile` ≠ "Adobe Standard"/"Adobe Color" → "the
  profile"; `WhiteBalance="Auto"` → "Auto white balance"; `IncrementalTemperature`/`IncrementalTint` ≠ 0 →
  "a relative white balance"; `ConvertToGrayscale` with any `GrayMixer*` ≠ 0 → "the black & white mix";
  `ProcessVersion` < 10 with `Exposure` (no 2012) → "settings of the pre-2012 process".
- [ ] Tests on the real files: the groups exactly; exposure; a curve point /255; a colour-grading hue
  (red 0° lands where Oklab puts sRGB red, ~29°); a zero grain not reported, a non-zero one reported.
- [ ] Gate, commit.

## Task 5: `read` and the app

**Files:** `crates/lr-preset/src/lib.rs` (`read`), `crates/app/Cargo.toml`, `crates/app/src/preset_ops.rs`.

**Interfaces:** `pub struct Imported { pub name: String, pub group: Option<String>, pub mapped: Mapped
}`, `pub struct Report { pub presets: Vec<Imported>, pub not_presets: usize, pub unreadable: usize }`,
`pub fn read(file_name: &str, bytes: &[u8]) -> Report`.

- [ ] `read`: by extension; zip → each entry by its own extension, group from its folder; name falls back
  to the file stem.
- [ ] `import_presets(files, into)`: `.json` as before; others through `lr_preset::read`; folder = `into`
  else the preset's group (`folder_name`, made — recorded in the undo's after-folders) else top level;
  `unique_name` per folder; status names presets, folders, left-out counts and not-presets. Picker filter
  `json, xmp, lrtemplate, zip`.
- [ ] Tests: the real `.xmp` into its group's folder; the real zip → folder(s) and count; one undo step
  removes presets and the made folders; same name twice in one folder numbered, in two folders not.
- [ ] Gate, commit.
