# M10.10a — an image watermark: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** Export → Watermark offers Text · Image; Image lays a copy of a chosen PNG/JPEG/TIFF/WebP in the
corner at a width that is a share of the long edge, blended by its own alpha × the opacity.

**Architecture:** The export crate owns the settings, the decoded `Logo` and the compositing (no GUI); the
app's lib keeps the copies (`watermark_store`) and resolves the logo once per run on the worker thread; the
bin draws the section and runs the file picker.

**Tech Stack:** Rust, `image` 0.25 (decode, Lanczos3 resize — already in the tree), `color::OutputSpace`.

**Spec:** `docs/superpowers/specs/2026-10-11-m10.10a-image-watermark-design.md`.

## Global Constraints

- No egui in `export` or in any `crates/app/src` lib module; the picker (`rfd`) only in the bin.
- No new crates; `image` at the workspace's version and features (`png`, `jpeg`, `tiff`, `webp`).
- Settings stay readable: an options file or export preset without the new fields reads as Text, width 15.
- The stored name is a bare file name; nothing outside the store is ever read through it.
- A broken or missing logo is a note in the report, never a panic and never a failed photo.
- Hover text: one short sentence, no full stop (`docs/DESIGN.md` §8).
- Gate: `$SP/gate.sh > $SP/gate.out 2>&1; rc=$?` then commit only on `rc == 0`; filters after `--`;
  sabotage only a committed tree; never `git checkout` uncommitted work.

## Review Focus

1. **A preset made on another machine, or a copy deleted from the store** — the export runs without the
   mark and the status says which image could not be read. (Task 3 test.)
2. **A hand-edited name — `../../etc/x.png`, an absolute path** — never read outside the store; the note.
   (Task 2 test, on the derived path.)
3. **A logo with soft, anti-aliased edges over a coloured hole** — resized premultiplied, so no fringe of
   the hidden colour. (Task 1 test.)
4. **A DNG export** — the logo converted into ProPhoto (`fixed_space`), the space the buffer is in, not the
   dialog's. (Task 3 test.)
5. **The same file chosen twice** — one copy, not `logo-1.png`; a different file of the same name gets `-1`.
   (Task 2 test.)

## Task 1: the settings, `Logo`, and drawing it (export crate)

**Files:** `crates/export/src/watermark.rs` (settings, `apply`), create `crates/export/src/watermark/logo.rs`;
`crates/app/src/batch_export/render.rs` (the call gains `None`), `options.rs` (test literal).

**Interfaces — produces:**
- `pub enum WatermarkKind { #[default] Text, Image }` with `ALL` and `label()` ("Text", "Image").
- `Watermark { …, pub kind: WatermarkKind, pub image: String, pub image_width: u8 }`; `IMAGE_WIDTH_RANGE:
  (u8, u8) = (2, 50)`; default width 15. `is_active`: Text → as before; Image → `!image.trim().is_empty() &&
  opacity > 0`.
- `pub struct Logo` — `decode(bytes: &[u8], space: color::OutputSpace) -> Result<Logo, String>`, `width()`,
  `height()`, `pixel(x, y) -> [f32; 4]` (premultiplied, encoded in `space`). Longer than `MAX_LOGO` (4096 px)
  → shrunk once at decode.
- `pub fn apply(image: &mut ImageBuf, mark: &Watermark, logo: Option<&Logo>)`.

- [ ] Tests first, in `logo.rs` (PNG bytes built in the test with `image::RgbaImage` →
  `DynamicImage::write_to(Cursor, Png)`):
  - `a_transparent_hole_leaves_the_photo_untouched`: a 40×20 logo, left half `(255,0,0,0)` (red, fully
    transparent), right half opaque white, on grey 0.5 at opacity 100 → some pixel ≥ 0.99 and **no pixel
    with r > g + 0.02** (catches alpha ignored and a straight-alpha resize fringe).
  - `opacity_scales_the_blend`: opaque white logo on 0.5 → the brightest pixel ≈ 1.0 at 100 and ≈ 0.75 at
    50 (±0.01).
  - `the_width_follows_the_long_edge`: width 20 → inked column span 80 on 400×300, 160 on 800×600, and 80
    on a portrait 300×400, whose long edge is its height (±1).
  - `the_logo_lands_in_its_corner`: every changed pixel in the asked-for quadrant, for all four corners.
  - `a_p3_export_moves_red_by_the_matrix`: `Logo::decode(red png, DisplayP3).pixel(0,0)` ≠ `[1,0,0,1]` by
    > 0.05 first, then equals `DisplayP3.convert_srgb8([255,0,0])/255` within 1/255; Srgb is exact.
  - `a_logo_that_does_not_fit_is_skipped`: a 10×40 logo at width 50 on 40×30 → unchanged.
  - `a_broken_file_is_an_error`: `b"not an image"` and the first half of a real PNG → `Err`, no panic.
  - `a_huge_logo_is_shrunk_once`: 5000×10 → width 4096.
  - In `watermark.rs`: `old_settings_read_as_text` (JSON without the new fields → Text, `""`, 15);
    `each_kind_draws_only_itself` (Image with no logo → unchanged; Text with empty text and a logo →
    unchanged); `image_is_active_only_with_a_file_and_opacity`.
- [ ] Run: `cargo test --workspace --offline -- watermark` → FAIL (does not compile: no `Logo`, `kind`).
- [ ] Implement: `mod logo; pub use logo::Logo;` in `watermark.rs`. `Logo` holds an `image::Rgba32FImage`,
  premultiplied. Decode: `image::load_from_memory` → `to_rgba32f()`; per pixel, when `space != Srgb`,
  `encode(from_srgb(srgb_to_linear(c)))`; premultiply; if `max(w,h) > MAX_LOGO`, resize once. `draw`:
  `tw = round(long·width/100)`, `th = round(tw·h/w)` (≥ 1); skip unless `tw + 2m ≤ w && th + 2m ≤ h`
  (`m = round(long·MARGIN)`); `imageops::resize(Lanczos3)`; clamp `a` to `[0,1]` and each channel to
  `[0,a]`; `dst = dst·(1 − a·op) + c·op`. `apply` dispatches on `kind`. The module doc's "Text only"
  paragraph is replaced. Every existing call gains `, None`.
- [ ] Run the same filter → PASS; the existing watermark tests unchanged in what they assert.
- [ ] Gate, commit `feat(export): an image watermark — Logo decoded into the export's space, resized
  premultiplied, blended by its alpha (M10.10a)`.

## Task 3: the run reads the logo once and draws it (worker, render, flow)

**Files:** `batch_export/worker.rs` (`ExportDirs`, `Batch`, `resolve_logo`, `ExportReport::{notes,

`export_flow.rs`, `preview_build.rs`, `preview_flow.rs` (callers).

**Interfaces:**
- Consumes: `Logo::decode`, `apply(…, Some(&logo))`, `WatermarkStore::path_of`.
- Produces: `#[derive(Default)] pub struct ExportDirs { pub looks: Option<PathBuf>, pub watermarks:
  Option<PathBuf> }` replacing `spawn`'s `looks_dir`; `ExportReport::notes: Vec<String>`;
  `ExportReport::summary(&self) -> String` (the status line, moved from `export_flow`);
  `export_one(…, look, logo: Option<&export::watermark::Logo>)`.

- [ ] Tests first (worker): a run with `kind: Image`, `image: "logo.png"` (an opaque red PNG written into a
  temp store), format `Png8`, source `flat(200, 100)` → read back; against a twin run without the mark, every
  differing pixel lies in the bottom-right quadrant and some are red. A missing `gone.png` → `exported == 1`
  and `notes == ["the watermark image gone.png could not be read"]`. A text-mark run with no store → no
  note. `resolve_logo` for a DNG export with `space: Srgb` equals `Logo::decode(…, ProPhoto)`. `summary`:
  `Exported 2, 1 skipped` unchanged; a note appended after a comma.
- [ ] Run: `cargo test --workspace --offline -- batch_export` → FAIL (does not compile).
- [ ] Implement. `spawn(…, dirs: ExportDirs, upload)`; on the worker thread `Batch { looks:
  resolve_looks(&jobs, dirs.looks), logo: resolve_logo(&opts, dirs.watermarks) }`; `run` takes `&Batch` in
  place of `looks` and pushes the note into the report before planning. `resolve_logo`: `Ok(None)` unless
  `kind == Image && is_active()`; the space is `opts.format.fixed_space().unwrap_or(opts.space)`; any miss

  `WatermarkStore::user_default(config).dir()` and sets `status = r.summary()`.
- [ ] Run → PASS. Gate, commit `feat(app): an export reads its image watermark once and draws it; a missing
