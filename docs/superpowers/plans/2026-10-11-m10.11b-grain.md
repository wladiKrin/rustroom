# M10.11b — Grain: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.
> **Commits carry no `Co-Authored-By` trailer. Never push.**

**Goal:** Effects → Grain (Amount, Size, Roughness): luminance grain in stops, strongest in the midtones,
the same on the photo at any render scale and in any region, on the CPU and the GPU; Lightroom presets'
grain maps across.

**Architecture:** `edit_model::Grain` in the vignette group (shown as Effects) → `pipeline` tail stage
after sharpening, its noise and parameters in one place the GPU reads → a WGSL twin in `REPLACEABLE` → the
panel's Effects body in its own module → `lr-preset`'s mapping.

**Tech Stack:** Rust, WGSL (wgpu), egui.

**Spec:** `docs/superpowers/specs/2026-10-11-m10.11b-grain-design.md`.

## Global Constraints

- `out = p · 2^(A · n · w(L))`; `A = amount/100 · MAX_EV`, `MAX_EV = 0.5`; `w(L) = 4L(1−L)`, `L =
  linear_to_srgb(luminance(p)).clamp(0, 1)`.
- Cell = `(1 + 4·size/100) · scale` buffer pixels; below 1, sampled at 1 and the amplitude × cell.
- Roughness: octave 2 at half the cell, offset by (17.3, 41.9) cells, mixed `n = ((1−r)·n1 + r·n2) /
  sqrt((1−r)² + r²)`.
- Hash: integer only (`u32` wrapping), the same on CPU and GPU; fixed seed.
- The field stays `vignette`; `EDIT_GROUP_NAMES[5]` reads *Effects*. A default `Grain` is not serialized.
- No egui outside the bin; no new crates; hover text one sentence, no full stop.
- Gate unpiped, commit on `rc == 0`; sabotage only a committed tree, `--no-fail-fast`.
