# M10.12a — The flat composite, made usable — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Change a mask row's op in place, Duplicate (and Duplicate and invert) a mask, and invert a whole composite — with nesting parked on a measured table.

**Architecture:** One new serialized flag, `MaskedAdjustment::invert`, applied after the fold in the three places that fold a mask's rows (CPU `Composite::at`, the GPU's generated `coverage` shader, the Show-mask tint), with its three named traps pinned by sabotaged tests. The panel's new rules live in a no-egui lib module `mask_actions`; the right-click menus and the "Invert mask" checkbox are thin bin code over it.

**Tech Stack:** Rust workspace; `edit-model` (serde), `pipeline` (CPU stages, prefix cache keys), `gpu-pipeline` (WGSL text generation), `app` (egui 0.35 bin + lib).

**Spec:** `docs/superpowers/specs/2026-10-12-m10.12a-mask-composites-design.md`

## Global Constraints

- Build/test env: every cargo command runs after
  `export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:/opt/homebrew/opt/libraw/lib/pkgconfig:/opt/homebrew/opt/little-cms2/lib/pkgconfig:$PKG_CONFIG_PATH"`.
- **One cargo mode:** always `cargo test --workspace <name-filter>`, never `-p`. Clippy in its own dir:
  `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings`.
- A filtered run must report `N passed` with **N > 0** — a filter matching nothing exits 0.
- The flag: `#[serde(default, skip_serializing_if = "std::ops::Not::not")] pub invert: bool` — an
  uninverted mask writes the bytes it always did.
- Coverage under the flag is `1 − fold(base, refinements)`, applied after the last refinement.
- `lib.rs` modules have **no egui**. Hover sentences: one sentence, ≤110 chars, no full stop, no `;`.
- The "Invert mask" hover is exactly: `Inverts the whole mask so it covers what its shapes leave out`.
- Menu items: mask row → `Duplicate`, `Duplicate and invert`; component row (not the base) → radio
  items `Add`, `Subtract`, `Intersect` (`MaskOp::label`).
- Commit messages carry **no** `Co-Authored-By` trailer. Never push.
- Sabotage protocol: take a `cp` backup of the file first, sabotage, run the named test, restore with
  `cp` (**never** `git checkout -- <file>`, which destroys uncommitted work), re-run green.

## Review Focus

1. **A right-click is not a click.** Right-clicking a mask row must open its menu without selecting,
   deselecting or dragging it — pinned in Task 7 (`a_right_click_opens_the_menu_without_selecting`).
2. **The base row has no op.** Right-clicking the base component row must offer no Add/Subtract/
   Intersect items — pinned in Task 7 (`the_base_row_offers_no_op`).
3. **Eyes stay aligned on Duplicate** when `shown` is shorter than the mask list (it arrives short after
   an undo, a paste or a snapshot) and when the last mask is duplicated — pinned in Task 6.
4. **A live flag is never hidden.** A composite inverted then cut back to one shape keeps "Invert mask"
   drawn, and "Duplicate and invert" of it flips the flag, not the shape — pinned in Task 6.
5. **A switched-off mask stays off when inverted.** "Off" is skipping the stage; a refactor reading off
   as zero coverage would invert to *full* — pinned in Task 2
   (`a_switched_off_inverted_mask_changes_nothing`).

//! What the masks panel's right-click menus and its "Invert mask" box do to the edits: change a
//! row's op, duplicate a mask, and flip a mask's inversion (M10.12a).
//!
//! ⚠ No egui. The menus and the checkbox live in `develop/panel/{masks,mask_components}.rs`;
//! everything they *decide* is here, where it can be tested without a window — `mask_order`'s rule.

use edit_model::{MaskOp, MaskedAdjustment};

/// Set row `j`'s op — `0` is the base, `j > 0` the `j-1`th refinement.
///
/// Returns whether anything changed: `false` for the base (it has no op — it is the Add every other
/// row folds onto, `mask_order`'s top-row rule), an out-of-range row, or the op it already has, so
/// the caller records an undo step only for a real change.
pub fn set_op(m: &mut MaskedAdjustment, j: usize, op: MaskOp) -> bool {
    let Some(r) = j.checked_sub(1).and_then(|k| m.refine.get_mut(k)) else {
        return false;
    };
    if r.op == op {
        return false;
    }
    r.op = op;
    true
}

/// Whether the panel draws "Invert mask" for `m`.
///
/// ⚠ For a composite, and for any mask whose flag is on — so a composite inverted and then cut back
/// to one shape never hides a live flag. A one-shape mask otherwise has only its shape's Invert,
/// which is the same coverage (the author's call, 2026-10-12).
pub fn whole_invert_drawn(m: &MaskedAdjustment) -> bool {
    !m.refine.is_empty() || m.invert
}

/// Flip the inversion the panel shows for `m` as a whole: the mask's own flag where "Invert mask"
/// is drawn, the shape's own Invert otherwise. Exact either way — on one shape they coincide.
pub fn flip_whole_invert(m: &mut MaskedAdjustment) {
    if whole_invert_drawn(m) {
        m.invert = !m.invert;
    } else {
        let f = m.mask.invert_mut();
        *f = !*f;
    }
}

/// Insert a copy of mask `i` directly below it, select the copy and show its overlay — what the
/// panel does for a mask it adds itself. With `invert`, the copy covers what the original leaves
/// out ([`flip_whole_invert`]). Returns whether anything changed (`false` for an `i` out of range).
///
/// ⚠⚠ `shown` is index-aligned with `masks` (`Session::mask_shown`) and is padded to the masks'
/// length **before** the insert, `move_mask`'s rule — it arrives short after an undo, a paste or a
/// snapshot, and inserting into a short list would hand every later mask its neighbour's eye.
pub fn duplicate(
    masks: &mut Vec<MaskedAdjustment>,
    shown: &mut Vec<bool>,
    selected: &mut Option<usize>,
    i: usize,
    invert: bool,
) -> bool {
    let Some(src) = masks.get(i) else {
        return false;
    };
    let mut copy = src.clone();
    if invert {
        flip_whole_invert(&mut copy);
    }
    shown.resize(masks.len(), false);
    masks.insert(i + 1, copy);
    shown.insert(i + 1, true);
    *selected = Some(i + 1);
    true
}

/// Right-click at `at`, then run one more frame so a context menu it opened is laid out.
///
/// ⚠ egui opens a context menu on the **release** of the secondary button, and draws it on the frame
/// after — so three frames, the last with no input.
pub fn right_click_at(ctx: &egui::Context, at: egui::Pos2, mut body: impl FnMut(&mut egui::Ui)) {
    let button = |pressed| egui::Event::PointerButton {
        pos: at,
        button: egui::PointerButton::Secondary,
        pressed,
        modifiers: Default::default(),
    };
    for events in [
        vec![egui::Event::PointerMoved(at), button(true)],
        vec![button(false)],
        Vec::new(),
    ] {
        let _ = ctx.run_ui(
            egui::RawInput {
                screen_rect: Some(screen()),
                events,
                ..Default::default()
            },
            &mut body,
        );
    }
}

/// [`right_click_at`] the widget labelled `label`. Panics if no such widget was drawn.
pub fn right_click(ctx: &egui::Context, label: &str, mut body: impl FnMut(&mut egui::Ui)) {
    let at = find(ctx, label, &mut body)
        .unwrap_or_else(|| panic!("no widget labelled {label:?} was drawn"));
    right_click_at(ctx, at, body);
}
