# M10.12b1 — A mask's scene sliders as offsets: the stage, the GPU twin, the panel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mask's Exposure, Contrast, Highlights, Shadows, Whites, Blacks and (relative) Temp/Tint act as per-pixel offsets to the global sliders, at the global stages' own position, on CPU and GPU.

**Architecture:** One tail stage, `SceneOffsetsStage`, replaces the four global scene stages when any active mask carries a scene offset; per pixel it sums `global + Σ coverage_i × offset_i` and applies the four stages' own arithmetic through functions they now share. Each mask's coverage comes from a coverage-only `MaskStage::coverage_plane`. `MaskStage` keeps only the look sliders. A GPU twin generates one shader with every mask's coverage chain.

**Tech Stack:** Rust; `edit-model`, `pipeline`, `gpu-pipeline` (WGSL), `app` (egui panel).

**Spec:** `docs/superpowers/specs/2026-10-12-m10.12b-mask-offsets-design.md` (part b1; b2 has its own plan).

## Global Constraints

- Env: `export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:/opt/homebrew/opt/libraw/lib/pkgconfig:/opt/homebrew/opt/little-cms2/lib/pkgconfig:$PKG_CONFIG_PATH"`.
- `cargo test --workspace <filter>` only; N > 0 passed. Clippy in `target/clippy`. Goldens: `cargo test --workspace --test golden`.
- `MIRED_PER_STEP = 1.0` (a first value, the author tunes it). `+temp` = warmer = the global Kelvin raised:
  `mired' = mired(global) − temp × MIRED_PER_STEP`. Legacy: `temp = (mired(baseline) − mired(K)) / MIRED_PER_STEP`, `tint = tint`.
- WB per pixel: `gains = G ⊙ exp(Σ c_i ln R_i)`, `G` = the global gains (`[1,1,1]` when the global WB is
  inactive, as the four-stage path then applies none), `R_i = gains(global shifted by i) / G`.
- New `Edits`/`LocalAdjustments` fields: `#[serde(default, skip_serializing_if = …)]`.
- No scene offset in any active mask → the tail is built exactly as today (byte-identical).
- Where no mask covers, `SceneOffsetsStage` output is **bit-identical** to the four stages.
- Lib modules no egui; hovers one sentence ≤110 chars, no full stop. No `Co-Authored-By`. Sabotage from `cp`.

## Review Focus

1. **A disabled mask, or one with only look sliders**, adds no offset and does not switch the tail to
   `SceneOffsetsStage` — pinned in Task 3 (`a_switched_off_mask_adds_no_offset`, `look_sliders_alone_keep_the_four_stages`).
2. **An inverted mask, and an AI mask still waiting for its map**, offset exactly where (and only where)
   they cover — pinned in Task 3 (`an_inverted_mask_offsets_outside_its_shape`, `a_waiting_ai_mask_offsets_nothing`).
3. **A region render** (zoomed in) offsets the same pixels as the whole-frame render — pinned in Task 3
   (`a_region_is_offset_as_that_part_of_the_whole`).
4. **A legacy mask Kelvin under an as-shot global** renders as it did — pinned in Task 2 and Task 3.
5. **The mask's look sliders still apply** (Saturation in an exposure mask) — pinned in Task 3
   (`a_mask_keeps_its_look_sliders`).
