# M10.12b2 — The reference photo for pixel-reading masks — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mask that reads pixels (a luminance or colour range, a gating brush) and carries a scene offset selects ONCE, on the globally edited photo before any mask, for its offsets and its look sliders alike — so nothing chases its own effect.

**Architecture:** `SceneOffsetsStage` gains an optional *reference*: the global tail up to the masks (the four scene stages with the global values, the curve, local contrast, saturation, HSL, grading), run on a copy of its input only when such a mask exists. Those masks' coverage is computed from it, used for their offsets, and handed through a `CoverageSlot` (an `Arc` built with the pipeline) to the same mask's look `MaskStage`, which blends by it instead of reading its own base. On the GPU both stages decline (the twin and that mask's `GpuMaskStage`), so the CPU stages run; the cost is measured. The brush coverage cache's base identity follows the new bases.

**Tech Stack:** Rust workspace — `edit-model`, `pipeline`, `gpu-pipeline`, `app` (lib `rustroom_app`).

**Spec:** `docs/superpowers/specs/2026-10-12-m10.12b-mask-offsets-design.md` (§ *The reference photo (part b2)*, *Tests*). b1's plan: `docs/superpowers/plans/2026-10-12-m10.12b1-mask-offsets.md`.

## Review Focus

1. **A region render** (zoomed, panning): the slot's plane is region-sized and the reference runs on the same region — a region render must equal the whole frame's crop.
2. **The grade range view** runs the tail as two halves (`build_pipeline_split_tapped`): the offsets stage in `before_grade`, the slot-fed mask in `from_grade` — they must share one slot.
3. **A disabled** pixel-reading mask with an offset: no reference, no slot, nothing applied.
4. **The GPU**: a slot-fed mask must never be substituted by a `GpuMaskStage` (which would read its own base); the CPU stage it leaves must still release an offered rasteriser's plane (`EndMask` guard on the slot path too).
5. **The brush cache**: a gating brush's cached map must miss whenever its true base changes — since b1 that includes *later* masks' scene offsets — and must not miss on a mask's own look slider.

Each is pinned by a named test below (Tasks 3, 4, 5).
