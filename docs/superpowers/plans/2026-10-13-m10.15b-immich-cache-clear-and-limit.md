# M10.15b — Clear the Immich downloads, and a soft limit that warns at startup — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A **Clear cache** for the downloaded Immich originals, a soft size limit set in Settings → Immich (default 10 GB), and a startup dialog — switchable off — when the downloads exceed it.

**Architecture:** The measuring, listing, threshold and wording live in the lib module `rustroom_app::immich_cache` (no egui), beside the existing `remove_downloads`. Two `Settings` fields carry the limit and the switch. In the bin, the Immich tab moves out of `modals/settings.rs` into `modals/settings_immich.rs` (the file is near the 1,000-line ceiling) and gains a *Downloaded originals* section; a new `modals/immich_cache.rs` is the one dialog both ways in open; `immich_flow.rs` gains the clear and the startup check, the clear going through the existing `remove_downloaded`.

**Tech Stack:** Rust, egui 0.35 (bin only), serde.

**Spec:** `docs/superpowers/specs/2026-10-13-m10.15b-immich-cache-clear-and-limit-design.md`

## Global Constraints

- ⛔ No automatic eviction: nothing is deleted except by the user's **Clear cache**.
- Clear removes **only supported image files** in the configured server's cache root (`catalog::is_supported`, the test `remove_downloads` and `present_names` use) — never sidecars, `.part` files, the list cache or thumbnails — and goes through `RustroomApp::remove_downloaded`.
- Sizes are **decimal**: `10 GB` = `10 × 10⁹` bytes, printed by `photo_info::format_bytes`'s rules ("74.0 MB", "12.4 GB").
- Defaults: `immich_cache_limit_gb = 10`, `immich_cache_warn = true`; **no field-level `#[serde(default)]`** on either (the struct's container-level default supplies them).
- Nothing shows while Immich is switched off: the section lives inside the tab's `if d.immich_enabled`, and startup checks only when `immich_source::connection(&settings)` is `Some`.
- Startup warns only when **strictly over** the limit.
- Lib modules have no egui. Hover text: one sentence, ≤ 110 characters, no full stop. No source file over 1,000 lines of code and doc.
- Tests never touch the real cache directory: every test passes its own `test_dir` root.
- Gate: `cargo fmt --all --check`, `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` (filter by test name, never `-p`). Commit messages carry no `Co-Authored-By`. Never push.

## Review Focus

1. **A bulk Download running when Clear is pressed** — a file still being written is a `.part`, which is neither counted nor removed; one that lands after the clear simply stays. → `usage_and_downloads_count_images_only` (Task 1) pins the `.part` exclusion.
2. **No server URL, a changed URL, or an empty cache directory** — "Nothing downloaded", **Clear…** disabled, no startup dialog. → `a_missing_or_sidecar_only_directory_is_nothing_downloaded` (Task 1), `with_nothing_downloaded_clear_opens_nothing` (Task 5).
3. **Clearing from Settings while an Immich photo is open in Develop** — edits saved, Develop emptied, no render left reading a vanished file. → `clearing_the_open_photo_empties_develop_and_keeps_its_edits` (Task 4).
4. **An upgrade from a settings file without the two fields** — 10 GB and the warning on, never 0 GB (a warning every launch) or off. → `a_settings_file_from_before_the_download_limit_gets_10_gb_and_the_warning` (Task 2).
5. **Don't warn again with no Settings window behind it** — the choice must reach the file, not only memory, or the dialog returns next launch. → `dont_warn_again_unticks_and_saves_the_warning` (Task 4).

```rust
/// How much the downloads take: the bytes and the number of photos.
#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub struct Usage {
    pub bytes: u64,
    pub photos: usize,
}

/// Every downloaded original in `root`, sorted — what a clear removes.
///
/// ⚠ Only `catalog::is_supported` files — the test `remove_downloads` and `present_names` use — so a
/// sidecar, a `.part` still being written or a `.DS_Store` is never counted or removed. A missing
/// directory is nothing downloaded.
pub fn downloads(root: &Path) -> Vec<PathBuf> {
    let Ok(rd) = std::fs::read_dir(root) else {
        return Vec::new();
    };
    let mut out: Vec<PathBuf> = rd
        .flatten()
        .filter(|e| e.file_type().map(|t| t.is_file()).unwrap_or(false))
        .map(|e| e.path())
        .filter(|p| catalog::is_supported(p))
        .collect();
    out.sort();
    out
}

/// The downloads' total size and count — one directory listing, ~3 ms for 1,000 photos (M10.15b).
pub fn usage(root: &Path) -> Usage {
    let mut u = Usage::default();
    for p in downloads(root) {
        if let Ok(m) = std::fs::metadata(&p) {
            u.bytes += m.len();
            u.photos += 1;
        }
    }
    u
}

/// The soft limit in bytes — **decimal**, the units `photo_info::format_bytes` prints, so "12.4 GB"
/// and "10 GB limit" are in the same unit.
pub fn limit_bytes(gb: u32) -> u64 {
    gb as u64 * 1_000_000_000
}

/// Whether startup opens the Clear dialog: Immich connected, the warning on, and the downloads
/// **strictly** over the limit.
pub fn warn_at_startup(connected: bool, warn: bool, limit_gb: u32, usage: Usage) -> bool {
    connected && warn && usage.bytes > limit_bytes(limit_gb)
}

fn photos(n: usize) -> String {
    if n == 1 {
        "1 photo".to_string()
    } else {
        format!("{n} photos")
    }
}

/// The Settings line: "74.0 MB · 21 photos", or "Nothing downloaded".
pub fn size_line(usage: Usage) -> String {
    if usage.photos == 0 {
        return "Nothing downloaded".to_string();
    }
    format!("{} · {}", crate::photo_info::format_bytes(usage.bytes), photos(usage.photos))
}

/// The dialog's title — the size at startup, the verb when asked from Settings.
pub fn dialog_title(usage: Usage, startup: bool) -> String {
    if startup {
        format!("Immich downloads use {}", crate::photo_info::format_bytes(usage.bytes))
    } else {
        "Clear Immich downloads".to_string()
    }
}

/// The dialog's body. ⚠ Always names the edits: what a clear keeps is the reason it is safe.
pub fn dialog_body(usage: Usage, limit_gb: u32, startup: bool) -> String {
    let n = match usage.photos {
        1 => "1 downloaded photo".to_string(),
        n => format!("{n} downloaded photos"),
    };
    let rest = format!(
        "Clearing removes {n}; edits, marks and thumbnails stay, and a photo downloads again when you open it"
    );
    if startup {
        format!("Over your {limit_gb} GB limit. {rest}")
    } else {
        rest
    }
}
```

use crate::{theme, RustroomApp};

pub fn show(app: &mut RustroomApp, ctx: &egui::Context) {
    let Modal::ImmichCache { startup, root, usage } = &app.modal else {
        return;
    };
    let (startup, root, usage) = (*startup, root.clone(), *usage);
    let title = immich_cache::dialog_title(usage, startup);
    let body = immich_cache::dialog_body(usage, app.settings.immich_cache_limit_gb, startup);
    let extra: &[(&str, &str)] = if startup {

        &[]
    };

        "immich_cache",

        theme::DialogSize::Standard,

            "Clear cache",
            "Deletes the downloaded originals and keeps every edit, mark and thumbnail",
            usage.photos > 0,
            if startup { "Not now" } else { "Cancel" },

        },

    /// Clear every downloaded original of the server cached at `root` — Remove downloads applied to
    /// all of them (M10.15b), so the open photo, the sidecars and the grid's ↓ are handled the same.
    pub(crate) fn clear_immich_cache(&mut self, root: &std::path::Path) {
        let paths = rustroom_app::immich_cache::downloads(root);
        self.remove_downloaded(&paths);
    }

    /// Once, after bootstrap: offer to clear when Immich is connected, the warning is on and the
    /// downloads are over the soft limit.
    pub(crate) fn check_immich_cache_at_startup(&mut self) {
        let connected = immich_source::connection(&self.settings).is_some();
        if let Some(root) = self.immich_cache_root() {
            self.check_immich_cache_in(connected, root);
        }
    }

    /// [`Self::check_immich_cache_at_startup`] with the root given — what the tests drive.
    pub(crate) fn check_immich_cache_in(&mut self, connected: bool, root: std::path::PathBuf) {
        // ⚠ Not even measured while Immich is off: the integration shows no trace of itself then.

            s.immich_cache_limit_gb,
            usage,
        ) {
