# M10.16a — Depth masks: the depth map and the Depth range mask — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Depth range mask component — near/far/feather/invert over a depth map Depth Anything V2 Small estimates once per photo — with an on-photo picker and a Show depth map view; and AI components (Subject, Selection, Depth) that finally cover in a mask's Noise reduction, Dehaze and Defringe.

**Architecture:** `ai-mask` gains the model and its normalisation; the app snaps the map to the photo's edges with `pipeline::spatial::guided_filter` and caches it in decode space like every AI map. A depth component reaches the pipeline exactly as an AI component does — an 8-bit frame raster through the brush side channel, the band applied on the CPU — so the pipeline and the GPU only gain a match arm. The prefix gains an injected AI-raster source resolved at the stage's own frame size, its identity in the step key.

**Tech Stack:** Rust; `ai-mask` (`tract-onnx` 0.23.8), `edit-model`, `pipeline`, `gpu-pipeline`, `app` (egui).

**Spec:** `docs/superpowers/specs/2026-10-14-m10.16a-depth-masks-design.md`.

## Review Focus

1. **A flat scene** (a wall, a sky: every disparity equal, or non-finite values from the network) must give a
   finite map, never NaN — pinned in Task 1 (`a_flat_or_broken_plane_normalises_to_finite_values`).
2. **A portrait or a rotated photo**: the stored map is in decode orientation and the right way round — pinned
   in Task 4 (`a_depth_map_comes_back_in_decode_orientation`).
3. **A region render at 1:1 zoom** covers exactly that slice of the whole-frame depth coverage — pinned in
   Task 5 (`a_depth_component_clipped_to_a_region_is_that_slice_of_the_whole`).
4. **A degenerate picker drag** (zero area, or entirely off the photo) leaves the band unchanged — pinned in
   Task 8 (`an_empty_drag_sets_no_band`).
5. **Near dragged past Far, and a zero-width band at feather 0** stay finite and sensible — pinned in Task 2
   (`a_depth_band_is_sorted_and_finite_at_its_edges`).

  ```rust
  pub fn input_size(w: u32, h: u32, long: u32) -> (u32, u32) {
      let s = long as f32 / w.max(h).max(1) as f32;
      let r = |v: u32| (((v as f32 * s) / 14.0).round().max(1.0) as u32) * 14;
      (r(w), r(h))
  }
  /// The value at fraction `q` of the sorted finite values.
  fn percentile(sorted: &[f32], q: f32) -> f32 { sorted[((sorted.len() - 1) as f32 * q).round() as usize] }
  pub fn normalise(d: &Plane, scale: DepthScale) -> Plane {
      let mut finite: Vec<f32> = d.data.iter().copied().filter(|v| v.is_finite()).collect();
      finite.sort_by(f32::total_cmp);
      if finite.is_empty() { return Plane { w: d.w, h: d.h, data: vec![0.5; d.data.len()] }; }
      let (lo, hi) = (percentile(&finite, 0.01), percentile(&finite, 0.99));
      let span = hi - lo;
      let data = d.data.iter().map(|&v| {
          if !v.is_finite() || span <= 1e-9 { return 0.5; }
          let v = v.clamp(lo, hi);
          // Disparity is LARGE when near: position = 1 − nearness.
          let near = match scale {
              DepthScale::Linear => (v - lo) / span,
              // The share of the photo's pixels farther than this one.
              DepthScale::Equalised => finite.partition_point(|&x| x < v) as f32 / finite.len() as f32,
          };
          (1.0 - near).clamp(0.0, 1.0)
      }).collect();
      Plane { w: d.w, h: d.h, data }
  }
  ```
