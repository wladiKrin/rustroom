# M10.16d1 — Lens Blur: the CPU reference, the UI and export — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lens Blur — a depth-driven, occlusion-aware, shaped-aperture blur with Subject or Point focus — as a cached prefix step on the CPU, with its Develop section, Pick focus, Visualize, and export; d2 adds the GPU twin.

**Architecture:** `pipeline::stages::lens_blur` holds the whole algorithm as plain functions over planes (radius, layers, a 128-point spiral gather at half resolution, a full-resolution composite), wrapped in `LensBlurStage`, a prefix step after the masked capture corrections. Its inputs — the depth plane, the Subject alpha, the focus depth — come through `AiRasters` (widened with `plane` and `lens_focus`), which the app's `AiSource` implements from the cached maps. The app computes the focus depth in decode space (`lens_blur_tool`), requests the maps while Lens Blur is on, and draws the section, the picker and the visualisation.

**Tech Stack:** Rust; `edit-model`, `pipeline`, `app` (egui).

**Spec:** `docs/superpowers/specs/2026-10-14-m10.16d-lens-blur-design.md` (d1; d2 has its own plan).

## Global Constraints

- Env: `export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:/opt/homebrew/opt/libraw/lib/pkgconfig:/opt/homebrew/opt/little-cms2/lib/pkgconfig:$PKG_CONFIG_PATH"`.
- `cargo test --workspace <filter>` only (N > 0 passed); clippy in `target/clippy`; goldens `--test golden`.
- `Edits.lens_blur` is `#[serde(default, skip_serializing_if = "LensBlur::is_default")]`; off is never written.
- Defaults: off; Amount 50, Focus Subject, Focal range 10, Bokeh Circle, Boost 25. The edit group **"Lens Blur"** is **appended** (index 11), off in `EditGroups::default()`, on in `ALL`.
- Radius: `R = amount/100 × 0.03 × long side` at the render scale; `h = focal_range / 200`; `c = R · clamp((|D − f| − h) / 0.5, 0, 1)`, × (1 − S) in Subject mode. Background `D ≥ f − h`, foreground `D < f − h`.
- Boost: `B = I · (1 + 3·boost/100 · smoothstep(0.7·L99, L99, lum))`, L99 the frame's 99th-percentile luminance.
- The gather: 128 Vogel-spiral offsets, spread over the tile-max radius (16-px tiles at half resolution, dilated by one tile); weight `(pattern area / 128) / (rq² · shape area)`; half-resolution gathers, full-resolution composite; **where `c == 0` and no foreground covers, the output is the input exactly**.
- Shapes (unit disc units): Circle `|o| ≤ 1`; Blades = the hexagon inscribed in the disc; Ring = the disc weighted `0.35 + 0.65·smoothstep(0.55, 0.95, |o|)`; Cat-eye = disc ∩ disc shifted by `0.6 ×` the point's offset from the frame centre (normalised to ±1).
- Lib modules have no egui; hovers one sentence ≤ 110 chars, no full stop; no `Color32` outside `theme.rs`.
- No source file over 1,000 lines of code + doc; report touched files over ~600.
- Commits without a `Co-Authored-By` trailer; never push; sabotage each key test from a `cp`.

### Task 3: The blur — radius, layers, gather, composite (`pipeline`)

**Files:** create `crates/pipeline/src/stages/lens_blur/{radius.rs,gather.rs}`; `mod.rs` holds `LensBlurStage` and the `render` entry.

**Produces:**
```rust
pub struct Params { pub focus: f32, pub half_range: f32, pub radius_px: f32, pub bokeh: edit_model::Bokeh, pub boost: f32 }
impl Params { pub fn new(lb: &edit_model::LensBlur, focus: f32, long_side_px: usize) -> Params }
/// The blur radius at depth `d` (0 near … 1 far), before the subject's alpha.
pub fn radius(p: &Params, d: f32) -> f32;
/// The blurred frame: `img` (linear), `depth` and optional `subject` alpha as w×h planes in 0..=1.
pub fn render(img: &ImageBuf, depth: &[f32], subject: Option<&[f32]>, p: &Params) -> ImageBuf;
```
- [ ] Tests first (synthetic, 160 × 100 unless stated):
  - `radius_is_zero_in_the_sharp_zone_and_grows_outside` — exact 0 on `|d − f| ≤ h`, monotone, `R` at `h + 0.5`.
  - `a_point_behind_focus_becomes_a_disc_and_keeps_its_light` — a 2 × 2 bright point (value 50) on black at depth 1, focus 0, R 12: the output's lit area has a radius 12 ± 2 px (measured on the 5 % contour) and the total light is within 2 % of the input's.
  - `each_shape_draws_its_disc` — the same point per `Bokeh`: Circle's contour radius is the same at 0° and 30° (±1 px); Blades' differs by ≥ 8 %; Ring's centre is dimmer than its rim; Cat-eye at the frame centre is round, at x = 0.9 W narrower radially.
  - `no_halo_behind_a_sharp_subject` — background a blue/green texture at depth 1; a red disc subject at depth 0.2 with alpha 1; Subject focus 0.2, R 16: in the 6-px ring outside the subject the output's red is < 2 % above the unblurred background's.
  - `a_foreground_spreads_over_the_subject` — a white bar at depth 0 in front of a grey subject at 0.5 (focus 0.5): pixels of the subject next to the bar get brighter (the bar's blur covers them).
  - `in_focus_pixels_are_the_input_exactly` — Point focus on a depth-0.5 region: those pixels' bits equal the input's.
  - `boost_brightens_highlight_discs_and_leaves_midtones` — a disc's peak rises with Boost 100 vs 0; a uniform mid-grey frame is unchanged by Boost.
  - `tiny_frames_and_full_amount_stay_finite` (Review Focus 3) — 1 × 1, 3 × 2 and 64 × 40 frames at Amount 100: same size out, every value finite.
- [ ] Implement per Global Constraints: `radius`; boost; half-resolution planes (2 × 2 means of colour, the max of `c / 2`, the fractions of background and foreground pixels); the tile-max radius; the per-pixel gather (`rayon` rows) accumulating background and foreground sums and weights separately, `covers = aperture::weight(kind, (p − q)/c(q), pos(q))`; background `= sum / weight` (fallback the pixel itself), foreground colour `= sum / weight` and coverage `min(1, Σ (A_pattern/N)/(c(q)²·area))`; bilinear upsample; the composite `out = bg`; sharp `t = clamp(1 − c/1.5, 0, 1)` → `out = I` when `t == 1` else lerp; Subject `out = lerp(out, I, S)`; foreground `out = lerp(out, fg, α)` — skip the arithmetic entirely where α = 0 and t = 1 so the identity is bit-exact.
- [ ] Sabotages: the background gather including subject pixels → the halo test red; dropping `1/area` → the energy test red; lerp at t = 1 → the identity test red. Commit `feat(pipeline): lens blur — a sampled-aperture gather in three layers (M10.16d)`.
