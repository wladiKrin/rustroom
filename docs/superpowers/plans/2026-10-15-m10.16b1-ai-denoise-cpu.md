# M10.16b1 — AI denoise, the CPU path — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI denoise end to end on the CPU — DRUNet through `tract`, an automatic σ, a tiled background job, a disk cache with a soft limit, the prefix's first step and an Amount slider in Detail, export included.

**Architecture:** `ai-mask` runs the network on one encoded tile (`denoise::Drunet`). The app lib's `ai_denoise` owns everything around it — the encoding and its correction back into linear ProPhoto, the noise estimate, the tiling with progress and cancel — behind a `TileNet` trait so b2's GPU engine swaps in. The finished image rides in `AiMaps` beside the probability maps, so the preview's `AiSource` and export's `maps_for` reach it with no new plumbing; `pipeline` gains an `ImageSource` and `AiDenoiseStage`, the prefix's FIRST step, blending the result (resized with the same `downscale_to` as checkpoint 0) by Amount.

**Tech Stack:** Rust, `tract-onnx` 0.23.8, `half` + `flate2` (already in the build), egui.

**Spec:** `docs/superpowers/specs/2026-10-15-m10.16b-ai-denoise-design.md`

## Global Constraints

- The model: `drunet_color.onnx`, 130,589,232 bytes, SHA-256 `2ae3ab5eb15daac2ee79be984d584b908ce7f0f60b27be87d005f728c2aa0087`, URL `https://huggingface.co/synthscript/drunet-color-onnx/resolve/main/drunet_color.onnx`; licence note MIT with the DIV2K caveat.
- Input `[1, 4, h, w]`: RGB sRGB display-referred 0…1 + a plane σ/255; h, w multiples of 8. Tiles 512 × 512, 32 px overlap.
- The encoding: linear ProPhoto → linear sRGB → × `0.9 / L₉₉.₅` (`lens_blur::highlight_level`'s grid, 99.5th) → sRGB transfer → clamp 0…1. The result goes back as a CORRECTION added to the original.
- σ automatic, clamped 1…40; Amount 0–100 in Detail's group; off never written (`skip_serializing_if`).
- Cache: Settings → Performance, a GB soft limit (default 10) warned at startup, Clear…; nothing evicted on its own.
- No egui in the lib; files under the 1,000-line ceiling (`modals/settings.rs` 863 → its own module); every hover one sentence (DESIGN.md).
- One cargo mode (`cargo test --workspace <filter>`), clippy in `target/clippy`; commits carry no `Co-Authored-By`; never push.

## Review Focus

1. **A photo whose full decode never arrives** (the session on its half decode, or a JPEG) — no job, no step, the line says why; never a half-size image denoised as if it were full. Pinned in Task 7 (`no_job_before_the_full_decode`).
2. **Changing photos mid-job** — the job is cancelled, never inserted into the next photo's maps. Pinned in Task 7 (`a_job_for_another_photo_is_dropped`).
3. **Clipped highlights and out-of-gamut colours** — kept exactly, the correction ≈ 0 there. Pinned in Task 2 (`clipped_and_out_of_gamut_values_pass_through`).
4. **A frame whose sides are not multiples of 8 or of the tile** — padded by reflection, cropped back, seamless. Pinned in Task 2 (`odd_sizes_tile_seamlessly`).
5. **A corrupt or truncated cache file** — rejected and recomputed, never a garbage image. Pinned in Task 4 (`a_truncated_file_is_rejected`).

### Task 2: The processing (`app` lib `ai_denoise`)

**Files:** `crates/app/src/ai_denoise.rs` (new; `lib.rs`).
**Produces:**
```rust
pub trait TileNet { fn run(&mut self, rgb: &[f32], w: usize, h: usize, sigma: f32) -> Result<Vec<f32>, String>; }
pub struct Encoding { pub scale: f32 }
impl Encoding { pub fn of(img: &ImageBuf) -> Self; pub fn encode(&self, p: [f32; 3]) -> [f32; 3] /* clamped 0..1 */; pub fn decode(&self, e: [f32; 3]) -> [f32; 3] /* linear ProPhoto */ }
pub fn noise_sigma(img: &ImageBuf, enc: &Encoding) -> f32; // σ in 0..255 units, clamped 1..40
pub const TILE: usize = 512; pub const OVERLAP: usize = 32;
pub fn denoise(img: &ImageBuf, net: &mut dyn TileNet, sigma: f32, progress: &dyn Fn(usize, usize) -> bool /* false = cancel */) -> Result<Option<ImageBuf>, String>;
```
- [ ] Tests first: `the_encoding_round_trips_where_nothing_clips`; `clipped_and_out_of_gamut_values_pass_through` (an identity net leaves the image bit-close; a net that adds 0.01 everywhere moves an in-range pixel and leaves a pixel at 3× white unchanged… by the correction rule, i.e. moved by its share); `noise_sigma_reads_known_noise` (Gaussian σ 8 in the encoding on a flat field → 8 ± 10 %; a clean gradient → ≤ 1.5); `odd_sizes_tile_seamlessly` (a constant-adding net on 301 × 203 and 1100 × 700: every pixel the same correction, no seam); `progress_counts_tiles_and_cancel_stops`.
- [ ] Implement: σ — the 2 × 2 Haar diagonal `(a − b − c + d)/2` of the encoded luminance on non-overlapping blocks, the MAD over the flattest 25 % of 16 × 16 blocks (by their mean absolute horizontal+vertical difference), × 1.4826 × 255. Tiles: 512 with 32 overlap, reflection-padded to multiples of 8, weights a linear ramp across overlaps, normalised.
- [ ] Sabotage the clamp-free correction and the ramp. Commit `feat(app): ai_denoise — the encoding, the noise estimate and the tiled correction (M10.16b)`.
