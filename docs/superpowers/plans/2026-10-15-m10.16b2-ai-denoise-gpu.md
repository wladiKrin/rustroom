# M10.16b2 — AI denoise on the GPU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DRUNet's convolutions on the GPU through `wgpu`, swapped in as the denoise job's network whenever an adapter exists and Settings' *Use the GPU* is on — the same picture as `tract`'s, several times faster.

**Architecture:** One WGSL kernel — a tiled matrix product (64 × 64 outputs a workgroup, 16 deep, 4 × 4 per thread) — in three index modes: the 3 × 3 convolution (zero-padded), the 2 × 2 stride-2 down-convolution, and the 2 × 2 stride-2 transposed convolution (one product over input pixels with the four output quadrants as columns). ReLU and two residual adds fused into its store. `gpu_pipeline::drunet` reads the weights as plain tensors (no `tract` in the GPU crate), checks them against DRUNet's shape, builds the 64-convolution program once per tile size, and runs a tile as a handful of submissions. The app's `denoised::network` gives the job the GPU engine with `tract` behind it as the fallback.

**Tech Stack:** Rust, `wgpu` 29 (WGSL compute), `tract-onnx` 0.23.8 (its ONNX parser, for the weights only), the app's existing `ai_denoise::TileNet` seam.

**Spec:** `docs/superpowers/specs/2026-10-15-m10.16b-ai-denoise-design.md` — §3 *The GPU engine (b2) and the split*, §4 *Tests (b2)*.

## Global Constraints

- DRUNet is plain convolutions: a 3 × 3 head (4 → 64), four scales of four residual blocks (`x + conv(relu(conv(x)))`, bias-free 3 × 3) with 2 × 2 stride-2 down- and transposed up-convolutions (64 → 128 → 256 → 512 and back), additive skips, a 3 × 3 tail (64 → 3). (Spec §3; confirmed from the file: 64 initializers, 61 Conv, 3 ConvTranspose, 28 Relu, 32 Add, no biases.)
- Weights read once from the ONNX file's initializers (tract's own parser) and uploaded once per session; activations resident per tile. (§3)
- Held to `tract`: a parity test per kernel and over the whole network on small and odd-sized tiles, within a tolerance this plan measures. (§3, §4)
- **Rule:** a whole frame over ~3 minutes → tune the kernels before merging. (§4) The author called the CPU path "painfully slow": tune toward the fastest the kernel reaches, and report the time.
- b2 swaps the GPU engine in as the job's runner whenever an adapter exists — the same picture, faster; `tract` stays the fallback. (§3)
- `gpu-pipeline` has no `tract` dependency; `pipeline`/`core-image` have no GUI dependency; the app lib has no egui (CLAUDE.md).
- No file over 1,000 lines of code and doc (the gate); a file already over ~600 named in the report.
- One cargo mode: `cargo test --workspace <filter>`; clippy in `CARGO_TARGET_DIR=target/clippy` with `-D warnings`.
- Commit messages carry no `Co-Authored-By` trailer; never push.
- A GPU test with no adapter prints `SKIPPED: no GPU adapter on this machine` and returns (the crate's pattern).

## Review Focus

1. **A GPU failure mid-job** (device lost, a buffer the device refuses, a panic inside `wgpu`) — the job finishes on the CPU, never a garbage tile and never a dead worker. Pinned in Task 5 (`a_failing_gpu_hands_the_rest_to_the_cpu`).
2. **No adapter, or *Use the GPU* off** — the CPU network, exactly b1's behaviour. Pinned in Task 5 (`without_the_gpu_the_cpu_network_runs`).
3. **A tile past the device's binding limit, or with sides not a multiple of 8** — refused with an error (and so the CPU), never handed to `create_buffer`. Pinned in Task 4 (`a_tile_the_device_cannot_hold_is_refused`, `sides_must_be_multiples_of_eight`).
4. **The GPU memory a finished job leaves behind** — ~0.5 GB of activations for a 512 px tile; freed when the job ends, the weights kept. Pinned in Task 4 (`release_frees_the_activations`) and Task 5 (the worker calls `finished`).
5. **Editing while a job runs** — the job must not hold the queue for a whole tile; a tile is submitted level by level. Measured in Task 6 (a render frame's time with a job running), not unit-tested.

```rust
/// Every initializer of DRUNet's file as `(name, shape, values)` — the GPU engine's weights (M10.16b2),
/// read by tract's own parser so no second ONNX reader exists.
pub fn weights(path: &std::path::Path) -> Result<Vec<(String, Vec<usize>, Vec<f32>)>, InferError> {
    use tract_onnx::prelude::Framework;
    let proto = tract_onnx::onnx().proto_model_for_path(path).map_err(err)?;
    weights_of(&proto)
}

/// [`weights`] from a parsed model. ⚠ Float only (`data_type` 1); the values from `raw_data` (little-endian)
/// or `float_data`, and their count must be the shape's.
pub fn weights_of(
    proto: &tract_onnx::pb::ModelProto,
) -> Result<Vec<(String, Vec<usize>, Vec<f32>)>, InferError> {
    let graph = proto.graph.as_ref().ok_or_else(|| InferError::Model("no graph".into()))?;
    graph
        .initializer
        .iter()
        .map(|t| {
            if t.data_type != 1 {
                return Err(InferError::Model(format!("{}: not float", t.name)));
            }
            let shape: Vec<usize> = t.dims.iter().map(|&d| d.max(0) as usize).collect();
            let data: Vec<f32> = if t.raw_data.is_empty() {
                t.float_data.clone()
            } else {
                t.raw_data
                    .as_chunks::<4>()
                    .0
                    .iter()
                    .map(|b| f32::from_le_bytes(*b))
                    .collect()
            };
            if data.len() != shape.iter().product::<usize>() {
                return Err(InferError::Model(format!(
                    "{}: {} values for {shape:?}",
                    t.name,
                    data.len()
                )));
            }
            Ok((t.name.clone(), shape, data))
        })
        .collect()
}
```

  - `pub(crate) enum Mode { Conv3 = 0, Down2 = 1, Up2 = 2 }`.
  - `pub(crate) enum Buf { Input, Output, Skip(usize), Work(usize, usize) }` (scale, slot 0..3).
  - `pub(crate) struct Op { pub mode: Mode, pub weight: String, pub src: Buf, pub dst: Buf, pub relu: bool, pub add1: Option<Buf>, pub add2: Option<Buf>, pub scale_in: usize, pub cin: usize, pub cout: usize }`.
  - `pub(crate) fn program(a: &Arch) -> Vec<Op>` — the 64 convolutions in order.
  - `pub(crate) fn pack(mode: Mode, t: &Tensor) -> Vec<f32>` — `[K][N]` row-major.
  - `pub(crate) fn names(a: &Arch) -> Vec<(String, Vec<usize>)>` — every expected weight with its shape (what `Arch::of` checks and the tests fabricate).

The graph (from the file):

```
x1 = head(in)                                   conv3 4 → w0 at scale 0      → Skip(0)
for s in 0..3:  cur = Skip(s); blocks × [t = relu(conv3(cur)); cur = cur + conv3(t)]
                Skip(s+1) = down2(cur)          w_s → w_{s+1}
body:           cur = Skip(3); blocks × res; the LAST block's store also adds Skip(3)
for s in 2,1,0: cur = up2(cur)                  w_{s+1} → w_s, into Work(s, 1)
                blocks × res; the LAST block's store also adds Skip(s)
out = tail(cur)                                 conv3 w0 → 3 → Output
```

Buffers at scale `s`: `Skip(s)`; `Work(s, 0)` the ReLU temporary; `Work(s, 1)`, `Work(s, 2)` alternate as the block's input and output (`cur` never overwritten while it is read; `Skip(s)` never written after its producer). Weight names, with `nb = blocks`: `m_head.weight [w0,4,3,3]`; `m_down{l}.{b}.res.{0,2}.weight [w,w,3,3]` (b < nb), `m_down{l}.{nb}.weight [w_l, w_{l-1}, 2, 2]` (l = 1..3); `m_body.{b}.res.{0,2}.weight`; `m_up{l}.0.weight [w_l, w_{l-1}, 2, 2]` (ConvTranspose: `[in, out, kh, kw]`), `m_up{l}.{b+1}.res.{0,2}.weight`; `m_tail.weight [3, w0, 3, 3]`.

Packing (`K` rows, `N` columns): Conv3 `W[co][ci][ky][kx]` → `K = 9·cin`, `k = ci·9 + ky·3 + kx`, `B[k][co] = W[co][k]`. Down2 → `K = 4·cin`, `k = ci·4 + ky·2 + kx`, `B[k][co] = W[co][k]`. Up2 `W[ci][co][ky][kx]` → `K = cin`, `N = 4·cout`, `n = (ky·2 + kx)·cout + co`, `B[ci][n] = W[ci][co][ky][kx]`.

### Task 3: The kernel — one convolution on the GPU

**Files:**
- Create: `crates/gpu-pipeline/src/drunet/wgsl.rs`, `conv.rs`, `reference.rs` (`#[cfg(test)]`)

**Interfaces:**
- Consumes: `Mode`, `pack` (Task 2).
- Produces:
  - `pub(crate) fn shader(mode: Mode) -> String` — `const MODE: u32 = <n>u;` then the kernel.
  - `pub(crate) struct Dims { pub in_w: u32, pub in_h: u32, pub cin: u32, pub cout: u32 }` and `impl Dims { fn out(&self, mode) -> (u32, u32); fn mnk(&self, mode) -> (u32, u32, u32) }`.
  - `pub(crate) fn uniform(mode: Mode, d: &Dims, relu: bool, add1: bool, add2: bool) -> [u32; 12]`.
  - `pub(crate) fn conv_layout() -> [wgpu::BindGroupLayoutEntry; 6]` (src ro, weights ro, dst rw, res1 ro, res2 ro, params uniform).
  - `pub(crate) fn groups(mode: Mode, d: &Dims) -> (u32, u32)` — `(ceil(M/64), ceil(N/64))`.
  - `reference::{conv3, down2, up2}(src: &[f32], d: &Dims, w: &Tensor) -> Vec<f32>` (CHW, `f64` accumulation).

The kernel (`wgsl.rs`, verbatim; `MODE` prepended):

```wgsl
struct Params {
  in_w: u32, in_h: u32, out_w: u32, out_h: u32,
  m: u32, n: u32, k: u32, cout: u32,
  relu: u32, add1: u32, add2: u32, pad: u32,
}
@group(0) @binding(0) var<storage, read> src: array<f32>;
@group(0) @binding(1) var<storage, read> wts: array<f32>;
@group(0) @binding(2) var<storage, read_write> dst: array<f32>;
@group(0) @binding(3) var<storage, read> res1: array<f32>;
@group(0) @binding(4) var<storage, read> res2: array<f32>;
@group(0) @binding(5) var<uniform> p: Params;

const TM: u32 = 64u;
const TN: u32 = 64u;
const TK: u32 = 16u;
var<workgroup> sa: array<f32, 1024>; // [k][m]
var<workgroup> sb: array<f32, 1024>; // [k][n]

// The product's row m, column k: an input value, zero outside the image.
fn a_at(m: u32, k: u32) -> f32 {
  if (m >= p.m || k >= p.k) { return 0.0; }
  let in_hw = p.in_w * p.in_h;
  if (MODE == 0u) {
    let y = i32(m / p.out_w);
    let x = i32(m % p.out_w);
    let ci = k / 9u;
    let tap = k % 9u;
    let iy = y + i32(tap / 3u) - 1;
    let ix = x + i32(tap % 3u) - 1;
    if (iy < 0 || ix < 0 || iy >= i32(p.in_h) || ix >= i32(p.in_w)) { return 0.0; }
    return src[ci * in_hw + u32(iy) * p.in_w + u32(ix)];
  }
  if (MODE == 1u) {
    let y = m / p.out_w;
    let x = m % p.out_w;
    let ci = k / 4u;
    let tap = k % 4u;
    return src[ci * in_hw + (2u * y + tap / 2u) * p.in_w + 2u * x + tap % 2u];
  }
  return src[k * in_hw + m];
}

// Where row m, column n lands: the output plane's pixel, a quadrant's for the transposed convolution.
fn out_at(m: u32, n: u32) -> u32 {
  if (MODE == 2u) {
    let y = m / p.in_w;
    let x = m % p.in_w;
    let q = n / p.cout;
    let co = n % p.cout;
    return co * p.out_w * p.out_h + (2u * y + q / 2u) * p.out_w + 2u * x + q % 2u;
  }
  return n * p.out_w * p.out_h + m;
}

@compute @workgroup_size(16, 16)
fn main(@builtin(local_invocation_id) lid: vec3<u32>, @builtin(workgroup_id) wid: vec3<u32>) {
  let t = lid.y * 16u + lid.x;
  let m0 = wid.x * TM;
  let n0 = wid.y * TN;
  var acc: array<vec4<f32>, 4>; // acc[j][i]: column n0 + lid.y + 16j, row m0 + lid.x + 16i
  for (var k0 = 0u; k0 < p.k; k0 = k0 + TK) {
    for (var r = 0u; r < 4u; r = r + 1u) {
      let e = t + r * 256u;
      sa[e] = a_at(m0 + e % TM, k0 + e / TM);
      let k = k0 + e / TN;
      let n = n0 + e % TN;
      var w = 0.0;
      if (k < p.k && n < p.n) { w = wts[k * p.n + n]; }
      sb[e] = w;
    }
    workgroupBarrier();
    for (var kk = 0u; kk < TK; kk = kk + 1u) {
      let a = vec4<f32>(sa[kk * TM + lid.x], sa[kk * TM + lid.x + 16u],
                        sa[kk * TM + lid.x + 32u], sa[kk * TM + lid.x + 48u]);
      for (var j = 0u; j < 4u; j = j + 1u) {
        acc[j] = acc[j] + a * sb[kk * TN + lid.y + 16u * j];
      }
    }
    workgroupBarrier();
  }
  for (var j = 0u; j < 4u; j = j + 1u) {
    let n = n0 + lid.y + 16u * j;
    for (var i = 0u; i < 4u; i = i + 1u) {
      let m = m0 + lid.x + 16u * i;
      if (m < p.m && n < p.n) {
        var v = acc[j][i];
        if (p.relu != 0u) { v = max(v, 0.0); }
        let o = out_at(m, n);
        if (p.add1 != 0u) { v = v + res1[o]; }
        if (p.add2 != 0u) { v = v + res2[o]; }
        dst[o] = v;
      }
    }
  }
}
```

**Files:**

**Interfaces:**
- Consumes: Tasks 2–3.
- Produces:
  - `pub struct GpuDrunet` with `pub fn new(ctx: Arc<GpuContext>, weights: &Weights) -> Result<Self, String>`, `pub fn run(&mut self, rgb: &[f32], w: usize, h: usize, sigma: f32) -> Result<Vec<f32>, String>` (`rgb` interleaved HWC 0…1, `sigma` in 0…255 units — `Drunet::run`'s contract), `pub fn release(&mut self)`.

`new` checks `Arch::of`, packs and uploads every weight once (`STORAGE | COPY_DST`). `run` checks the size (multiples of 8, `fits`), builds or reuses the per-size `Sized { w, h, bufs, steps }` — every buffer of `Buf` at its scale's channel count and size, one uniform and one bind group per `Op` (`res1`/`res2` bound to `dst`'s scale's spare buffer when unused, flags 0) — uploads the input `[4, h, w]` (RGB planes, then `sigma / 255`), and encodes the ops **one compute pass and one submission per level** (head + down1; each down level; the body; each up level + its transposed convolution; the tail), then copies `Output` to a readback buffer, maps it (`poll(Wait)`), and returns HWC. Everything under `crate::guarded`; a `None` from it → `Err("the GPU failed")`.
