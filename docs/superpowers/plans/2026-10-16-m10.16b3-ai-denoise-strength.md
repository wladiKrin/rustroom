# M10.16b3 — AI denoise: the noise map at 2× Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each pixel denoised at the noise its own brightness carries — a per-brightness noise curve, a σ plane per tile, at 2× — in both engines.

**Architecture:** A new lib module `noise_curve` measures σ for each eighth of encoded brightness (today's estimator, per band) and turns a tile's encoded pixels into a σ plane (the curve at each pixel's blurred brightness × `CALIBRATION` 2.0). `TileNet::run` takes that plane instead of a scalar; `ai_denoise::denoise_in` asks a σ source for each tile's plane; `ai_denoise::run` builds the curve once per photo. The cache's recipe moves to `denoise:v2`.

**Tech Stack:** Rust; the app lib, `ai-mask` (`tract`), `gpu-pipeline` (`GpuDrunet::run_map`, built in b2's spike).

**Spec:** `docs/superpowers/specs/2026-10-16-m10.16b-strength-and-speed-design.md` §1 (and `2026-10-15-m10.16b-ai-denoise-design.md` for b1/b2).

## Global Constraints

- The noise curve: σ for each eighth of encoded brightness, by today's estimator (2 × 2 binned, 16 px blocks, the flattest quarter, the median Haar diagonal) on that band's blocks only; a band with too few blocks, or reading under 0.5, takes its neighbour's. (§1)
- The map: each pixel's σ = the curve at its brightness × `CALIBRATION` (now 2.0), clamped 1…40; the brightness is the encoded luma box-blurred over 15 px; linear between the bands' centres. (§1)
- Both engines take a σ plane; the recipe moves to `denoise:v2`; the Detail line unchanged; no new control. (§1)
- No file over 1,000 lines of code and doc; the app lib has no egui; one cargo mode (`cargo test --workspace <filter>`), clippy in `target/clippy`.
- Commit messages carry no `Co-Authored-By` trailer; never push.

## Review Focus

1. **A photo that is mostly clipped or mostly black** — too few blocks in most bands; the curve must still fill every band (from neighbours, or the whole-photo estimate) and never hand the network a NaN. Pinned in Task 1 (`a_photo_with_one_band_fills_every_band`).
2. **A single bright pixel in a dark tile** (a street lamp) — the 15 px blur keeps it from dropping the σ of the dark pixels around it. Pinned in Task 1 (`the_map_reads_blurred_brightness`).
3. **The tile's reflection padding** — the plane covers the padded tile (its `pw × ph`), never the unpadded one. Pinned in Task 2 (`each_tile_carries_its_map`).
4. **A result computed at 1×** — never reused under the new default. Pinned in Task 2 (`the_key_is_pinned_at_v2`).
5. **Every σ the network sees stays within 1…40** — the clamp, after the 2×. Pinned in Task 1 (`the_map_is_clamped`).

```rust
    /// A ramp of brightness whose noise falls as it brightens: the curve reads each band's noise within
    /// 20 %, and falls.
    #[test]
    fn noise_curve_tracks_noise_rising_toward_the_shadows() {
        let enc = Encoding { scale: 1.0 };
        let (w, h) = (1024, 512);
        let mut rng = 0x1234_5678u32;
        let mut gauss = || {
            let mut u = || {
                rng ^= rng << 13;
                rng ^= rng >> 17;
                rng ^= rng << 5;
                (rng as f32 + 1.0) / (u32::MAX as f32 + 2.0)
            };
            let (a, b) = (u(), u());
            (-2.0 * a.ln()).sqrt() * (std::f32::consts::TAU * b).cos()
        };
        let want = |v: f32| 12.0 - 8.0 * v; // σ in 0…255 units, 12 at black, 4 at white
        let img = image(w, h, |x, _| {
            let v = 0.05 + 0.9 * x as f32 / w as f32;
            let s = want(v) / 255.0;
            enc.decode([v + s * gauss(), v + s * gauss(), v + s * gauss()])
        });
        let c = noise_curve(&img, &enc);
        for b in 1..BANDS - 1 {
            let v = (b as f32 + 0.5) / BANDS as f32;
            assert!((c[b] - want(v)).abs() < 0.2 * want(v), "band {b}: {} vs {}", c[b], want(v));
        }
        assert!(c[1] > c[6], "the curve does not fall: {c:?}");
    }

    /// Review Focus 1: one band of blocks — every band filled from it, none NaN.
    #[test]
    fn a_photo_with_one_band_fills_every_band() {
        let enc = Encoding { scale: 1.0 };
        let img = image(256, 256, |x, y| {
            let n = ((x * 7 + y * 13) % 11) as f32 / 255.0;
            enc.decode([0.5 + n, 0.5 + n, 0.5 + n])
        });
        let c = noise_curve(&img, &enc);
        assert!(c.iter().all(|v| v.is_finite() && *v >= 0.5), "{c:?}");
        assert!(c.iter().all(|v| (v - c[4]).abs() < 1e-6), "all from the one band: {c:?}");
    }

    #[test]
    fn a_flat_curve_gives_a_flat_map() {
        let rgb: Vec<f32> = (0..32 * 16 * 3).map(|i| (i % 97) as f32 / 97.0).collect();
        let m = noise_map(&rgb, 32, 16, &[5.0; BANDS], 2.0);
        assert_eq!(m.len(), 32 * 16);
        assert!(m.iter().all(|v| (v - 10.0).abs() < 1e-5));
    }

    /// Review Focus 2: a lone bright pixel in the dark barely moves its neighbours' σ.
    #[test]
    fn the_map_reads_blurred_brightness() {
        let (w, h) = (64, 64);
        let mut rgb = vec![0.05; w * h * 3];
        let i = 32 * w + 32;
        rgb[i * 3..i * 3 + 3].fill(1.0);
        let c: Curve = [20.0, 18.0, 16.0, 14.0, 12.0, 10.0, 8.0, 6.0];
        let m = noise_map(&rgb, w, h, &c, 1.0);
        assert!((m[i + 1] - m[0]).abs() < 0.5, "{} vs {}", m[i + 1], m[0]);
    }

    /// Review Focus 5: the 2× never takes σ past 40, nor under 1.
    #[test]
    fn the_map_is_clamped() {
        let rgb = vec![0.5; 8 * 8 * 3];
        assert!(noise_map(&rgb, 8, 8, &[30.0; BANDS], 2.0).iter().all(|v| *v == 40.0));
        assert!(noise_map(&rgb, 8, 8, &[0.1; BANDS], 2.0).iter().all(|v| *v == 1.0));
    }
```

    // ai_denoise.rs
    /// Review Focus 3: each tile's plane covers the padded tile, and the dark half of a photo whose noise
    /// curve falls is given more σ than the bright half.
    #[test]
    fn each_tile_carries_its_map() {
        struct Record(std::sync::Arc<std::sync::Mutex<Vec<(usize, usize, Vec<f32>)>>>);
        impl TileNet for Record {
            fn run(&mut self, rgb: &[f32], w: usize, h: usize, s: &[f32]) -> Result<Vec<f32>, String> {
                self.0.lock().unwrap().push((w, h, s.to_vec()));
                Ok(rgb.to_vec())
            }
        }
        let seen = std::sync::Arc::new(std::sync::Mutex::new(Vec::new()));
        let img = image(301, 203, |x, _| if x < 150 { [0.002; 3] } else { [0.6; 3] });
        let enc = Encoding::of(&img);
        let c: crate::noise_curve::Curve = [20.0, 18.0, 16.0, 14.0, 12.0, 10.0, 8.0, 6.0];
        let sigma = |rgb: &[f32], w: usize, h: usize| crate::noise_curve::noise_map(rgb, w, h, &c, 1.0);
        denoise_in(&img, &enc, &mut Record(seen.clone()), &sigma, &|_, _| true).unwrap();
        let seen = seen.lock().unwrap();
        let (w, h, s) = &seen[0];
        assert_eq!(s.len(), w * h, "the plane covers the padded tile");
        assert_eq!((w % 8, h % 8), (0, 0));
        let at = |x: usize| s[(h / 2) * w + x];
        assert!(at(10) > at(290) + 2.0, "dark {} vs bright {}", at(10), at(290));
    }
