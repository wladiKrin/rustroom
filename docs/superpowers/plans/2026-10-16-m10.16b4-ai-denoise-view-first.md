# M10.16b4 — AI denoise: your view first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The tiles you are looking at are denoised first and shown as they land, the rest following behind.

**Architecture:** `ai_denoise::Tiler` replaces the one-shot tile loop: it picks the remaining tile nearest a focus point (decode-normalised), folds each tile in, and keeps the result up to date tile by tile — **the original decode wherever no tile has landed yet**, so the prefix step needs no coverage: where the "denoised" image equals the input, the blend changes nothing. The worker reads the focus the flow sets before every tile and publishes the result so far at most once a second (`DenoiseResult::Partial`); only the finished result is cached. The canvas records its visible centre; the flow maps it to decode space through the canvas's own `decode_point`.

**Tech Stack:** Rust; the app lib (`ai_denoise`, `denoise_worker`), the bin (`denoise_flow`, `develop::canvas`).

**Spec:** `docs/superpowers/specs/2026-10-16-m10.16b-strength-and-speed-design.md` §2.

## Global Constraints

- The job denoises the tiles nearest the view's centre first; the session publishes the centre in decode coordinates; the worker re-reads it between tiles — panning re-orders what is left. (§2)
- At most once a second the worker publishes the partial result; the prefix step blends only where covered and passes the rest through; each publish has its own id; the Detail line still counts the tiles. (§2)
- Only a finished result is cached; export never reads a partial result. (§2)
- The finished result is the same image as b3's one-shot run, bit for bit.
- No file over 1,000 lines of code and doc; the app lib has no egui; one cargo mode; clippy in `target/clippy`; no `Co-Authored-By` trailer; never push.

## Review Focus

1. **A job cancelled mid-way, then the photo reopened** — the partial result must not count as finished: the job runs again (and the partial stays on screen until it is replaced). Pinned in Task 3 (`a_partial_result_is_not_a_finished_one`).
2. **The finished result** — identical to b3's, whatever order the tiles ran in. Pinned in Task 1 (`the_step_by_step_result_is_the_one_shot_result`).
3. **A partial result reaching the cache** — never; the file appears only with the last tile. Pinned in Task 2 (`partial_results_arrive_and_only_the_finished_one_is_stored`).
4. **The overlap between a finished tile and an unfinished one** — the finished tile's own values there (normalised by the weight so far), never darkened by a missing neighbour's weight. Pinned in Task 1 (`a_partial_result_is_the_original_outside_finished_tiles`).
5. **A view centre outside the photo** (a small photo centred in a big canvas, a pan past the edge) — clamped into 0…1, the nearest tiles first. Pinned in Task 1 (`tiles_go_nearest_the_focus_first`, a focus at (2, 2)).

```rust
    /// A network that records each tile's first pixel — the image encodes position, so it names the tile.
    struct Where(std::sync::Arc<std::sync::Mutex<Vec<[f32; 3]>>>);
    impl TileNet for Where {
        fn run(&mut self, rgb: &[f32], _: usize, _: usize, _: &[f32]) -> Result<Vec<f32>, String> {
            self.0.lock().unwrap().push([rgb[0], rgb[1], rgb[2]]);
            Ok(rgb.to_vec())
        }
    }

    fn by_position(w: usize, h: usize) -> ImageBuf {
        image(w, h, |x, y| enc_identity_decode([x as f32 / w as f32, y as f32 / h as f32, 0.5]))
    }

    /// Review Focus 5: the first tile is the one nearest the focus, a focus past the photo clamped in.
    #[test]
    fn tiles_go_nearest_the_focus_first() {
        let img = by_position(1100, 700); // 3 × 2 tiles
        for (focus, want) in [([0.0, 0.0], [0.0, 0.0]), ([2.0, 2.0], [588.0 / 1100.0, 188.0 / 700.0])] {
            let seen = Default::default();
            let mut t = Tiler::new(&img, &Encoding { scale: 1.0 });
            t.step(&mut Where(std::sync::Arc::clone(&seen)), &flat, focus).unwrap();
            let first = seen.lock().unwrap()[0];
            assert!((first[0] - want[0]).abs() < 1e-3 && (first[1] - want[1]).abs() < 1e-3, "{first:?}");
        }
    }

    /// A focus moved between tiles re-orders what is left.
    #[test]
    fn a_moved_focus_reorders_the_rest() {
        let img = by_position(1100, 700);
        let seen: std::sync::Arc<std::sync::Mutex<Vec<[f32; 3]>>> = Default::default();
        let mut t = Tiler::new(&img, &Encoding { scale: 1.0 });
        let mut net = Where(std::sync::Arc::clone(&seen));
        t.step(&mut net, &flat, [0.0, 0.0]).unwrap();
        t.step(&mut net, &flat, [1.0, 1.0]).unwrap();
        let second = seen.lock().unwrap()[1];
        assert!((second[0] - 588.0 / 1100.0).abs() < 1e-3 && (second[1] - 188.0 / 700.0).abs() < 1e-3);
    }

    /// Review Focus 4: after one tile, the result is the original outside it and the network's inside.
    #[test]
    fn a_partial_result_is_the_original_outside_finished_tiles() {
        let img = image(1100, 700, |x, y| [0.1 + 0.0002 * x as f32, 0.12, 0.08 + 0.0003 * y as f32]);
        let mut t = Tiler::new(&img, &Encoding::of(&img));
        t.step(&mut Lift, &flat, [0.0, 0.0]).unwrap();
        let r = t.result();
        assert_eq!(r.pixel(1000, 600), img.pixel(1000, 600), "outside: the original");
        assert_ne!(r.pixel(10, 10), img.pixel(10, 10), "inside: denoised");
        assert_ne!(r.pixel(500, 10), img.pixel(500, 10), "the overlap: the finished tile's own");
        assert_eq!(t.done(), 1);
    }

    /// Review Focus 2: stepped in any order, the finished result is the one-shot result bit for bit.
    #[test]
    fn the_step_by_step_result_is_the_one_shot_result() {
        let img = image(1100, 700, |x, y| [0.1 + 0.0002 * x as f32, 0.12, 0.08 + 0.0003 * y as f32]);
        let enc = Encoding::of(&img);
        let one = denoise_in(&img, &enc, &mut Lift, &flat, &|_, _| true).unwrap().unwrap();
        let mut t = Tiler::new(&img, &enc);
        for focus in [[1.0, 1.0], [0.0, 0.5], [0.3, 0.0], [1.0, 0.0], [0.5, 1.0], [0.0, 0.0]] {
            t.step(&mut Lift, &flat, focus).unwrap();
        }
        assert_eq!(t.done(), t.total());
        assert_eq!(t.into_result().data(), one.data());
    }
```

(`flat` is `|_: &[f32], w: usize, h: usize| vec![8.0; w * h]`; `enc_identity_decode` is `Encoding { scale: 1.0 }.decode`.)

```rust
    /// tile; the finished result comes last.
    #[test]
    fn partial_results_arrive_and_only_the_finished_one_is_stored() {
        let d = test_dir::TempDir::new("denoise-worker-partial");
        let w = DenoiseWorker::spawn_publishing(
            Box::new(|| Ok(Box::new(Slow) as Box<dyn TileNet + Send>)),
            Some(d.path().to_path_buf()),
            || {},
            std::time::Duration::ZERO,
        );
        w.request(DenoiseRequest { key: "a".into(), image: Some(photo(1100, 700)) });
        let mut partials = 0;
        let mut done = false;
        for _ in 0..600 {
            for r in w.poll() {
                match r {
                    DenoiseResult::Partial { key, .. } => {
                        assert_eq!(key, "a");
                        if !done {
                            partials += 1;
                            if partials == 1 {
                                assert!(!crate::denoise_cache::exists(d.path(), "a"), "a partial was stored");
                            }
                        }
                    }
                    DenoiseResult::Done { .. } => done = true,
                    _ => panic!("a failure"),
                }
            }
            if done {
                break;
            }
            std::thread::sleep(std::time::Duration::from_millis(10));
        }
        assert!(done && partials >= 2, "{partials} partials, done {done}");
        assert!(crate::denoise_cache::exists(d.path(), "a"));

    /// The focus set before a job reaches it: the first tile is the one nearest it.
    #[test]
    fn the_focus_reaches_the_job() {
        struct Where(Arc<std::sync::Mutex<Vec<[f32; 3]>>>);
        impl TileNet for Where {
            fn run(&mut self, rgb: &[f32], _: usize, _: usize, _: &[f32]) -> Result<Vec<f32>, String> {
                self.0.lock().unwrap().push([rgb[0], rgb[1], rgb[2]]);
                Ok(rgb.to_vec())
            }
        }
        let seen: Arc<std::sync::Mutex<Vec<[f32; 3]>>> = Default::default();
        let s = Arc::clone(&seen);
        let w = DenoiseWorker::spawn(Box::new(move || Ok(Box::new(Where(s)) as Box<dyn TileNet + Send>)), None, || {});
        w.set_focus([1.0, 1.0]);
        let (pw, ph) = (1100, 700);
        let enc = crate::ai_denoise::Encoding { scale: 1.0 };
        let img = Arc::new(ImageBuf::from_vec(
            pw,
            ph,
            (0..pw * ph)
                .flat_map(|i| enc.decode([(i % pw) as f32 / pw as f32, (i / pw) as f32 / ph as f32, 0.5]))
                .collect(),
        ));
        w.request(DenoiseRequest { key: "a".into(), image: Some(img) });
        assert_eq!(wait(&w, 1).len(), 1);
        // ⚠ The job encodes in the photo's own encoding (`Encoding::of`), monotonic in x and y: the
        // bottom-right tile's corner has the largest of both among every tile's corner.
        let all = seen.lock().unwrap();
        assert_eq!(all.len(), 6, "3 × 2 tiles");
        let (mx, my) = all.iter().fold((0f32, 0f32), |(a, b), p| (a.max(p[0]), b.max(p[1])));
        assert_eq!((all[0][0], all[0][1]), (mx, my), "the bottom-right tile first: {:?}", all[0]);
    }
```
