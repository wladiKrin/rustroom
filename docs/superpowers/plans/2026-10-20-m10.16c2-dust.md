# M10.16c2 — Dust — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retouch's **Remove dust**: sensor dust found automatically in the photo and each spot added as an ordinary Heal patch — one click, one undo step, every patch removable like any other.

**Architecture:** A detector in the lib (`dust_tool`, no egui) finds soft, dark, round blobs in smooth areas of the undeveloped decode — a ring-against-centre contrast in log luminance over a few radii, gated by the local texture — and returns them in decode coordinates. They are mapped into the patches' post-lens space through the lens's inverse (`ai_space::DecodeMap::post_lens_of`), and become Heal spots whose source the existing auto-source picker (`spot_source::pick`) chooses. A button and a Sensitivity slider sit beside the existing **Find dust** view in Retouch.

**Tech Stack:** Rust, `rayon`, `pipeline::spatial::gaussian_blur`, `egui` 0.35.

**Spec:** `docs/superpowers/specs/2026-10-19-m10.16c-remove-design.md` (§ c2).

## Global Constraints

- No network, no download: "no network, the most value per cost".
- The finds become **Heal spots** — "the existing spot machinery … each removable like any spot" — with "a threshold slider for sensitivity".

- A spot lives in the post-lens, pre-perspective frame, normalised per axis; its radius is a fraction of the long edge (`edit_model::Spot`).
- DESIGN.md: hovers one sentence, no full stop, ≤ 110 chars; no literal font size or `Color32` outside `theme.rs`; every slider has a `slider_help` sentence.

### Task 1: The detector (lib, no egui)

**Files:** Create `crates/app/src/dust_tool.rs`; modify `crates/app/src/lib.rs` (module list).

**Interfaces — Produces:**
- `pub struct Find { pub centre: [f32; 2] /* decode-normalised */, pub radius: f32 /* fraction of the decode's long edge */, pub contrast: f32 /* log-luminance darkening, > 0 */ }`
- `pub const DEFAULT_SENSITIVITY: f32 = 50.0;` (0..=100)
- `pub fn find(img: &core_image::ImageBuf, sensitivity: f32) -> Vec<Find>` — strongest first, at most `MAX_FINDS = 200`.

**The algorithm** (constants are the builder's starting points; Task 4 measures and may retune, recording the numbers):
1. Luminance of `img` box-downscaled so the long side is ≤ `WORK = 3000`; `log(max(L, 1e-4))`.
2. `D = logL − gaussian_blur(logL, σ = 24)` — gradients and vignetting gone.
3. For each radius `r` in `[2.0, 3.0, 4.5, 7.0, 10.0, 15.0]` (working pixels): `c_r = blur(D, 2.5 r) − blur(D, 0.6 r)` (positive where a disc is darker than its ring); texture `t_r = sqrt(max(blur(D², 4 r) − blur(D, 4 r)², 0))`.
4. A candidate is a pixel where `c_r` is a strict maximum over its 3 × 3 neighbourhood and over the neighbouring radii, with `c_r ≥ min_contrast(sensitivity)` where `min_contrast(s) = 0.12 · 10^(−s/100)`, and `c_r ≥ 3 · t_r`, and the background luminance there (`blur(L, 24)`) at least 5 % of the frame's 99th-percentile luminance (dust in near-black is noise).
5. Non-maximum suppression: a weaker candidate within `2 · max(r)` of a stronger one goes. Strongest first; at most `MAX_FINDS`.

- [ ] **Tests:** `finds_soft_dark_discs_on_a_gradient` (a 1600 × 1200 linear gradient with five gaussian-edged discs, radii 4–20 px, darkening 4–15 % → all five found, each centre within 0.3 r, radius within ×2); `none_on_texture` (the same size, a seeded random texture of contrast 20 % with no discs → ≤ 2 finds at the default sensitivity); `a_bright_spot_is_not_dust` (a disc 10 % brighter → none); `nothing_in_near_black` (a disc on a 0.2 %-of-peak background → none); `sensitivity_finds_more_as_it_rises` (discs from 1 % to 12 % darkening: finds at 90 ≥ finds at 50 ≥ finds at 10, and 90 > 10).
- [ ] Red, implement, green; sabotage the texture gate (`c_r ≥ 3 · t_r` removed) → `none_on_texture` red; commit `feat(app): the dust detector — soft dark discs in smooth areas (M10.16c2)`.

### Task 2: Finds into Heal patches (lib)

**Files:** Modify `crates/app/src/ai_space.rs` (`DecodeMap::post_lens_of`), `crates/app/src/dust_tool.rs`.

**Interfaces:**
- Consumes: Task 1's `Find`.
- Produces: `DecodeMap::post_lens_of(&self, d: [f32; 2]) -> [f32; 2]` (the lens's inverse by fixed-point iteration — the loop `decode_to_frame` already runs, moved here and called from there); `pub fn to_spots(finds: &[Find], post_lens: &dyn Fn([f32; 2]) -> [f32; 2], aspect: f32, existing: &[edit_model::Spot], tool: spot_tool::SpotTool, sample: &dyn Fn([f32; 2]) -> [f32; 3]) -> Vec<edit_model::Spot>` — each find's centre through `post_lens`, radius `(1.6 · find.radius).clamp(spot_tool::MIN_RADIUS, spot_tool::MAX_RADIUS)`, `SpotMode::Heal`, the tool's feather, source from `spot_source::pick` (fallback: 3 radii up, else down — `place_with_source`'s rule); a find whose centre falls inside an existing spot's radius (or one already added) is skipped.

### Task 3: Retouch's Remove dust

**Files:** Create `crates/app/src/develop/panel/retouch_dust.rs` (the button and the Sensitivity slider beside Find dust); modify `crates/app/src/develop/panel/retouch.rs` (call it from `find_dust`'s place — a line or two), `crates/app/src/develop/canvas/spot_overlay.rs` (`sampler_for` → `pub(crate)`), `crates/app/src/slider_help.rs` (`Scope::Patch` gains `("Sensitivity", "Finds fainter dust, and with it more spots that are not dust")`).

**Interfaces — Consumes:** Task 1's `find`, Task 2's `to_spots`, `sampler_for(&mut Session)`, `Session.full_long`, `Edited::{discrete, note}`.

- Behaviour: **Remove dust** runs `find` on `s.buffer` at the slider's sensitivity, maps through `DecodeMap::with_shared(…, s.lens_memo.get(…), …).post_lens_of`, appends `to_spots(…)` to `s.edits.spots`, sets `ed.note` to `"Removed N dust spots"` / `"Found no dust"`, and `ed.discrete()` when N > 0. On a buffer whose long side is under 1,500 px (the stand-in) it detects nothing and notes `"Waits for the photo to load"`. Sensitivity is a tool setting: a field `dust: f32` on `spot_tool::SpotTool` (the Retouch tool's settings, not persisted — `spot_tool`'s standing), default `DEFAULT_SENSITIVITY`.
  - Hover for the button: `"Finds sensor dust in the photo and heals each spot with a patch"`.
- [ ] **Tests (the panel harness, `retouch.rs`'s `Panel`):** `remove_dust_adds_heal_patches_as_one_step` (a buffer with three dark discs → three Heal patches, `ed.settled`, note says 3; Review Focus 5); `remove_dust_waits_for_the_photo` (a 400 × 300 buffer → no patches, the note; Review Focus 4); `pressing_remove_dust_twice_adds_nothing_more`; every new hover and slider through the existing sweeps.
