# M10.19d — The Retouch panel as Paint · Find — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Retouch panel as option B: a **Paint · Find** switch deciding what the photo does, one brush,
one **Retouches** list across every kind with the selected retouch's settings under it, and People and Dust found
the same way — reviewed on the photo with **Pick · Add more**.

**Architecture:** Lib (no egui): `retouch_list` (the one list's rows, numbering and selection), `retouch_task`
(the task, what to find, the photo's gesture), `dust_tool::Run` extended into a review like `people_tool::Run`.
Bin: `retouch.rs` composes `retouch_brush`, `retouch_find`, `retouch_list` (panel); the canvas dispatches on the
task, `find_overlay` drawing people or dust with the chosen gesture; `dust_flow` lands a search as a review.

**Tech Stack:** Rust, egui 0.35.

**Spec:** `docs/superpowers/specs/2026-10-22-m10.19d-retouch-paint-find-design.md`.

## Review Focus

1. **A patch selected while painting**: the brush's sliders must not change it — `the_brush_never_edits_a_selected_retouch`.
2. **A list row of each kind**: picking it selects exactly that retouch and switches Paint and the brush to it —
   `picking_a_row_selects_it_alone_and_shows_its_brush`.
3. **A drag in Find**: never paints; in Add more it asks to look there; in Pick it asks nothing —
   `a_drag_in_find_paints_nothing_and_looks_only_in_add_more`.
4. **Dust's review**: Remove N spots makes N Heal patches marked `dust`, one undo step; the dust view on during the
   review only — `removing_dust_spots_makes_marked_heal_patches` and `the_dust_view_follows_the_review`.
5. **Deleting a retouch of one kind** renumbers that kind only and keeps every other row's flags —
   `deleting_one_kind_renumbers_only_that_kind`.

### Task 2: The task, the gesture and dust's review (lib)

**Files:** Create `crates/app/src/retouch_task.rs`; Modify `crates/app/src/dust_tool.rs`, `crates/app/src/lib.rs`.

**Interfaces — produces:**

```rust
// retouch_task
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)] pub enum Task { #[default] Paint, Find }
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)] pub enum FindKind { #[default] People, Dust }
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)] pub enum Gesture { #[default] Pick, Add }
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct RetouchState { pub task: Task, pub find: FindKind, pub gesture: Gesture }

// dust_tool — Run grows a review (people_tool::Run's shape)
pub struct Run {
    pub queued: Option<f32>, pub search: Option<Search>, pub said: Option<String>,   // as today
    pub active: bool,               // the review is on, from a landing until Remove, Cancel, a press, another photo
    pub finds: Vec<Find>, pub ticked: Vec<bool>,
    pub look: Option<Vec<[f32; 2]>>, // a drawing in Add more, decode-normalised
    pub there: Option<[f32; 4]>,     // the running search is a look there, in this decode rect
    pub view: bool,                  // the dust view on during the review (default true)
    pub contrast: f32,               // its threshold (visualize::DEFAULT_THRESHOLD)
}
pub fn hit(finds: &[Find], at: [f32; 2], w: usize, h: usize) -> Option<usize>; // within SPOT_SCALE × radius, nearest
pub fn place(f: Find, rect: [f32; 4], w: usize, h: usize) -> Find;             // a find of an area into the decode
pub fn fresh(new: Vec<Find>, finds: &[Find], spots_in_decode: &[[f32; 3]]) -> Vec<Find>; // not already found or patched
pub fn drawn(points: &[[f32; 2]], radius: f32, w: usize, h: usize) -> Find;     // the drawing itself, (a)
pub fn summary(n: usize, ticked: usize) -> String;      // "No dust found" | "1 spot · 1 to remove" | "7 spots · 5 to remove"
pub fn remove_label(ticked: usize) -> String;           // "Remove 1 spot" | "Remove 7 spots"
pub const LOOK_SENSITIVITY: f32 = 100.0;
```

(`Run` keeps `Default`, `view: true` and `contrast` set by a manual `Default`.)
