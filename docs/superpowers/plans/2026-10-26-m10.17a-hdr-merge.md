# M10.17a HDR merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Photo → Photo merge → HDR…: a bracket of raws aligned, deghosted and merged into a floating-point
`-HDR.dng` that Rustroom reads back as a raw of the same camera.

**Architecture:** `raw-decode` gains a camera-space decode (`decode_camera`) and its own reader for float
`LinearRaw` DNGs; `export` gains the float DNG writer; a new zero-GUI crate `photo-merge` holds the frames,
alignment, exposure, deghost, merge, the preview render and the orchestration; the CLI and the app (lib worker +
bin dialog/flow) drive it.

**Tech Stack:** Rust workspace; libraw via `rsraw`; `flate2` + `half` (both already in `Cargo.lock`); rayon;
egui 0.35 for the dialog.

**Spec:** `docs/superpowers/specs/2026-10-26-m10.17a-hdr-merge-design.md`

  predictor **3**, **16-bit float**, `WhiteLevel` 1.0, IFD0 preview **1024 px**; output `<first stem>-HDR.dng`,
  then `-HDR-2`…; shortcuts ⇧⌘H and ⌥⇧⌘H; Lightroom's defaults (Auto align on, Auto settings on, Deghost None,
  overlay off, Create stack off).

## Review Focus

1. **The same file twice** (a photo and its virtual copy, or a RAW+JPEG pair) — merged as one frame, the raw of
   the pair; two distinct raws needed. → Task 10 `a_virtual_copy_and_its_original_are_one_frame`.
2. **A name already taken** — `-HDR.dng` exists → `-HDR-2.dng`; the partial file is a dot-file the scan never
   lists. → Task 10 `the_name_steps_past_a_taken_one`, Task 2 `the_partial_file_is_hidden_and_renamed`.
3. **Cancel or quit mid-merge** — no `-HDR.dng` and no visible partial. → Task 11
   `a_cancelled_merge_leaves_no_file`.
4. **Frames that share almost nothing valid** (a wide bracket, a black frame) — alignment falls back (neighbour,
   then identity) and the output stays finite. → Task 5 `a_frame_with_nothing_in_common_falls_back_to_identity`,
   Task 6 `the_merge_is_finite_everywhere`.
5. **A merged DNG in the selection** — refused, never fed to `decode_camera`. → Task 10
   `a_merged_hdr_is_refused`.
