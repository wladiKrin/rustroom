# M10.18e Print Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** File → Print… ⌘P puts the selection on pages, Single (Fit/Fill) or a contact sheet, written as a
PDF or sent to a CUPS printer.

**Architecture:** the export worker renders each photo into a staging folder at its printed size × PPI.
The lib module `print` lays out pages, writes a hand-rolled PDF that embeds the JPEGs as they are, and
builds the `lp` call. The bin side has a flow, pumped every frame, and a dialog with a live page preview.

**Tech Stack:** Rust, egui 0.35, no new crate.

**Spec:** `docs/superpowers/specs/2026-11-03-m10.18e-print-design.md`

## Global Constraints

- No egui in `crates/app/src/print/` (a lib module). The dialog is in `modals/print.rs`.
- Hover text goes through `theme::Hover`'s `.hover()`: one sentence, no full stop. No literal `Color32` or
  font size outside `theme.rs`.
- No file over 1,000 lines of code and doc. Nothing is added to `session_flow.rs`.
- Tests: directories come from `test_dir`. A test waits on an event under a 120 s ceiling, never a fixed
  budget. Every fixture says whether it was captured or constructed.
- Gate: `cargo test --workspace <filter>`, then clippy with `CARGO_TARGET_DIR=target/clippy`, then
  `cargo fmt --check`.

## Review Focus

1. A selection mixing portraits and landscapes, Fill with Rotate on: each photo covers its cell with no
   white edge.
2. One photo more than a page holds: the last page holds one cell.
3. A caption with characters outside WinAnsi (`ł`, emoji): printed as `?`, and the PDF stays valid.
4. A photo that fails to render: named in the outcome, the other photos still printed, and no empty cell
   left unexplained.
5. `lpstat` missing (this machine): the dialog offers PDF only and nothing panics.

### Task 1: Fill sizes in export

**Files:** `crates/export/src/sizing.rs`

- Add `FitMode::Cover`, covering a `width` × `height` box as given, and `FitMode::CoverEither`, covering it
  either way round. Neither goes in `FitMode::ALL`, so the export dialog never offers them. Give them
  labels and `uses_length() == true`.
- In `plan`: `Cover` is `max(W/w, H/h)`; `CoverEither` is `max(max(a,b)/long, min(a,b)/short)`.
- Tests:
  - `cover_fills_the_box_and_overflows_one_side`: 3000×2000 into 1000×1000 px gives 1500×1000.
  - `cover_either_turns_the_box_to_the_photo`: 2000×3000 into a box of 1500×1000 gives 1000×1500.
  - `cover_is_not_offered_in_the_export_dialog`: `!ALL.contains(&Cover)`.

### Task 2: Page geometry (`print/layout.rs`)

**Produces:**
```rust
pub enum Paper { A3, A4, A5, Letter, In4x6, In5x7, In8x10 }   // ALL, label(), size_mm() (portrait)
pub enum Orientation { Portrait, Landscape }
pub enum Layout { Single, ContactSheet }
pub enum Fit { Fit, Fill }
pub enum Sharpening { Off, Low, Standard, High }              // amount(): 0/25/50/75
pub struct PrintSettings { layout, paper, orientation, margin_mm: f32, fit, columns: u8, rows: u8,
    gap_mm: f32, captions: bool, rotate: bool, ppi: u16, sharpening, printer: Option<String>, copies: u16 }
    // serde(default), a hand-written Default (A4, Portrait, 10 mm, Fit, 4×5, 5 mm, captions on, rotate on, 300, Standard, 1 copy)
pub struct Rect { x, y, w, h }                                // PDF points, origin bottom-left
pub fn page_size_pt(&PrintSettings) -> (f32, f32)
pub fn per_page(&PrintSettings) -> usize
pub fn pages(n: usize, &PrintSettings) -> Vec<Vec<usize>>     // photo indices per page
pub fn cell(&PrintSettings, slot: usize) -> Rect              // the photo's box, the caption excluded
pub fn caption_at(&PrintSettings, slot) -> Option<(f32, f32)> // the caption's centre baseline
pub struct Placed { pub image: Rect, pub rotated: bool, pub clip: Rect }
pub fn place(px: (usize, usize), cell: Rect, fill: bool, rotate: bool) -> Placed
pub fn export_size(&PrintSettings) -> OutputSize              // cm, ppi, dont_enlarge, WidthHeight/Dimensions/Cover/CoverEither
```
- Fill only applies to Single; a contact sheet is always Fit.
- Rotated: a photo whose orientation differs from the cell's turns, when `rotate` is on.
- Tests:
  - A4 portrait is 595.3×841.9 pt;
  - 21 photos in a 4×5 sheet make pages of 20 and 1;
  - a Fit landscape in a portrait cell, rotate on, is rotated and larger than unrotated;
  - Fill covers the cell (image ⊇ clip == cell);
  - the export size is the cell's size in cm at the PPI, for both fits.

### Task 3: The PDF (`print/pdf.rs`)

**Produces:** `pub struct PageContent { size: (f32,f32), images: Vec<PageImage>, captions: Vec<(f32,f32,String)> }`,
`pub struct PageImage { jpeg: Vec<u8>, px: (usize,usize), placed: Placed }`, and
`pub fn write(pages: &[PageContent], caption_pt: f32) -> Vec<u8>`.
- Objects: Catalog, Pages, one Page each, one image XObject per photo (`/Filter /DCTDecode`,
  `/ColorSpace [/ICCBased n]`), one shared ICC stream (`export::icc_for(Srgb)`, `/N 3`), Helvetica with
  WinAnsiEncoding, and the xref with exact offsets.
- Captions are escaped (`\ ( )`), WinAnsi-mapped, and `?` stands for any other character.
- Tests:
  - every xref offset points at `n 0 obj`;
  - two pages give `/Count 2`;
  - a caption `a(b)ł` is written `a\(b\)?`;
  - a rotated image's `cm` turns it (the matrix's b and c are non-zero).
- Manual check: `pdfinfo` and `pdftoppm` on a written file.

### Task 4: Printers (`print/printer.rs`)

**Produces:**
- `pub trait Runner { fn run(&self, prog: &str, args: &[String]) -> std::io::Result<(bool, String)>; }`
- `pub struct System;`
- `pub fn printers(&dyn Runner) -> Vec<String>`, which parses `lpstat -e`, one name per line, empty when
  it is missing or fails.
- `pub fn lp_args(printer, copies, paper, file) -> Vec<String>`
- `pub fn send(&dyn Runner, ...) -> Result<(), String>`
- `Paper::media()`: `A3`, `A4`, `A5`, `Letter`, `4x6`, `5x7` and `8x10`, as CUPS names them (`na_index-4x6_4x6in`
  and the like).
- Tests: the list is parsed; a missing program gives an empty list; the arguments are exact; a failed `lp`
  is an error carrying its output.

### Task 5: The job (`print/job.rs`)

**Produces:**
- `pub fn export_options(&PrintSettings, staging: &Path) -> ExportOptions`: JPEG 95, sRGB, Files, the
  default metadata, sharpening, `export_size`, and no watermark.
- `pub fn assemble(settings, order: &[PhotoId], names: &[String], written: &HashMap<PhotoId, PathBuf>) -> Result<(Vec<u8>, usize /*pages*/), String>`:
  it reads each JPEG and its dimensions (`image::image_dimensions`), places it, and writes the PDF. A photo
  that did not render leaves its cell out, and the pages close up.
- `pub fn outcome(...) -> String`: "Printed N photos on P pages to X" or "Saved P pages to f.pdf",
  followed by the failed count and the below-PPI count.
- Tests use constructed JPEGs written with `image`.

### Task 6: The app (`print_flow.rs`, `modals/print.rs`, the menu, Settings)

- `Settings.print: PrintSettings`.
- `Command::Print`, with File → Print… ⌘P, its command help, and the disabled state with no selection.
- `Modal::Print { draft, printers, page, ids }`, opened by `open_print`. The printer list is read once, when
  the dialog opens.
- The dialog:
  - a preview of the current page, painted from thumbnails (`get_stale`), with ‹ ›;
  - the settings grid;
  - the footer button "Print" or "Save PDF…", plus Cancel.
- `start_print` saves the settings, asks for the PDF path (rfd) when saving, and spawns the export into
  `cache_dir/rustroom/print/<stamp>`.
- `pump_print`:
  - shows progress in the status;
  - on Finished, assembles on a thread, then writes the file or calls `lp`;
  - sets the status;
  - removes the staging folder.
- Tests, through `test_app`:
  - ⌘P opens the dialog on the selection;
  - Save writes a PDF with the page count, through an injected path and the export's real worker on
    constructed JPEGs;
  - with no printers, Print is not offered.
