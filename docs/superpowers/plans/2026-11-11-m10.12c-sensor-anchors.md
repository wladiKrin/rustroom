# M10.12c sensor anchors — Implementation Plan

> Executed inline (superpowers:executing-plans), the author's standing choice.

**Goal:** a spot, an eye or a brush stroke stays on its content when lens correction or perspective changes.
**Spec:** `docs/superpowers/specs/2026-11-11-m10.12c-sensor-anchors-design.md`

## Global Constraints
- `cargo test --workspace <filter>` only, never `-p`. Clippy goes in `CARGO_TARGET_DIR=target/clippy`.
- A new serde field is `default` + `skip_serializing_if`. The fingerprint test must stay pinned.
- No egui in `pipeline` or in app lib modules. No file over 1,000 lines. Add nothing to `session_flow.rs`.
- Every new test is sabotaged once. Every fixture says whether it is constructed or captured.

## Review Focus
1. A legacy item (no `decode`) renders exactly as before, in the preview, in export and in a rendered preview.
2. A photo with no lens profile and no perspective: the mapping must be the identity. A gesture still writes `decode: true`.
3. Undo to an entry from before migration brings back legacy items, which must still render right.
4. A pasted or synced spot from another photo keeps its own flag.
5. The resolver must never build a full-size corrector per frame. It is memoised.

### Task 1: the `decode` marker (edit-model)
- `Spot`, `Eye`, `BrushStroke` gain `pub decode: bool`, `#[serde(default, skip_serializing_if = "is_false")]`.
- Docs on each say: decode space when true, else the old working space.
- Fix the constructors and exhaustive fixtures the compiler names.
- Test `a_marker_free_mark_serializes_as_before_and_a_decode_one_round_trips`.

### Task 2: `pipeline::anchors`
- `Anchoring::new(lens: Option<&LensShot>, lc: LensCorrection, p: Perspective, decode_w, decode_h)`:
  - a distortion-and-scale corrector at a nominal long edge of 1024, memoised process-wide;
  - `Homography::from_edits(&p, aspect)` when active.
- `to_post_lens(d)` uses fixed-point iteration (eight steps). `to_decode(p)` uses the green channel of
  `Corrector::source`. `stroke_to_working(d)` is post-lens, then the homography forward.
  `stroke_to_decode(w)` is the homography's `source_of`, then `to_decode`.
- `resolve(&Edits, &Anchoring) -> Cow<Edits>` maps decode items to working space and clears the flag. It
  borrows when nothing is anchored.
- `migrate(&mut Edits, &Anchoring) -> bool` maps legacy items to decode and sets the flag.
- Tests:
  - round trip within 0.01 px over a grid with the corners;
  - identity without a lens or perspective;
  - legacy passes through bit for bit;
  - the nominal-size corrector agrees with the full-size one within 0.05 px normalised to the frame;
  - a spot rendered through `SpotRemovalStage` lands on the same feature with correction on and off;
  - a stroke's coverage centroid does the same, with lens and with a keystone;
  - `migrate` then `resolve` returns the original working coordinates.

### Task 3: renderers resolve at entry
- The render engine worker, beside the scene-referred strip, takes the decode size from `buffer` and the lens
  it holds.
- `batch_export/render.rs` before its prefix and tail builds.
- The CLI `render`.
- Test: an engine frame with a decode-anchored spot equals the frame with that spot's legacy equivalent.

### Task 4: the canvas
- Overlays (spot, eye, mask painting and tint, hover coverage, hit tests) draw each item through its flag.
  - Decode items go through `DecodeMap::decode_to_frame` for spots and eyes, and the same path for strokes,
    since decode → post-lens → homography → frame is the stroke's chain too.
  - Legacy items go through the old maps.
- Gestures write decode, through `DecodeMap::frame_to_decode`, and set the flag.
- The auto-source sampler reads the decode directly, with no corrector.
- Find dust writes its finds as decode spots.
- Tests: the existing overlay tests, plus a click on a lens-corrected photo storing the decode point.

### Task 5: migration on open
- When Develop has its lens and decode size, migrate legacy items once per session, with no undo step.
- Test: the picture is unchanged within 1e-3, and the items are flagged.
