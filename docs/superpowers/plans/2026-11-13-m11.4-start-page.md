# M11.4 start page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A launch reopens the Library's last source with its photo selected (on by default, switchable). When it can't, a start page fills the middle: a Continue list, plus a two-map welcome that stays until it is ticked away.

**Architecture:** A lib module, `rustroom_app::start` (no egui), holds the stored place, the reopen decision and the Continue rows. A bin module, `place.rs`, converts `LibrarySource` to and from the stored place, reopens on the first frame, and mirrors the place into the settings afterwards. A bin module, `start_page.rs`, draws the page in place of the old `library::empty_library`.

**Tech Stack:** Rust, egui/eframe 0.35, serde (settings JSON), the existing `RailData` catalog snapshot.

**Spec:** `docs/superpowers/specs/2026-11-13-m11.4-start-page-design.md` (mockups: <https://claude.ai/artifact/Hnj6DR4oeAh21SR1KGYjge>)

## Global Constraints

- Logic in the lib (`crates/app/src/lib.rs` modules: no egui); widgets in bin modules (`main.rs`'s list).
- Every new control has a hover: one sentence, sentence case, **no full stop** (`every_hover_is_one_short_sentence`).
- Four text sizes only, through `TextStyle` (`.heading()` = Display for the page heading, `.small()` = Caption); no literal font size or `Color32` outside `theme.rs`/`theme/tokens.rs`. Colours come from `theme::tokens::of(ui)` and `theme::accent_color`.
- `Settings` has a container-level `#[serde(default)]`: `reopen_last` and `show_welcome` default to **true** in `Settings::default()`. Add no field-level `#[serde(default)]`.
- Copy, verbatim: heading "Welcome to Rustroom" with the sentence "Your files are never changed, edits are kept separately beside them." while the welcome shows; "No photos open" with "Pick up where you were, or open something new" once it has gone. Buttons "Open a folder…" (primary) and "Import from a card…". Card title "What's where". Checkbox "Don't show this again". Settings rows "Reopen where you left off" and "Show the welcome on the start page". Sub-label "Continue". **No drop hint anywhere.**
- Map keys, verbatim: ① "Library · Develop: browse, or edit one photo" ② "Rail: where photos come from" ③ "Search and Filter: narrow the grid" ④ "Status row: counts, sort and jobs"; ⑤ "Panel: the edits, in sections" ⑥ "Tools: crop, masks, retouch and more" ⑦ "Filmstrip: the other photos you have open" ⑧ "Export: save the finished picture". ① sits in both maps.
- Tests: `cargo test --workspace <filter>`, never `-p`. Clippy: `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets -- -D warnings`. Test directories come from `test_dir`. Commits carry **no** `Co-Authored-By` trailer.
- No file over 1,000 code+doc lines. `session_flow.rs` (987) gets nothing new. Report any touched file over 600.

## Review Focus

1. **The first frame's `None` must never overwrite the stored place.** The mirror runs only after the reopen has been attempted. Test: `the_mirror_does_not_write_before_the_reopen` (Task 3).
2. **An Immich reopen that is still loading must not be stored as "nothing open"**, and a failed one must drop the pending state so the mirror resumes. Test: `a_failed_immich_reopen_leaves_the_start_page_and_resumes_the_mirror` (Task 3).
3. **A click elsewhere while a reopen is pending wins**: the stored selection is not forced onto the new source. Test: `a_new_source_before_the_reopen_lands_drops_the_selection` (Task 3).
4. **An old settings file** (no new fields) loads with reopening on and the welcome showing. Test: `an_old_settings_file_reopens_and_welcomes` (Task 1).
5. **A stored photo that is no longer in the source** leaves the default selection and does not panic. Test: `a_missing_photo_keeps_the_default_selection` (Task 3).

**Interfaces:**
- Consumes: Tasks 1–2; `RustroomApp::{open_catalog_folder, open_all_photos, open_smart, open_periods, open_collection, open_keyword, open_publish, open_person}` and the two extracted Immich openers.
- Produces:
  - `pub(crate) fn to_place(source: &LibrarySource) -> start::Source` and `pub(crate) fn from_place(source: &start::Source) -> LibrarySource`, both exhaustive matches (no `_` arm).
  - `RustroomApp.place_state: PlaceState`, where `pub(crate) enum PlaceState { NotTried, Pending(start::Place), Mirroring }` (it starts as `NotTried`).
  - `pub(crate) fn pump_place(&mut self, ctx: &egui::Context)`, called once per frame in `shell/mod.rs`'s `ui` after `handle_input` and before `top_panel`. It does three things by state:
    - `NotTried`: if `settings.reopen_last` and `last_place` is `reopenable`, open it through the matching opener and go to `Pending`; otherwise go to `Mirroring`. ⚠ It does nothing while the window is a ghost session (`buffer_is_ghost`), which never applies in the Library.
    - `Pending(place)`: when `library.source` converts to `place.source`, select the stored `(path, copy)` if it is among the entries, as the only selection and the active one, set `lib.reveal = true`, and go to `Mirroring`. Also go to `Mirroring`, with no selection, if the library shows a different source, or if `immich_opening` is `None` while the library is still `None` (the Immich reply failed; its status line already says why).
    - `Mirroring`: compute `library.as_ref().map(|l| to_place(&l.source))`. When it differs from `settings.last_place`'s source, or one of them is `None` and the other is not, store `Place { source, selected: <the active entry's (path, copy)> }` and `save_settings()`.
  - `pub(crate) fn remember_place_on_close(&mut self)`: when mirroring, store the current place, its selection taken from the open Develop session's `(path, copy)` if there is one, otherwise the Library's active entry, and save.
