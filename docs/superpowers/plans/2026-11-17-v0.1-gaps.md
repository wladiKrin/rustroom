# v0.1 piece 1 — the version in About and more RAW formats: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. ⚠ This project runs plans **inline** (executing-plans) by the author's standing choice.

**Goal:** About shows the version (and the commit of a git build), and the Library takes the 17 more RAW formats the bundled LibRaw decodes.

**Architecture:** The format list stays in `catalog` (`RAW_EXTENSIONS`, `IMAGE_EXTENSIONS`); the Open dialog stops keeping its own copy. The version line is a pure lib function (`rustroom_app::about`), fed by `CARGO_PKG_VERSION` and a commit a new `crates/app/build.rs` reads from git.

**Tech Stack:** Rust, egui (the About modal), a Cargo build script.

**Spec:** `docs/superpowers/specs/2026-11-17-v0.1-gaps-design.md`

## Global Constraints

- New RAW extensions, exactly: `pef nrw srw rwl raw 3fr fff iiq mos mef erf sr2 srf mrw crw kdc dcr` (17). **Not** `x3f` (needs `USE_X3FTOOLS`) nor `gpr` (needs `USE_GPRSDK`) — neither defined by `rsraw-sys`.
- Append, never insert (`AGENTS.md`): the new extensions go at the END of `RAW_EXTENSIONS`.
- The commit falls back to `unknown` (a build outside git); the About line then shows the version alone.
- Anything visible follows `docs/DESIGN.md`; text through `theme` helpers, no literal sizes.
- No commit trailer; never push; branch `v0.1-gaps`.
- ⚠ `session_flow.rs` is at the 1,000-line ceiling (`AGENTS.md`) — this plan only REMOVES lines from it.

## Review Focus

1. **An upper-case extension** (`IMGP0001.PEF`, as cameras write) is recognised — Task 1's test uses upper case.
2. **A `.raw` that is not a camera's** must fail to decode as an error, never a panic — Task 1 adds `a_file_that_is_not_a_raw_is_an_error_not_a_panic` in `raw-decode`.
3. **A build outside git** (a source tarball) still compiles and shows "Version 0.1.0" — Task 2's `version_line` test covers `unknown`; the build script must not fail without `git` or `.git`.
4. **The Open dialog and the catalog disagreeing** — Task 1 derives the dialog's list; Step 5 proves no literal list is left.
5. **A decode that LibRaw claims but this build cannot do** — Task 4 opens one real sample per new format before the docs say so.

```rust
/// v0.1: every format the bundled LibRaw decodes reaches the Library, upper case as cameras write it.
#[test]
fn every_raw_format_the_bundled_libraw_decodes_is_raw() {
    for ext in ["pef","nrw","srw","rwl","raw","3fr","fff","iiq","mos","mef","erf","sr2","srf","mrw","crw","kdc","dcr",
                "cr2","cr3","nef","arw","raf","dng","orf","rw2"] {
        assert!(is_raw(Path::new(&format!("a.{ext}"))), "{ext}");
        assert!(is_raw(Path::new(&format!("A.{}", ext.to_uppercase()))), "{ext} upper");
    }
}

/// Built without their SDKs (`USE_X3FTOOLS`, `USE_GPRSDK`): offering them would offer photos that never open.
#[test]
fn sigma_and_gopro_raws_stay_out() {
    assert!(is_raw(Path::new("a.pef")), "positive control");
    for ext in ["x3f", "gpr"] {
        assert!(!is_supported(Path::new(&format!("a.{ext}"))), "{ext}");
    }
}

#[test]
fn the_open_dialog_list_is_every_supported_extension_once() {
    let all = supported_extensions();
    for e in RAW_EXTENSIONS.iter().chain(IMAGE_EXTENSIONS) {
        assert_eq!(all.iter().filter(|x| *x == e).count(), 1, "{e}");
    }
    assert_eq!(all.len(), RAW_EXTENSIONS.len() + IMAGE_EXTENSIONS.len());
}
```
