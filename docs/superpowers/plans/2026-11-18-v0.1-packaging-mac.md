# v0.1 piece 3b — the Mac app: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. ⚠ This project runs plans **inline** (executing-plans) by the author's standing choice.

**Goal:** `Rustroom-0.1.0-macos-arm64.dmg` — `Rustroom.app` with its Homebrew libraries and libgphoto2's drivers
inside, ad hoc signed, opening on macOS 15 and later — built by one script locally and by the release workflow.

**Architecture:** ONE script, `packaging/macos/build.sh`, makes the bundle and the disk image; the release workflow's
`macos` job only calls it (on `macos-15`, with `--floor 15.0`). The script copies every non-system library the binary
and the drivers reach into `Contents/Frameworks`, the drivers into `Contents/PlugIns/libgphoto2/{camlibs,iolibs}`,
rewrites every reference to `@rpath/<name>`, measures the floor, writes `Info.plist` from a committed template, and
signs inside out. A lib module, `rustroom_app::app_bundle`, tells libgphoto2 and libheif at startup where those
folders are.

**Tech Stack:** bash with macOS's own `otool`, `install_name_tool`, `codesign`, `iconutil`, `plutil`, `hdiutil`,
`shasum`; Homebrew's `little-cms2 libheif libgphoto2 pkgconf`; `cargo-about`; Rust (the `app` crate's lib).

**Spec:** `docs/superpowers/specs/2026-11-18-v0.1-packaging-mac-design.md`

## Global Constraints

- Bundle identifier **`io.github.wladikrin.Rustroom`** — fixed forever. Apple Silicon only; file name
  `Rustroom-<version>-macos-arm64.dmg`. The release's floor is **15.0**.
- Drivers: every camlib **except `ax203`, `st2205`, `tp6801`, `docupen`**; every iolib.
- Ad hoc signing (`codesign --sign -`) only — no Developer ID, notarisation or hardened runtime (piece 4).
- No tool beyond macOS's own, Homebrew's four formulae and `cargo-about`. Every path from `brew --prefix`, never a
  literal `/opt/homebrew`. The script `cd`s to the repository root and starts from an empty `target/macos`.
- No egui in the lib; `main` gets one call and no `cfg` (`rustroom_app::console`'s pattern). Nothing changes off macOS.
- One cargo mode (`cargo test --workspace <name>`); clippy into `target/clippy`; no commit trailer; never push;
  branch `v0.1-packaging-mac`.

## Review Focus

1. **A variable the user already set** (`launchctl setenv CAMLIBS …`) is never replaced — Task 1's test.
2. **A bundle path with a space** (`/Users/x/My Apps/Rustroom.app`, a mounted `Rustroom 0.1.0` volume) — Task 1's
   test for the derivation; every path in the script quoted, and Task 4 runs the app from the mounted image.
3. **App Translocation:** a quarantined app runs from a random read-only copy — the folders come from the running
   executable, so they follow it; Task 6's quarantined launch reads the open drivers with `lsof`.
4. **A Homebrew update renames a library** (`libx265.217` → `.218`): the walk follows it and the licence map matches
   by pattern (`libx265.*.dylib`), not by full name — Task 3's dry check.
5. **The script run twice, or from another folder:** the second run starts clean and ends with the same file list —
   Task 2's step.

### Task 1: `rustroom_app::app_bundle` — the libraries' folders inside a bundle

**Files:** Create `crates/app/src/app_bundle.rs`; modify `crates/app/src/lib.rs` (`pub mod app_bundle;` just before
`pub mod app_icon;` — the list is alphabetical); modify `crates/app/src/main.rs` (the first line of `fn main`, before
`console::attach_to_parent()`).

**Interfaces — Produces:**
- `pub struct RuntimeDirs { pub camlibs: PathBuf, pub iolibs: PathBuf, pub heif_plugins: PathBuf }` (`Debug, Clone,
  PartialEq, Eq`).
- `pub fn runtime_dirs(exe: &Path) -> Option<RuntimeDirs>` — `Some` only when `exe`'s parent is named `MacOS`, its
  parent `Contents`, and that one's parent's name ends in `.app`; then `Contents/PlugIns/libgphoto2/camlibs`,
  `Contents/PlugIns/libgphoto2/iolibs`, `Contents/PlugIns/libheif`. Paths only — no file system access.
- `pub fn to_set(dirs: &RuntimeDirs, is_set: impl Fn(&str) -> bool) -> Vec<(&'static str, PathBuf)>` — in the order
  `CAMLIBS`, `IOLIBS`, `LIBHEIF_PLUGIN_PATH`, leaving out every name `is_set` answers true for.
- `pub fn point_libraries_inside()` — on macOS: `std::env::current_exe()`, `runtime_dirs`, `to_set` with
  `|k| std::env::var_os(k).is_some()`, `std::env::set_var` each; any failure does nothing. Off macOS the body is
  empty. Its doc says why it must run before any thread (`set_var` is not thread-safe).

  with `\`):

### Task 2: `packaging/macos/build.sh` — a bundle that runs

**Files:** Create `packaging/macos/build.sh` (`chmod +x`, `#!/bin/bash`, `set -euo pipefail`, a header like
`build.ps1`'s: what it builds, what it needs, what it writes) and `packaging/macos/Info.plist` (a template).

**Interfaces — Produces:** `packaging/macos/build.sh [--floor <version>]` → `target/macos/Rustroom.app` (this task),
the `.dmg` and its `.sha256` (Task 4). A `fail "<why>"` that prints to stderr and exits 1.

- [ ] **The template**, `plutil -lint` clean: `CFBundleIdentifier` `io.github.wladikrin.Rustroom`; `CFBundleName` and
  `CFBundleDisplayName` `Rustroom`; `CFBundleExecutable` `Rustroom`; `CFBundleIconFile` `rustroom`;
  `CFBundlePackageType` `APPL`; `CFBundleInfoDictionaryVersion` `6.0`; `CFBundleShortVersionString` and
  `CFBundleVersion` `@VERSION@`; `LSMinimumSystemVersion` `@MIN_MACOS@`; `NSHighResolutionCapable` true;
  `LSApplicationCategoryType` `public.app-category.photography`; `NSHumanReadableCopyright` `© The Rustroom
  contributors. GPL-3.0-or-later.`; and the purpose strings, exactly:
  - `NSDesktopFolderUsageDescription` — `Rustroom opens and saves the photos you keep on your Desktop.`
  - `NSDocumentsFolderUsageDescription` — `Rustroom opens and saves the photos you keep in Documents.`
  - `NSDownloadsFolderUsageDescription` — `Rustroom opens and saves the photos you keep in Downloads.`
  - `NSRemovableVolumesUsageDescription` — `Rustroom imports photos from your camera's card.`
  - `NSNetworkVolumesUsageDescription` — `Rustroom opens and saves photos on network drives.`
  - `NSLocalNetworkUsageDescription` — `Rustroom connects to your Immich server on your home network.`
- [ ] **The script, steps a–f and h of the spec:** the version from `cargo metadata` (the `app` package);
  `PKG_CONFIG_PATH` from `brew --prefix` of `little-cms2` and the prefix's `lib/pkgconfig`; `cargo build --release -p
  app`; the bundle's folders; the binary into `Contents/MacOS`; the drivers from `$(brew --prefix
  libgphoto2)/lib/libgphoto2/<version>/` (minus the four) and `…/libgphoto2_port/<version>/`; an empty
  `Contents/PlugIns/libheif`.
  - **The walk:** from the binary and every driver, each `otool -L` entry outside `/System/` and `/usr/lib/` —
    resolving `@rpath/x` through the referrer's own `LC_RPATH` entries (with `@loader_path` replaced by its folder)
    and `@loader_path/x` directly — copied once into `Frameworks` by base name (`cp -L`, then `chmod u+w`), and
    walked in turn.
  - **The rewrite:** every copied library's id to `@rpath/<name>`; every non-system reference in every Mach-O to
    `@rpath/<base name>`; every existing `LC_RPATH` deleted; then one rpath each — the binary
    `@executable_path/../Frameworks`, a driver `@loader_path/../../../Frameworks`, a library `@loader_path`.
    (Measured 2026-11-18: the binary's load commands end 232 bytes before its first section — room for its rpath.
    If `install_name_tool` ever reports no room, add `-Wl,-headerpad_max_install_names` to the macOS target's
    rustflags in `.cargo/config.toml`.)
  - **The outside-path check:** every `otool -L` entry and `LC_RPATH` path of every Mach-O in the bundle starts with
    `/System/`, `/usr/lib/`, `@rpath/`, `@executable_path/` or `@loader_path/` — else `fail` naming the file and path.
  - **The floor:** each Mach-O's `LC_BUILD_VERSION` `minos` (or `LC_VERSION_MIN_MACOSX` `version`); the highest, by
    `sort -V`, becomes `@MIN_MACOS@` and is printed with the files that set it. With `--floor F`, a higher one
    fails: `the bundle needs macOS <m> (<file>), more than the required F`.
  - **`Info.plist`** from the template (`sed` the two placeholders; `plutil -lint`); **the icon:** an `.iconset` from
    `packaging/icons/png/` (`icon_16x16` 16, `@2x` 32; `32x32` 32, `@2x` 64; `128x128` 128, `@2x` 256; `256x256`
    256, `@2x` 512; `512x512` 512, `@2x` 1024), `iconutil -c icns` → `Contents/Resources/rustroom.icns`.
  - **Signing:** `codesign --force --sign - --timestamp=none` on each library and driver, then on the app; then
    `codesign --verify --deep --strict --verbose=2` must pass.
- [ ] **Verify:** `packaging/macos/build.sh` ends green; `otool -L` of the binary names only `@rpath/` and system
  paths; `LSMinimumSystemVersion` reads `26.0` here; **`packaging/macos/build.sh --floor 15.0` FAILS here** with the
  floor message (this Mac's Homebrew is macOS 26 — the check's positive control); run the script a second time from
  `/tmp` (`/path/to/build.sh`) — same file list (`find target/macos/Rustroom.app | sort` diffed); `open
  target/macos/Rustroom.app` starts the app.
- [ ] **Sabotage:** skip the rewrite of one reference (`libjpeg`) → the outside-path check fails naming it; restore.
- [ ] **Commit** `feat(v0.1): packaging/macos/build.sh builds Rustroom.app with its libraries inside`.
