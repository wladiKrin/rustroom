# M9.6 — Defringe (purple / green, global and in masks)

**Date:** 2026-09-26 · **Branch:** `m9.6-defringe` · **Status:** choices made in brainstorm

## What and why

Longitudinal chromatic aberration leaves purple (in front of focus) and green (behind) halos beside
high-contrast edges anywhere in the frame. The lens profile's TCA correction does not touch it.
Plan done-when: *purple/green fringing on a high-contrast edge is removable by eye on a photo whose
lens profile did not fix it, with the control in the Lens group.*

## Decisions (the author's)

- **Lightroom's controls:** purple amount + purple hue range, green amount + green hue range, and an
  **eyedropper** that sets a range from a click on a fringe.
- **Global and in masks.** A mask's Defringe slider is **−100..+100, Lightroom's meaning**:
  negative protects the masked area from the global defringe, positive adds defringe there.

## Model (`edit-model`)

```rust
pub struct Defringe {
    pub purple_amount: f32,      // 0..=100
    pub purple_hue: [f32; 2],    // Oklab hue degrees, default [280, 340]
    pub green_amount: f32,       // 0..=100
    pub green_hue: [f32; 2],     // default [110, 170]
}
```
`Edits.defringe` (`#[serde(default)]`), in the **Lens** `EditGroups` group, `merge_from` and the
exhaustive fixtures. `is_active()` iff an amount > 0 (ranges alone are modifiers).
`LocalAdjustments.defringe: f32` (−100..=100).

## The stage (`pipeline::stages::defringe`)

Per pixel, in Oklab, over the whole prefix frame:
1. **Edge proximity** `e`: Sobel magnitude of Oklab L, max-filtered over radius `R` (scale-aware:
   `R = ceil(4 · scale.factor)`, at least 1), mapped through a smoothstep between two thresholds.
2. **Hue membership** `m_p`, `m_g`: 1 inside the range, feathered 10° outside, 0 beyond.
3. **Amounts per pixel:** `a_p = clamp(purple + Σ cov_i · local_i, 0, 100)`, likewise green;
   `local_i` from every enabled mask with a non-zero defringe; with the global amount 0 a positive
   local uses the global hue ranges.
4. `w = clamp(e · max(a_p·m_p, a_g·m_g) / 100, 0, 1)`; chroma scaled by `1 − w`, L untouched.

**Placement:** one prefix step **after geometry, before the masked capture steps** — in the frame the
masks live in, so global and local are one computation, and a defringe drag does not re-run the
geometry resample. Inserted when the global defringe is active **or** any enabled mask carries a
non-zero defringe. Key: `PrefixStepKey::Defringe(Defringe, Vec<MaskedAdjustment>)` holding the
projections (shape + refinements + the local amount) of the masks that carry one — a moved mask
re-runs only this step, geometry is already in the key through those projections' rule
(`prefix_airlight_key`'s precedent; checked in the plan).

Mask coverage comes from `MaskStage`'s own composite: its coverage computation is lifted into a
method both `apply` and the defringe stage call, so one definition of "where a mask is".

**CPU first.** An active defringe ends the resident GPU handoff for that photo, as masked NR does.
Its cost is measured at the fit rung and reported before deciding on a GPU twin.

## Eyedropper

A picker button in the Lens panel's Defringe block (the `picking_wb` pattern: view state on the
session, one left click on the canvas, no Settings binding — an armed click, not a drag). The click
samples a 5×5 window of the rendered frame and takes its most saturated pixel. The rule, a pure lib
function: a purple-family hue (190°..360° ∪ 0..20°) centres the purple range on it ±20°, a
green-family hue (90°..190°) the green range; a zero amount is raised to 40; any other hue changes
nothing and says so in the status line.

## Panel

Lens section: a Defringe block — the picker, purple amount, purple hue range, green amount, green
hue range. The hue range is a **new dual-handle widget** over a hue gradient (rules — no crossing,
min width 10°, drag the band to move it — in a lib module). Masks: a Defringe slider in each mask's
adjustments.

## Tests

- Synthetic: a purple fringe beside a sharp edge is desaturated; the same purple far from an edge
  survives; a fringe outside the range survives; L unchanged.
- Masks: −100 protects its area from the global defringe; +50 defringes with the global at 0.
- Keys: the step appears/disappears correctly; its key moves with the settings and a mask's shape;
  no other prefix key moves.
- Old sidecar loads neutral; round-trips; the picker rule; the range widget rules.
- Golden `defringe`.

## Out of scope

Automatic fringe detection; per-mask hue ranges; a GPU twin (unless the measurement asks for it).
