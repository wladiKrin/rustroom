# M9.11 — Red-eye (and pet-eye) correction — design

**Done when:** a flash portrait's pupils are corrected in one click each, non-destructively
(Obsidian `03-plan-of-action.md`). Extended by the author's choice to **pet eye** as well.

## Decisions taken in the brainstorm (the author's)

| Question | Answer |
|---|---|
| Gesture | **Click on the pupil.** Detection fits a circle around the click; the circle can then be moved and resized. |
| Scope | **Red eye + pet eye** (green/yellow/white flash reflection → dark pupil, optional catchlight). |
| Controls | **Per eye, new eyes inherit** the last-used Pupil Size / Darken (Lightroom's model). |
| What is stored | **Approach A: detect once at the click, store the circle.** The stage never detects; it corrects each pixel inside the circle in proportion to how red (pet: how bright) it is. Declined: detecting on every render (the eye would move when an upstream edit changes) and a stored raster mask. |
| Where in the UI | **Retouch modes**, beside Heal and Clone — not a sixth rail tool. |

## Data — `edit-model`

```rust
pub struct Eye {
    pub centre: [f32; 2],        // Spot's space: post-lens, pre-perspective frame, normalised per axis
    pub radius: f32,             // fraction of that frame's LONG edge (Spot::radius's rule)
    pub kind: EyeKind,           // Red | Pet
    pub pupil_size: f32,         // 0..=100, default 50
    pub darken: f32,             // 0..=100, default 50
    #[serde(default)]
    pub catchlight: Option<[f32; 2]>, // pet only: offset from centre in RADIUS units; None = off
}
pub enum EyeKind { Red, Pet }    // #[default] Red
```

- `Edits.eyes: Vec<Eye>` — empty = no stage. `Copy`, no container-level `serde(default)` (a
  defaulted `centre` would be an eye nobody placed — `Spot`'s rule).
- Travels on **`EditGroups.retouch`** with `spots`. Added to `merge_from`'s destructure (appended)
  and to the **three exhaustive fixtures** (`edit-model` `all_nonneutral`, `pipeline` `all_edits`,
  `app` `edit_clipboard::sample`).
- ⚠ The catchlight is an **offset stored at click time**, not a fixed "up-left" in the stage: the
  stage's frame is pre-orientation, so "up-left" is only knowable where the orientation is — the app.

## Stage — `pipeline/src/stages/red_eye.rs`

`RedEyeStage::new(&[Eye])`, `name() == "red_eye"`. A **prefix step right after spot removal**
(lens → NR → dehaze → spots → **red eye** → geometry → …): same coordinate space as spots, so
`SpotMap` draws it unchanged, and a heal patch never samples a corrected pupil's neighbour
differently from what the user sees. `PrefixStepKey::RedEye(Vec<Eye>)`; the cache key follows
automatically because `PrefixKey` is derived from `build_prefix_steps`. No GPU twin (like
`spot_removal`); `"red_eye"` joins `every_other_prefix_stage_is_left_alone`.

Per eye, over the circle's bounding box (a plain loop, as `spot_removal`):

- **Circle coverage** `c = coverage(d, r, 30)` — `spot_removal::coverage`, reused, fixed feather.
- **Red.** Redness `ρ = (R − max(G,B)) / max(R, 1e-4)`, clamped to `[0, 1]` — **one public
  function in the stage, used by detection too**. ⚠ Chosen by measurement (sRGB samples through
  `srgb_to_prophoto`): skin light/mid/dark/flushed score **0.16 / 0.26 / 0.32 / 0.37**, a lip
  **0.56**, flash pupils **0.57 (pink) – 0.78**. The spec's first metric, `(R − (G+B)/2)/R`, put
  skin at 0.27–0.47 — overlapping the pupils. Weight `w = smoothstep(t0, t0+0.12, ρ)` with
  `t0 = lerp(0.60, 0.40, pupil_size/100)` — **Pupil Size is sensitivity**: higher reaches the
  pinkish rim of the pupil, the circle still bounds it, and even at 100 flushed skin (0.37) stays
  below `t0`. Corrected pixel: `R' = (G+B)/2`, then all three × `k = lerp(1.0, 0.25, darken/100)`.
  G and B carry the iris texture through; a white catchlight has `ρ ≈ 0` and is left alone.
- **Pet.** `Yref` = the 95th-percentile luminance inside the circle; weight
  `w = smoothstep(t0, t0+0.15, Y/Yref)` with `t0 = lerp(0.70, 0.20, pupil_size/100)`. Corrected
  pixel: neutral grey at `Y · lerp(0.15, 0.03, darken/100)` (texture kept, colour removed). With a
  catchlight: a smoothstep disc of radius `0.18·r` at `centre + offset·r`, value `0.9·Yref`,
  composited over the darkened pupil.
- Out = `lerp(in, corrected, w · c)`. A non-finite or non-positive radius changes nothing.

## Detection — `app/src/eye_detect.rs` (lib, no egui)

`detect(click: [f32;2], kind, aspect, sample: impl Fn([f32;2]) -> [f32;3]) -> Detection`, with
`Detection::Found { centre, radius }` or `NotFound`. The sampler is `spot_overlay::sampler_for` —
the same injection `spot_source` uses, so detection reads the stage's input space.

1. Sample a **64×64 grid** over a square window of half-width `0.03` long-edge around the click.
2. Score each cell: redness `ρ` (red) or luminance `Y` (pet).
3. **Seed** = the best-scoring cell within the window's central quarter. Below a floor
   (`ρ < 0.50`; pet: `Y < 2 × window median`) → `NotFound`.
4. **Flood-fill** 8-connected from the seed over cells scoring ≥ `max(0.42, 0.6 · seed)` (pet: `max(2 × median, 0.5 · seed)`).
5. **Reject** a blob that touches the window edge or whose bounding box aspect exceeds 2.5 — a
   lip, a red shirt, a lamp — → `NotFound`.
6. Circle: blob centroid; radius `= 1.2 · sqrt(area / π)`, clamped to `[MIN_RADIUS, MAX_RADIUS]`.

`NotFound` still **places an eye** at the click with the tool's last radius, and the status bar
says *"No red pupil found near the click — placed a circle; drag its edge to resize."* A click
never does nothing.

## UI

- **Retouch mode** becomes four choices: **Heal · Clone · Red eye · Pet eye.** A lib enum in
  `spot_tool.rs` (`RetouchMode`) maps the first two onto `SpotMode`; `SpotMode` itself is unchanged
  (it is persisted per spot).
- **`eye_tool.rs`** (lib): `EyeTool { radius, pupil_size, darken, catchlight }` (session-lifetime,
  `SpotTool`'s rule), `place`, `hit_test` (inside → move, within the rim band → resize), `delete`,
  and the default catchlight offset for an orientation (up-left *on screen*).
- **Canvas** (`develop/canvas/eye_overlay.rs`, bin): in the eye modes, a click hit-tests eyes first
  (selects) else detects and places; a drag inside an eye moves it, on its rim resizes it; a drag on
  empty canvas places an eye of the dragged radius without detection. Circles drawn through
  `SpotMap` like spot outlines; the selected one highlighted. Moving or resizing renders on release
  only (prefix stage — the spot drag's rule).
- **Panel** (`develop/panel/retouch.rs`): an **Eyes** list under the patch list (row per eye, kind
  glyph, delete); Pupil Size and Darken (and Catchlight for pet, **on by default**) edit the selected eye, or the tool
  defaults when none is selected. Selecting an eye clears the selected spot and vice versa.
  Delete/Backspace removes the selected eye.
- **Undo:** place, move, resize, slider settle and delete are **one step each**, and every one both
  pushes `s.history` **and** marks the photo edited — the two must not diverge (`History::push`'s
  doc).

## Tests

- `edit-model`: round-trip; an unstated `catchlight` is `None`; eyes travel on retouch and no other.
- `pipeline`: red pupil neutralised (R ≈ (G+B)/2, darker) while skin at the rim and a white
  catchlight are untouched; Pupil Size widens the corrected set; pet pupil darkened and neutral,
  catchlight appears where its offset says; zero/NaN radius changes nothing; prefix order test
  gains red eye after spots; no eyes → no step; **one golden** with a red and a pet eye.
- `eye_detect`: synthetic red disc found from an off-centre click (centre within 1 cell, radius
  within 20%); pet bright disc found; no red → `NotFound`; an elongated red band (lip) → `NotFound`.
- `eye_tool` hit-test and placement; panel tests mirroring `retouch.rs`'s; an undo test that places
  an eye and asserts one Ctrl+Z removes exactly it.
- Every fixture is **constructed** (synthetic), stated as such; the real check is use on a flash
  portrait.

## Out of scope

Automatic whole-photo eye finding (no face detector — that is M9.13's territory); a GPU twin.
