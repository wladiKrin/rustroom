# M9.13 — AI masks: Select Subject and Select by click — design

**Done when** (Obsidian `03-plan-of-action.md`, amended by the author's choice of approach A): a
subject is masked without a stroke drawn, **and** any region — the sky first — is masked by one
click on it; the models' licences permit redistribution alongside a GPL-3.0 program.

## Decisions taken in the brainstorm (the author's)

| Question | Answer |
|---|---|
| Worth building? | **Yes** — for skies, people, and subjects of any kind. |
| Model delivery | **Download on first use**, with the files, sizes and licences shown first; a pinned SHA-256 per file. |
| Behaviour | **A mask component plus a Refine slider**: combinable like every other component, computed once from the unedited photo and cached, Refine moves the threshold on the soft map. |
| Approach | **A: BiRefNet_lite for Select Subject + MobileSAM for Select by click.** Declined: B, a self-converted ADE20K sky model (the dataset's research/education terms may reach the weights), and C, subject only. |
| Downloads during development | Approved: BiRefNet_lite, MobileSAM encoder + decoder, ONNX Runtime. |

## Licences (researched 2026-09-27; V = verified at the source)

- **BiRefNet_lite** — code MIT (V), weights MIT (V, Hugging Face `ZhengPeng7/BiRefNet`); ONNX
  `BiRefNet-general-bb_swin_v1_tiny-epoch_232.onnx`, 224 MB, GitHub release `ZhengPeng7/BiRefNet` v1.
- **MobileSAM** — Apache-2.0 code (V); the weights' licence is to be **verified at the source in
  Task 1** before any use. ONNX from the rembg release (`mobile_sam.encoder.onnx` 28 MB) and a SAM
  decoder (16.5 MB).
- **ONNX Runtime** — MIT, Microsoft's official GitHub release per platform (covers Intel Macs, which
  `ort`'s own prebuilts do not).
- ⛔ Excluded: BRIA RMBG-1.4 / 2.0 (non-commercial, V), NVIDIA SegFormer (non-commercial, V),
  `onnx-community/ISNet-ONNX` (re-tagged AGPL).

## Architecture

### Crate `ai-mask` (new; zero GUI dependency)
- `registry` — `ModelId { BiRefNetLite, MobileSamEncoder, MobileSamDecoder, OnnxRuntime }` with URL,
  SHA-256, byte size, licence name and URL, and for models the input size and normalisation.
- `download` — `fetch(id, dir, progress) -> Result<PathBuf>`: stream to `<file>.partial`, hash while
  writing, rename only on a matching hash; a mismatch deletes the partial and errors.
- `infer` — a `Segmenter` trait (`subject(&Rgb) -> Prob`, `embed(&Rgb) -> Embedding`,
  `click(&Embedding, point) -> Prob`) with the runtime chosen by the Task 1 spike behind it.
- `prep` — resize + normalise to the model's input; `post` — sigmoid/logits to a probability plane,
  guided upsampling to the stored resolution using the photo's luminance as the guide.
- `cache` — the coverage map as `u8`, long edge ≤ 2048, on disk under the app cache dir; key =
  hash of (file path, size, mtime, model id, prompt, lens-correction and perspective state).

### The runtime (decided by measurement)
Task 1 is a **spike**: BiRefNet_lite at 1024² on one of the author's RAF renders, through `ort`
(load-dynamic, ONNX Runtime downloaded as above) and through `tract` (pure Rust). Time and peak
memory recorded in the journal. **`tract` wins if it is within ~3× of `ort`** (no native dependency
is worth that); otherwise `ort` in load-dynamic mode, so a missing runtime disables only AI masks.

### Edit model
`Mask::Ai(AiMask { prompt: AiPrompt, refine: f32 })`, **appended** (externally tagged — old sidecars
load). `AiPrompt::Subject | AiPrompt::Click { point: [f32; 2] }`, the point in the brush's space
(post-perspective, pre-orientation/crop — `FrameMap`), so it stays on its object through crop and
rotation. `refine` in −100..=100. It rides the `masks` group; the three exhaustive fixtures gain one.
**No pixels in the sidecar.**

### Rendering
- The coverage map is computed in the **brush's space** from the lens-corrected, perspective-corrected
  photo before any adjustment, so edits never move it.
- It reaches `MaskStage` as a **side input** (`RenderSpec`, like dehaze's airlight): a map keyed by the
  mask's cache key. `MaskStage` samples it through `FrameMap` exactly as it samples a brush raster.
- Refine: `coverage = smoothstep(t − 0.15, t + 0.15, p)` with `t = 0.5 − refine / 250` — cheap, at
  render time, no re-inference.
- A mask whose map is not available renders as **empty** — preview shows the spinner row, export
  reports "AI mask not computed (model missing)" per photo.
- GPU: `MaskStage`'s twin receives the map as it receives the brush raster.

### UI
- Masks panel add menu: **Subject**, **Select by click** (then a click on the canvas).
- First use: a dialog listing the files, sizes, licences and destination, *Download* / *Cancel*; a
  progress bar; then the mask computes.
- Inference on a background worker; the mask row shows a spinner; the canvas stays live.
- The AI component's settings: **Refine** slider; for a click mask, clicking the canvas while it is
  selected re-aims it (one undo step).

## Tests
- `prep`/`post` on synthetic planes; guided upsampling keeps a synthetic edge.
- Refine: monotone in `refine`, identity-ish at 0, clamps.
- Cache key: changes on each of its inputs, stable otherwise.
- Download: a hash mismatch leaves no file; a match renames into place (a local file server or a
  `file://`-style injected reader — no network in tests).
- `Mask::Ai` round-trip, an older sidecar without it loads, the masks-group rule, the fixtures.
- A **golden** with an injected synthetic coverage map (no model in CI).
- Real models: `examples/ai_mask_probe.rs` on the author's photos — time, and the mask saved as a PNG
  beside the photo's crop for a visual check.

## Out of scope
Lightroom's person-part masks (face, hair, skin); automatic sky without a click; background removal /
transparency export; multiple positive/negative points per click mask (a brush add/subtract does it).
