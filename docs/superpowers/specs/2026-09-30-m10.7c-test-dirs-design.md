# M10.7c — Every test's temp directory is its own

**Date:** 2026-09-30 · **Branch:** `m10.7c-temp-dir-isolation` · **Status:** design approved

Recorded 2026-09-23 as "the 7 temp-dir test-isolation sites" (+2 in `immich_source`); CLAUDE.md has
carried *"never run two gates concurrently"* because of them.

## What the sweep found

~55 test sites create temp paths, in three kinds: **fixed names** (`rustroom_sync_{tag}`,
`rustroom_settings_{tag}.json`, `rustroom_edits_roundtrip.json` — collide between concurrent gates),
**process id only** (`rustroom_immich_{pid}`, `rustroom-size-{pid}` — collide between two tests in one
run, whose threads share a process), and **pid + counter** (safe). Four home-grown helpers
(`thumb_store::TempDir`, `ingest::temp_dir`, `camera-profile`'s `testing`, `test_app::TestDir`). And
**3,128 leftover directories, 72 MB, a week's worth** — cleared on 2026-09-30 with the author's OK.
The one production use, `batch_export::worker::staging_dir`, is already pid + counter.

## Design

A dev-only crate **`test-dir`**:

- **Layout:** `temp/rustroom-tests/<pid>/<tag>-<n>` — the process id keeps concurrent runs apart, a
  counter keeps a run's tests apart.
- **`TempDir::new(tag)`** — a fresh directory, deleted on drop (panics included); `.path()`, `.join()`,
  `.keep()` (hand the path over without deleting). **`test_dir::path(tag)`** = `TempDir::new(tag).keep()`,
  for fixtures that must return a plain path.
- **Cleanup of ended runs, by lock rather than by age** (a refinement of the approved "over a day
  old"): each run holds `File::try_lock` on `<pid>/.lock` for its lifetime; the first `TempDir` of a run
  deletes every other root whose lock it can take — its run has ended — and never one a concurrent gate
  still holds. A root without a lock file is left unless it is over a day old. So kept paths and
  crashed runs are cleaned at the next run.
- **Every site moves onto it** — app, catalog, export, image-decode, edit-model, camera-profile,
  ai-mask; the four helpers delegate to it. Examples (manual tools) and the production staging
  directory stay.
- **Guard:** a sweep in `test-dir`'s tests reads every crate's `src/` and `tests/` and fails on
  `env::temp_dir()` outside `test-dir` and `batch_export/worker.rs`; positive control — it must find that
  one allowed site.

## Tests

Two `TempDir`s with one tag differ, across threads too; dropping deletes, `keep` does not; the
cleanup removes a root whose lock is free and keeps one whose lock is held; the sweep. **The proof:**
two full gates run at once, both green — then CLAUDE.md's warning goes.
