## Decisions (the author's)

- **Scope:** every file over 1,000 lines of code + doc — the nine above — **and** the four giant
  functions broken into named steps.

## Rules

- **No behaviour changes.** Every public path keeps resolving (root `pub use`; the
  `batch_export/mod.rs` pattern). Preserved exactly: egui ids and the nesting that derives them, widget
  registration order, the order borrows are taken, the order phases run, every `TIMING` line.
- **Tests follow their code** into the submodule's own `#[cfg(test)] mod tests`; fixtures used by
  several modules go to a `#[cfg(test)]` fixtures module per split (`batch_export/fixtures.rs` is the
  precedent). A test of another module moves to it: the library's two filter tests → `library_state`,
  its arrow-step test → `grid_nav`, canvas's `a_region_frame_refreshes_the_fit_image_size` → the
  shell's landing. **M10.7e:** `PrefixCache`'s seven tests → `prefix_cache.rs`, and `render_engine`'s
  duplicate `fake_key` is deleted.
- **Misplaced docs are re-homed first, in commits of their own**, before anything moves; they are
  the only commits allowed to move comment lines between items. The truncated comment is completed and
  the dead link fixed in the same commits.
- **Out of scope** (recorded in `docs/BACKLOG.md`): moving window-free logic from bin modules into the
  lib (`rungs_to_drop`, `mark_filter_label`, `grid_columns` + `cells_in_row`, the band's union, the
  click→pixel maths), and de-duplicating the twice-written pan/zoom, the eyedroppers' click mapping and
  the shape counters in canvas tests.

## The giant functions

Each becomes an orchestrator calling its phases in today's order: what is hoisted before the big
borrow goes into an **inputs** struct, what is written back after it into an **outcome** struct.

- **`render_cached_with`** — a `Walk` (the `key_at`/`tier_at` closures become methods) → prefix
  (resume, then the scoped or whole-buffer walk, returning `PrefixOut` including `img`) → coverage → a
  `Tail` (the `build_tail` closure becomes a method) → tail input → soft-proof run → main tail → harvest
  → pack, counters in a `TailStats`. **Must not change:** the step loop's `break` stays inside one
  function; each timer stays with the code it times; `if gpu_tail { match shared() }` stays as written
  (a tuple match once cost 42 s and broke three tests); `REFUSE_THE_RESIDENT` lives with its reader;
  the two re-bindings (`region`, `input`) get distinct names so a mix-up fails to compile.
- **`canvas::show`** — `CanvasInputs::hoist` → `session_canvas`: plan and request with `&mut Session`,
  *then* borrow the texture for place and paint, then tool dispatch → composition guides → zoom/pan →
  readout; `CanvasOutcome::write_back` after the panel. `crop_aspect` and `brush_flow` join the hoist.
  **Must not change:** `available_size` read before `allocate_rect`; the eyedroppers' `interact`
  registered after the image's; `soft_next` taken on every frame with a texture; the guide solve before
  the tool write-back; the fringe status over the eye status; the outer `ui` for `press_on_canvas`.
- **`library::show`** — `apply_pinch` → `GridInputs`/`GridOutcome` → the panel (keys → geometry →
  background sensor → downloaded flags → rows → per cell: picture, stack badge, label badge, caption,
  marks, stars, interactions → sync window) → the band → the write-back. **Must not change:** no new
  `ui` scope wrapper anywhere (it moves egui ids — the rename field's focus and the accessibility test
  depend on them); registration order (background sensor first, the whole-cell `interact` last); the
  early returns leave the panel closure only; the band paints on the outer `ui`; `menu_select` before
  `menu`, `open_index` last.
- **`shell`'s `ui`** — named phases: dropped files, view reset, loader pumps, input (native menu →
  clipboard → commands → culling, in that order), job pumps, frame landing (`apply_frame`, callable
  without a window), thumbnails, captures, top panel (command before rename, both deferred), view body;
  the macOS close stays inline.

## Verification

- **Tests:** the multiset of test *names* is identical before and after (3,291; only module paths
  move); no golden reference changes; the 16 GPU-gated tests run on this Mac, which has an adapter.
- **A conservation check on every commit:** for a move, the non-blank lines of the touched files are
  the same multiset before and after except `use`/`mod`/`pub use`/visibility lines; for an extraction,
  no comment line disappears. The generalisation of the removed-`///` check in the standing lessons.
- **A guard:** a sweep in `test-dir` — the crate that already sweeps every crate's sources — fails on a
  file over **1,000 lines** of code + doc outside test items, measured exactly as above; positive
  controls first (the walk finds over 300 files, and the largest measures over 500), then a sabotage. `CLAUDE.md`'s `awk` measure is
  replaced by it.
- **Speed:** the `RUSTROOM_DEBUG_RENDER` `TIMING` lines of one Straighten drag, before and after.
- **Use:** the GUI at the end — Develop, the grid, the top bar.

## Order

One branch. Doc re-homing first; then one gated commit per file: `catalog`, `edit-model`, `pipeline`,
`settings`, `render_engine` (move, then extraction), `main.rs`, `shell`, `library`, `canvas`; then the
guard and the docs (`CLAUDE.md`'s measure and its file sizes, the journal, the backlog's out-of-scope
items, the vault's M10.7d and M10.7e).
