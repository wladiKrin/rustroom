# M10.11b — Grain

**Date:** 2026-10-11 · **Branch:** `m10.11b-grain` · **Status:** design approved

Phase 10's M10.11b: *"A Grain slider (P-26, 2026-09-28)."* Lightroom's Effects panel carries the post-crop
vignette and Grain (Amount, Size, Roughness); `lr-preset` lists grain as *left out* today.

## Decisions (the author's)

- **Effects, with Vignette** — Lightroom's arrangement: the Vignette section and edit group are shown as
  **Effects**, holding the post-crop vignette and Grain.
- **Lightroom's three controls**: Amount, Size, Roughness. How strong Amount 100 is, is the author's
  photographic call — tuned on crops after it is built.

## Design

### The setting (`edit_model::Grain`)

`Grain { amount: f32 (0..100), size: f32 (0..100), roughness: f32 (0..100) }`, defaults 0 / 25 / 50
(Lightroom's), active when `amount > 0`. In the group whose field is `vignette` — **the field keeps its
name**, so every stored preset, sync selection and settings file reads as before; only the displayed name
becomes *Effects*. ⚠ **Not serialized while default** (`skip_serializing_if`), M10.11a's lesson: a default
block would change every rendered preview's key on disk.

### The stage (`pipeline/src/stages/grain.rs`)

- **Where**: the last scene-linear stage of the tail — after sharpening (grain is not sharpened), before the
  camera rendering, a look and the output transform.
- **What**: brightness only, in stops — `out = p · 2^(A · n(x, y) · w(L))`:
  - `n` — zero-mean value noise on a lattice (an integer hash of the cell corners, smoothstep-interpolated,
    so CPU and GPU compute the same integers);
  - `A = amount / 100 · MAX_EV` (`MAX_EV` 0.5 to start — the author tunes it);
  - `w(L) = 4L(1 − L)`, `L` the pixel's luminance encoded (sRGB curve, clamped) — strongest in the
    midtones, fading in deep shadows and highlights, as film grain shows.
- **Size**: the cell is `1 + 4 · size / 100` pixels **of the full-resolution frame** (1–5), times the
  render scale in the buffer's pixels — so a preview and the export show the same grain on the photo.
  ⚠ Below one buffer pixel per cell (a fit preview), the lattice is sampled at one pixel and the amplitude
  scaled by the cell size, the standard deviation an average of that many cells would have — never harsh
  single-pixel noise standing in for fine grain.
- **Roughness**: a second octave at half the cell, offset, mixed in by `roughness / 100`, the sum
  normalised to keep the strength — rougher is less even.
- **Where a pixel is**: the lattice is addressed in the **frame's** coordinates (`Region` offset), so a
  region render is the same crop of the full render, the vignette's rule. One fixed seed: the same grain
  field on every photo, deterministic everywhere.
- **GPU twin** (`gpu-pipeline/src/grain.rs`), region-aware like the vignette's, in `REPLACEABLE`, so the GPU
  tail stays whole.

### The panel

The section shown as **Effects** (`EDIT_GROUP_NAMES[5]`): the post-crop vignette's sliders under a
*Post-crop vignette* sub-header, then *Grain* — Amount, Size, Roughness, each with its own hover sentence
(`slider_help::Scope::Grain`). Its body moves to `develop/panel/effects.rs` (`adjustments.rs` is 795 lines
of code).

### Lightroom presets

`GrainAmount`, `GrainSize`, `GrainFrequency` → Amount, Size, Roughness, one to one; grain leaves the
*left out* list; the group is carried when the file sets any grain or vignette setting.

## Tests

- **Stage**: off is the identity; the mean of a mid-grey frame moves under 2 %; the spread grows with Amount;
  midtones get more than a deep shadow or a highlight; the same pixel of the frame gets the same grain at
  any region; a ¼-scale render's cells are a quarter the size (its autocorrelation length) and its spread
  matches the export's downsampled; Roughness raises the high-frequency share; deterministic across runs.
- **GPU**: equal to the CPU within the per-pixel tolerance, whole and in a region; golden of the chart at
  Amount 50.
- **Model and presets**: an old `Edits` reads no grain; a default is not written; the Effects group carries
  it; an old preset ticking *Vignette* still carries the vignette (and now grain); a Lightroom preset's grain
  maps across and is no longer left out.
- **Panel**: the section is named *Effects*; its three Grain sliders draw with help.
- **Sabotages, each red**: the tone weight removed; the scale ignored; the region offset ignored; grain
  before sharpening; the GPU hash differing; the default serialized; the preset mapping dropped.

## As built (2026-10-12)

- **The noise is sampled at pixel corners** (frame `x`, `y`), which makes a quarter-scale pixel `x` read
  exactly what full-scale pixel `4x` does — asserted, not approximated.
- **The hash constants live in `pipeline`** (`HASH`, `SEED`, `SEED2`, `OFFSET`) and the WGSL substitutes them.
- **The Effects body** draws the vignette's sliders under *Post-crop vignette* and grain's under *Grain*
  with `theme::sub_label`, Detail's pattern.
- **Tuning crops**: `examples/probe_grain.rs`. `MAX_EV` 0.7 — the author asked for "a bit stronger" than 0.5.
