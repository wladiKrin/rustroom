# M10.19a HEIC / HEIF photos — design

**Status:** the author said "just start" (2026-11-11); every choice here is mine, marked *(my call)*.

## Intent

HEIC/HEIF photos (an iPhone's, Immich's copies of them, a camera's `.HIF`) never appear in Rustroom because libraw
cannot read them and the catalog does not list them. They should appear, open, edit and export like a JPEG.

## Goals

- `.heic`, `.heif` and `.hif` are catalogued like JPEGs: folders, Import from a card, the open dialog, Immich assets.
- Decoded by **libheif** (`libheif-rs`, MIT; libheif LGPL, linked dynamically) — a system build dependency like
  libgphoto2: `pacman -S libheif`, `brew install libheif`, CI's `libheif-dev`. Bound at **libheif 1.17** (Ubuntu 24.04).
- **Orientation** is the container's (`irot`/`imir`), applied by libheif; the EXIF tag is ignored, as the HEIF spec says.
- **Colour**: an embedded ICC profile is honoured through LittleCMS into linear ProPhoto; without one, the nclx
  primaries (1 = sRGB/709, 12 = Display P3) with the sRGB curve; anything else is read as sRGB *(my call)*. So an
  iPhone's Display P3 keeps its colour instead of being read as sRGB like a JPEG still is.
- **10-bit** (a camera's HIF) keeps its precision: decoded at 16 bits, scaled to [0, 1].
- **EXIF** (date, camera, lens, exposure, GPS) is read from the file's Exif block — the catalog, the import survey
  (`quick_look`) and the map all see it.
- Grid thumbnails and the instant preview are converted to sRGB for display.

## Non-goals

- HDR HEIC (PQ/HLG, Apple's gain maps): the SDR picture is decoded, the HDR part ignored.
- AVIF; burst/depth/auxiliary images; writing HEIC on export.
- ICC handling for JPEG/PNG/TIFF (still sRGB by assumption) — M10.13's ground.

## How

`image-decode/src/heif.rs`: the sniff (`ftyp` brands), the decode to oriented RGB samples with their colour, the
Exif block. `image-decode`'s `decode`, `thumbnail`, `preview`, `read_capture` and `quick_look` dispatch to it.
`catalog::IMAGE_EXTENSIONS` gains the three extensions; the open dialog's filter follows.
Fixtures are constructed with `heif-enc` (sRGB, P3 nclx, 10-bit, EXIF), committed small.
