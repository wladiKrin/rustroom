# M11.4 `v0.1` — piece 1: the version in About, and more RAW formats (short design)

> **Approved by the author 2026-11-17.** Piece 1 of four (the order agreed 2026-11-17): (1) these two gaps,
> (2) Windows, (3) packaging — an icon, a Mac app with its libraries inside, an AppImage, a Windows installer,
> built by a release workflow on a tag, (4) signing and stores, after going public.

## Why

M11.3 found both while writing the README: the About window shows no version (the bug form had to ask for
`git log -1`), and only eight RAW extensions reach the Library though the bundled LibRaw decodes far more.

## What

1. **About shows the version** — "Version 0.1.0", plus the short commit when built from a git checkout
   (`unknown` otherwise), so two test builds of 0.1.0 can be told apart. The bug form then asks for "the version
   shown in About Rustroom".
2. **17 more RAW extensions** in `catalog::RAW_EXTENSIONS` — the formats LibRaw 0.21.3 *as `rsraw-sys` builds it*
   decodes: Pentax `pef`, Nikon compacts `nrw`, Samsung `srw`, Leica `rwl`, Panasonic/Leica `raw`, Hasselblad
   `3fr` `fff`, Phase One `iiq`, Leaf `mos`, Mamiya `mef`, Epson `erf`, older Sony `sr2` `srf`, Minolta `mrw`,
   older Canon `crw`, Kodak `kdc` `dcr`.
   - **Excluded, checked in the build:** Sigma `x3f` (needs `USE_X3FTOOLS`) and GoPro `gpr` (needs `USE_GPRSDK`) —
     neither is defined in `rsraw-sys`'s build.
3. **One list:** the Open dialog's hard-coded extensions (`session_flow`'s `open_dialog`) read the catalog's lists.
4. **Docs:** the README's camera line; the backlog's and the vault's two gaps marked done.

## Known costs

- Settings → Stacking shows a chip per format: about 30 chips instead of 13 (the row wraps).
- No sample file of a new format is in hand: tests cover the lists, not the decoding. With the author's yes per
  download, one CC0 sample per format from raw.pixls.us is opened locally (never committed) to check it decodes.
- A `.raw` file that is not a camera's (other software uses the extension) shows as a photo that fails to decode.
