# `v0.1` piece 3b — the Mac app: a brief for the session on the author's Mac

## Where piece 3 stands

Packaging is split by machine (the author, 2026-11-17): **3a ✅ on Windows** — the icon, the Windows installer and the
release workflow; **3b here** — `Rustroom.app` in a `.dmg`; **3c on Arch** — an AppImage. Signing, notarisation and the
stores stay piece 4. Read `grep -n 'piece 3a' docs/JOURNAL.md` first.

## What 3a settled, to reuse

- **The icon:** `packaging/icons/rustroom.svg` (the aperture, the author's pick) and its committed PNGs
  `png/rustroom-{16,32,64,128,256,512,1024}.png` — exactly what an `.iconset` needs (`icon_16x16.png`,
  `icon_16x16@2x.png` = 32, … `icon_512x512@2x.png` = 1024) for `iconutil -c icns`. The window already shows the
  icon (`rustroom_app::app_icon`); eframe may also put it in the Dock of an unbundled run — check.
- **One script per package, which the release workflow only calls:** add `packaging/macos/build.sh` (like
  `packaging/windows/build.ps1`) and a `macos` job in `.github/workflows/release.yml` (an arm64 runner, `macos-14`) whose
  artifact the `release` job's `needs` must then include.
- **Licences:** `cargo about generate --manifest-path crates/app/Cargo.toml packaging/about.hbs` (`about.toml` already
  lists the macOS target) plus each bundled native library's own text, gathered from its source as `build.ps1` does.

## What the Mac needs (known, not yet tried)

- **The bundle:** `Contents/MacOS/Rustroom`, `Contents/Info.plist` (name, version from the crate, the icon, a minimum
  macOS), `Contents/Resources/rustroom.icns`, `Contents/Frameworks/` for the libraries.
- **The Homebrew libraries inside it**, their install names rewritten (`otool -L` / `install_name_tool`, or
  `dylibbundler`): LittleCMS, libheif with what Homebrew's libheif pulls in (libde265, x265, aom… and its **plugin
  folder**), libgphoto2 with libltdl, libusb, libexif and its **camlibs and iolibs folders**, which it finds through the
  `CAMLIBS` / `IOLIBS` environment variables — set inside the bundle before the first camera search.
- ⚠ **The minimum macOS is the oldest one the bundled libraries were built for** — Homebrew builds for the machine it
  runs on, so a bundle made on macOS 15 needs macOS 15. A design question for the author: accept that, or build the
  libraries for an older target (vcpkg with a deployment target, or LittleCMS from `lcms2-sys`'s bundled source).
- **Ad-hoc signing** after every `install_name_tool` change (arm64 refuses unsigned code); notarisation is piece 4, so a
  downloaded app is opened the first time with right-click → Open.
- ⚠ **The keychain:** a packaged app is a new code identity — the Immich keys' item will ask for access once
  (M10.15a, `AGENTS.md`'s Immich invariants).
- **macOS-only modules** (`native_menu`, `display_colorspace`) must behave the same in the bundle.
- **Decisions for the brainstorm:** the bundle identifier (permanent, like Windows' `AppId`), the minimum macOS,
  arm64 only or universal, the `.dmg`'s look.
