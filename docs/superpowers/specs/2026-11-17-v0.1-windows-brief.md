## Never run on Windows yet

The code is Rust throughout, but nothing has been built or run on Windows. One `cfg(windows)` exists
(`crates/app/src/reveal.rs`). What is known, from the Mac and Linux builds:

- **Native libraries:** LittleCMS (`lcms2` crate) and libheif (`libheif-rs`, plus its HEVC decoder libde265) are system
  libraries on macOS and Linux; on Windows they will most likely come from vcpkg. LibRaw is compiled in by `rsraw-sys`
  (C++ through `cc`) — but `rsraw-sys` runs **bindgen** on native builds, so **libclang (LLVM) is needed**.
- **Tethering** (`crates/tether`, libgphoto2 through `libgphoto2_sys`, which also runs bindgen): libgphoto2 barely
  supports Windows. Expect to put tethering behind a cargo feature or `cfg(not(windows))`, with the menu item hidden
  on Windows — the author's call in the brainstorm.
- **Printing** goes through CUPS (`lpstat` / `lp`); on Windows it is **PDF only** — the README already says so.
- **Keys:** the `keyring` crate (4.2) should use Windows Credential Manager; unverified.
- **macOS-only modules** (`native_menu`, `display_colorspace`) are gated at every reference — an ungated one is exactly
  what broke Linux. The in-window menu bar is what Windows will show.
- **Paths:** `dirs` everywhere (config, cache, data); the AI models land in the data folder; check long paths and drive
  letters in the catalog's folder tree.
- **GPU:** `wgpu` should pick DX12 or Vulkan; the GPU tests may need a GPU on that machine.

## How this project works (the short version)

- **Branch per piece** (`v0.1-windows`), **never push** (the author pushes), **no `Co-Authored-By` trailer**.
- **The gate:** `cargo fmt --all -- --check`, `CARGO_TARGET_DIR=target/clippy cargo clippy --workspace --all-targets --
  -D warnings`, `cargo test --workspace` — one cargo mode per session (`AGENTS.md`, *The gate*).
- **Closing:** the author tries it in the app and says "works, merge" — then merge `--no-ff`, delete the branch, and
  record it in `docs/JOURNAL.md`, `CLAUDE.local.md`, `docs/BACKLOG.md` (M11.2) and the vault (on the Mac).
- Fill `CONTRIBUTING.md`'s `<!-- fill at M11.2 -->` Windows build steps with what actually worked.
